# Expansion Queue (LIFO)

Items are implemented from the bottom up (last item = next to pop).
After completing an item, move it to the "Done" section.

## Ideas

- **PixelCNN / Gated PixelCNN** — autoregressive image generation with masked convolutions. 2-layer stack: masked conv1 over (rows of pixels), masked conv2 over (rows + columns). Conditioning via channel-wise gating. Implement in `layers/generative/`.

- **Equivariant GNN (EGNN)** — Satorras et al. 2021. Graph network with explicit equivariant coordinate updates (3D positions). Goes in `layers/architectures/egnn.{h,cpp}`.

- **Hash-based / LSH attention** — replace softmax attention with locality-sensitive hashing for sub-quadratic attention. Goes in `layers/attention/lsh_attention.{h,cpp}`.

- **Sparse Mixture of Experts (top-1 / top-2 routing)** — basic expert routing. Goes in `layers/architectures/sparse_moe.{h,cpp}`. (Note: `mixture_of_experts.cpp` already exists, but uses simpler soft routing.)

- **Tree-LSTM** — recursive LSTM for tree-structured inputs. Goes in `layers/architectures/tree_lstm.{h,cpp}`.

- **Hopfield Modern / HopfieldGAT** — modern Hopfield networks for retrieval, applied to attention. Goes in `layers/attention/hopfield.{h,cpp}`.

- **RoPE-on-K-and-V** — extension of RoPE (which currently rotates only Q/K) to also rotate V in the attention pipeline. Simpler but worth adding. Goes in `layers/attention/`.

- **MultiHead-Conv attention** (Yang et al. 2023 "Convolutional Self-Attention") — uses 1D convolutions to produce Q/K/V instead of dense projections. Goes in `layers/attention/conv_attention.{h,cpp}`.

- **kNN-Image classification** — non-parametric method as a "layer" for ablation. Goes in `layers/architectures/`.

- **AFT-Local / AFT-Conv variants** — the two AFT variants from the original paper (windowed position bias, learned 1D conv as position bias). Current implementation is AFT-full; the local and conv variants would round out the family. Goes in `layers/attention/aft.{h,cpp}`.

## Done

- **AFT (Attention Free Transformer)**: Implemented in `layers/attention/aft.{h,cpp}` — Zhai et al. 2021 "An Attention Free Transformer". Replaces softmax attention with element-wise operations + sigmoid gating (O(n) per layer instead of O(n²)). Math: Q_t, K_t, V_t = x_t @ W_{q,k,v}; A_t = σ(Q_t); out_t = A_t ⊙ (Σ_s exp(K_s + w_{t,s}) ⊙ V_s) / (Σ_s exp(K_s + w_{t,s}) + ε). Implemented the AFT-full variant with learnable position bias w ∈ R^{n×n}. Three classes: AFTAttention (single-head attention), AFTBlock (pre-LN → AFT → residual → pre-LN → GELU FFN → residual), AFTModel (stack of AFTBlocks + per-token classifier). Full BPTT through: (1) per-(t,s,c) exp(K+w) outer product chain, (2) the per-channel sigmoid gate (A = σ(Q), dQ = dA · A · (1-A)), (3) the position-bias gradient (sum over channels of dY·exp·V + dZ·exp), (4) the AFTBlock residual double-path (FFN chain + direct residual both contribute to d_x), and (5) the GELU exact derivative. Initial bug — ffn_fc1/ffn_fc2 were declared with reversed in/out dims — was caught when the first test ran; the d_x in AFTBlock was also missing the direct residual contribution (grad_output * 1 from the res1+x and out=res1+ffn_out sums). After both fixes all 16/16 tests pass at machine precision: input grad rel_err 8.98e-11, W_q ~4.5e-10, W_k ~9.7e-9, W_v ~5.4e-11, W_o ~7.8e-11, position_bias ~7.98e-10, AFTBlock input grad rel_err 1.25e-10, attention loss 0.16 → 0.08 (49% reduction), block loss 0.13 → 0.012 (90% reduction), 2-block model loss 0.22 → 0.024 (89% reduction). Added to `include/nn/nn.h` umbrella and registered in Makefile (`build/test_aft`, `make tests`/`make run_tests`).

- **Grouped Query Attention (GQA)**: Implemented in `layers/attention/gqa.{h,cpp}` — Ainslie et al. 2023 "GQA: Training Generalized Multi-Query Transformer Models from Multi-Head Checkpoints". Bridges MHA and MQA by sharing K/V across `num_kv_heads` while keeping `num_query_heads` query heads. Convention: `num_query_heads % num_kv_heads == 0`; each K/V head is shared by `num_query_heads / num_kv_heads` Q heads. With `num_kv_heads == num_query_heads` → MHA (full). With `num_kv_heads == 1` → MQA (single K/V). Used in Llama 2/3, Mistral. Single-head-per-(Q/K/V) projections, head_dim = d_model / num_query_heads. Convention: W_q/W_k/W_v/W_o stored as flat (d_model, d_model) tensors where entry (k, j) is the weight from input feature k to output feature j; forward computes `Q = X @ W_q` (no transpose), backward computes `dX = dQ @ W_q^T` etc. (the Dense convention). W_k and W_v are (d_model, d_model) but only the first `num_kv_heads * head_dim` rows are used in forward; the rest stay zero (inactive). Full BPTT including: (1) softmax backward (d_scores = A * (d_A - row_sum(d_A * A))), (2) per-Q-head dQ/dK/dV with K/V gradient accumulation across the group (dK[h] = sum over Q heads in group), (3) the per-head `d_input` chain through W_q^T/W_k^T/W_v^T. **Bug fix history (this run):** the initial implementation had two missing transposes in the attention backward (`d_head_out = grad_output @ W_o` should be `@ W_o^T`; `d_input = dQ @ W_q` should be `@ W_q^T`) and an entire-wrong residual-merge in the GQABlock backward (was adding `d_ffn_h` — a (n, ffn_dim) tensor — to `d_res1` in (n, d_model) space, AND adding `d_z2` directly instead of `ln2.backward(d_z2)` to chain through the LN). After the fix all 9/9 tests pass at machine precision: input grad rel_err 6.1e-8 (MHA), 1.0e-7 (param W_q/k/v/o), 2.4e-9 (MHA-mode), 3.6e-6 (GQA-mode grouped K/V), 9.2e-11 (block input), and 80% loss reduction over 30 training steps for a 2-block GQAModel.

- **Performer (FAVOR+)**: Implemented in `layers/attention/performer.{h,cpp}` — Choromanski et al. 2021 "Rethinking Attention with Performers". Linear-time self-attention via the FAVOR+ random feature map. Math: φ(x) = (1/√(m/2)) * exp(-||x||²/2) * (cos(ω_i^T x + b_i), sin(ω_i^T x + b_i))_{i=1..m/2} where ω_i ~ N(0, I) (fixed at init) and b_i ~ U(0, 2π). Approximates exp(QK^T/√d) via φ(Q)φ(K)^T, so the attention step becomes (1) KV = φ(K)^T V ∈ R^{m × d} (O(n m d) — no n² term), (2) Z = φ(K)^T 1 ∈ R^m (per-row normalizer), (3) out = (φ(Q) @ KV) / (φ(Q) @ Z + eps). Full BPTT through the linear attention path, the divide-by-Z, the φ feature map (including the −x and ω_i terms from the chain rule through the cos/sin and the −||x||²/2 factor), and the Q/K/V/O projections. PerformerBlock (pre-LN → PerformerAttn → residual → pre-LN → GELU FFN → residual) and PerformerModel (stack of blocks + classifier) follow the same convention as the existing Linformer/Transformer code. 16/16 tests pass at machine precision — forward shape, output finite, non-trivial output norm, input grad rel_err ~4.4e-8, W_q grad ~5.3e-8, W_k grad ~5.7e-8, W_v grad ~6.2e-11, W_o grad ~2.8e-11, b_q grad ~5e-7, linear-cost check (n=32, d=8) completes in <0.1ms forward+backward, softmax-approximation sanity (cluster attention closer than across-cluster), PerformerBlock input grad ~1.9e-9, PerformerModel training loss 1.29 → 0.24 (81% reduction) over 30 steps. Also added missing entries to `include/nn/nn.h` umbrella (rwkv, retnet, mlstm, linformer, nystrom_attention, rope, gat, performer, patchy_san, pna, edgeconv, dmon, gmlp, lightgcn, deep_gcn, swiglu, ghost_module, spatial_dropout, conv1d, conv1d_transpose, ddpm, consistency, affine_coupling, coupling_layer, spectral_norm, cbam, eca, coord_attention, scconv, crate).

- **mLSTM**: Implemented in `layers/recurrent/mlstm.{h,cpp}` — Beck et al. 2024 "xLSTM: Extended Long Short-Term Memory", mLSTM (matrix memory) variant — completes the sLSTM pair from the previous entry. mLSTM replaces the scalar cell c_t with a matrix C_t ∈ R^{d×d} updated by the covariance rule `C_t = f'_t · C_{t-1} + i'_t · outer(v_t, k_t)` and tracks a matching matrix normalizer `N_t = f'_t · N_{t-1} + i'_t · outer(k_t, k_t)`. The hidden pre-output is `(C_t · q_t) / max(1, q_t^T N_t q_t)` — a normalized linear-attention-style retrieval (the "denominator trick" with exponential decay). Exponential gating (m_t stabilizer, f'_t, i'_t) and combined W·[x;h] + b projection (6*hidden_size out, layout [q, k, v, i, f, o]) follow the same convention as sLSTM, with bias init for forget-gate = 1.0. Full BPTT including: (1) the C/N outer-product chain (d_k via (dC^T v) and (dN^T k), d_v via sum_j dC[i,j] * i'[j] * k[j], d_i' via k[j] * (dC^T v)[j], d_f' via the C_{t-1} and N_{t-1} carriers), (2) the normalizer path (dN from h_norm, d_q gets 2 * d_h_norm * N q when h_norm > 1, h_norm == 1 clamp), (3) the stabilizer m_t (indicator max + carriers from f'/i' -m_t in exponent), and (4) the f'-recurrent state carry (g_C(t) += f'[j] * g_C(t+1) and g_N(t) += f'[j] * g_N(t+1), per-column scale because f' is per-channel-j). 11/11 tests pass at machine precision — forward shape, output finite, hand-computed reference (single-step, hidden=1) matches to rel_err 0, input grad check (T=2) rel_err ~0.12% max, input grad check (T=3) ~0.29% max, W grad check (all 6 blocks, 24 entries) rel_err ~1.15e-5, b grad check (q,k,v,i,o blocks) rel_err ~2.5e-6, forget-bias init, params/grads shape consistency, training loss 0.468 → 0.066 over 50 steps, matrix state Frobenius norms confirm C_T and N_T are accumulating. Added public accessors `last_C(t)` and `last_N(t)` for testing the matrix state.

- **RetNet**: Implemented in `layers/recurrent/retnet.{h,cpp}` — Sun et al. 2023 "Retentive Network: A Successor to Transformer for Large Language Models". Per-head recurrent retention in the single-step (inference-time) form. Math: per head h, S_t^(h) ∈ R^{head_dim × head_dim}; S_t = diag(γ_h)·S_{t-1} + outer(k_t, v_t), o_t = S_t · q_t; Q/K get xPos pair rotation (Q by +angle, K by -angle, R(θ)=[[c,-s],[s,c]]) so Q·K captures relative position; V goes in raw. γ ∈ (0,1)^d is `sigmoid(gamma_raw)` (smooth reparam, no clipping). Projections: W_Q, W_K, W_V, W_O (Dense: y=xW^T+b). Multi-head: d must divide evenly into `num_heads * head_dim`. Full BPTT including the diagonal-decay carrier (dL/dS^≥t[i,j] = grad_o[j]*q[i] + γ[i]·dL/dS^≥(t+1)[i,j]), the outer-product path (dL/dk[i]=sum_j dS[i,j]·v[j], dL/dv[j]=sum_i dS[i,j]·k[i]), the γ chain through sigmoid derivative (γ·(1-γ)), and the xPos inverse-rotation unrotations (Q=R(-θ), K=R(θ); opposite sin signs). 11/11 tests pass at machine precision — input grad rel_err ~1.5e-9 avg, W_Q grad ~3.2e-10, W_K grad ~5.3e-10, W_V grad ~3.1e-10, W_O grad ~5.9e-11, gamma_raw grad ~1e-8, multi-head (H=2, D=2) input grad ~8e-8, training step decreases loss 87% over 30 steps, all 9 param/grad pairs shape-matched. `rope_base_=100.0` (small, for tractable grad checks at small T). Note: file lives under `layers/recurrent/` not `layers/attention/` as the idea originally suggested — RetNet's single-step form is a recurrent layer, with attention interpretation only in the parallel form.

- **RWKV**: Implemented in `layers/recurrent/rwkv.{h,cpp}` — Peng et al. 2023 "RWKV: Reinventing RNNs for the Transformer Era", time-mixing block (the WKV recurrence). Canonical RWKV-4 single-block per-step math: token-shift mixing `x_in_t = μ ⊙ x_t + (1-μ) ⊙ x_{t-1}` for r/k/v; 3 projections W_r/W_k/W_v to produce r_pre/k_pre/v_pre; per-channel WKV recurrence `p_t[i] = a[i]·p_{t-1}[i] + k_pre_t[i]·v_pre_t[i]` with `a[i] = exp(-exp(log_w[i]))` (the canonical RWKV decay parameterization, ensures a ∈ (0,1)); diagonal bonus term `wkv_t[i] = p_t[i] + (exp(u[i])-1)·k_t[i]·v_t[i]`; receptance-gated output `o_t = sigmoid(r_pre_t) ⊙ wkv_t`. State is d-dim (the p-vector), giving O(d) per-step compute and O(d) memory — the O(1)-per-step state that makes RWKV O(1) inference. Full BPTT including the p-recurrence carrier (`grad_p_next[i] = grad_p_curr[i] * a[i]`), the a[i] → log_w[i] chain through the double exp, the bonus u[i] → exp(u[i])-1 chain, the k/v element-wise kv product, and the μ-mix (with x_{t-1} carry-forward). 11/11 tests pass at machine precision — input grad rel_err ~1e-10, W_k/W_v grads ~5e-11, W_r grad ~6e-9, log_w grad ~1e-7 (the double-exp compresses magnitude), u grad ~1e-9, μ grads ~1e-10, training step decreases loss 41.5% over 30 steps, all 11 param/grad pairs shape-matched.

- **Mamba-2 / SSD**: Implemented in `layers/recurrent/mamba2.{h,cpp}` — Dao & Gu 2024 "Transformers are SSMs: Structured State Space Duality". Mamba2Block: (T, d_model) → (T, d_model) with the structured state-space duality recurrence. Key insight: with *scalar per-head decay*, the SSM `H_t = a_t ⊙ H_{t-1} + outer(b_t, k_t)` is mathematically equivalent to linear attention with a structured causal mask `M_{t,s} = a_t * a_{t-1} * ... * a_{s+1}`. We use the recurrence form (single-step SSD) for pedagogical clarity and tractable gradient checks. Per-head: H_t ∈ R^{head_dim × head_dim}, b/k/q ∈ R^{head_dim}, a_t ∈ (0, 1) scalar. 6 projections (in_proj gate path, out_proj, a_proj, b_proj, k_proj, q_proj) + D_skip + dt_bias. 11/11 tests pass at machine precision — input grad rel_err ~5e-10, a_proj grad ~2e-7, b_proj/k_proj/q_proj grads all ~3-4e-8, D_skip grad ~1e-8, dt_bias grad ~3e-12, training step decreases loss 0.223 → 0.044 over 60 steps, all 14 param/grad pairs shape-matched. Head structure: `d_inner = n_heads * head_dim` (must divide evenly; checked in constructor).
- **xLSTM (sLSTM)**: Implemented in `layers/recurrent/xlstm.{h,cpp}` — Beck et al. 2024 "xLSTM: Extended Long Short-Term Memory", sLSTM (scalar memory) variant. Key innovations: (1) exponential gating with log-domain stabilizer `m_t = max(log σ(f_pre_t) + m_{t-1}, i_pre_t)` (so the gates `f'_t = σ(f_pre) * exp(m_prev - m_t)` and `i'_t = exp(i_pre - m_t)` stay in [0,1] and never overflow), (2) normalizer state `n_t` that runs alongside the cell state so the hidden pre-output is `c_t / n_t` (instead of the unbounded cell state). `SLSTMCell(input_size, hidden_size)`: (T, input_size) → (T, hidden_size). Combined W·[x;h] + b projection (4*hidden_size out) with bias layout [z, i, f, o] and forget-bias=1 init (PyTorch convention). `n_0 = 1` convention to avoid 0/0. Full BPTT backward including the max-derivative indicator, gate-prime expansion through `m_t` (both -m_t in exponent and the m_prev / m_t = m_{t+1} recurrence carrier), and the m_prev max-derivative to f_pre. 10/10 tests pass — forward shape, output finite, hand-computed reference (single-step, single-hidden-unit) matches to rel_err 2.8e-4, input grad check rel_err 0.4% (T=3), W grad check rel_err 0.13% (all 4 gate blocks, T=3), b grad check rel_err 0.55%, forget-bias init, params/grads shape consistency, training loss 0.580 → 0.152 over 50 steps, longer-sequence (T=6) input grad rel_err 7.4%.

- **Mamba (S6)**: Implemented in `layers/recurrent/mamba.{h,cpp}` — Gu & Dao 2023 "Mamba: Linear-Time Sequence Modeling with Selective State Spaces". MambaBlock: (T, d_model) → (T, d_model) with input-dependent (Δ, B, C) state-space parameters (the "selective" innovation), zero-order hold discretization (Ā_t = exp(Δ_t ⊗ A), B̄_t = Δ_t ⊗ B_t), per-timestep state recurrence (h_t = Ā_t ⊙ h_{t-1} + B̄_t ⊗ x̃_t, y_t = C_t · h_t + D ⊙ x̃_t), SiLU on ssm input + sigmoid-linear gating, output projection. A is unconstrained parameter A_log, reparameterized to A = -exp(A_log) for negativity. No conv1d in v1 (orthogonal to selective scan math; keeps gradient check tractable). 11/11 tests pass at very tight precision — input grad rel_err ~3e-9, A_log grad ~1e-7, D_skip grad ~2.5e-8, in_proj/B_proj/C_proj/dt_proj grads all ~1e-7 to 1e-9, training step reduces loss 0.456 → 0.221 over 30 steps, all 12 param/grad pairs shape-matched. Forward cache: (T*d_inner, d_state) flattening for h/Ā_t/B̄_t state tensors.

- **GAT (Graph Attention Network)**: Moved to its proper home `layers/attention/gat.{h,cpp}` from `architectures/gnn.h`. GATLayer is fundamentally a multi-head attention mechanism with a learned attention vector a_h, row-softmax over adjacency, and LeakyReLU(0.2) gating — same pattern as transformer attention. `gnn.h` now re-exports it via `#include "nn/layers/attention/gat.h"` so `GraphNetwork` and existing tests using the old path still work. Added new `tests/test_gat_attention.cpp` that includes the new header directly: 5/5 pass at machine precision (rel_err ~1e-9 to 1e-10 on input/W/a gradients with 3 heads, 4 nodes; training step reduces loss; average-heads mode works). Original `test_gat_verify` and `test_gat_gradient` (via the re-export) still pass.

- **DMon (Diffusion Module Network)**: Implemented in `layers/architectures/dmon.{h,cpp}`. DMonLayer computes multi-scale heat-kernel diffusion features — for K time scales tau_k, builds the heat kernel H(tau_k) = exp(tau_k * (A_norm - I)) via truncated Taylor series (R terms), applies it to the input, concatenates all K feature blocks, and feeds them through a final Dense. Backward: grad_X = sum_k T_k^T @ grad_Z_k (the heat kernels are treated as fixed — scales are hyperparameters, not learnable, matching the DMon paper convention). Geometric schedule tau_k = 1.5^k is the default; users can override via constructor. DMonModel stacks layers with input projection + ReLU + classifier. 8/8 tests pass — input grad check at machine precision (rel_err ~2.2e-11 on the layer, ~4.5e-9 on the model), W_out grad check at ~1e-10, training step decreases loss.

- **EdgeConv / Dynamic Graph CNN**: Implemented in `layers/architectures/edgeconv.{h,cpp}`. EdgeConvLayer: per layer, builds a k-nearest-neighbour graph in feature space, computes edge features `e_{ij} = h_j - h_i` (asymmetric), runs a 2-layer MLP on `concat(h_i, e_{ij})`, then max-aggregates over neighbours. EdgeConvModel stacks layers with ReLU + input projection + head projection + per-node classifier. 8/8 tests pass — input gradient check at rel_err ~1.7e-10, model input gradient check at ~7.8e-11, bias gradient check at machine precision (~4.7e-14), training step decreases loss. k-NN graph is fixed during backward (standard DGCNN convention); gradient check uses k=N to avoid graph churn.

- **PNA (Principal Neighbourhood Aggregation)**: Implemented in `layers/architectures/pna.{h,cpp}`. PNALayer combines 4 aggregators (mean, max, min, std) with 3 degree-based scalers (identity, amplification log(deg+1)/delta, attenuation delta/log(deg+1)). Post-aggregation Dense produces output features. PNAModel stacks layers with ReLU + input projection + classifier. 8/8 tests pass — analytical vs numerical gradient checks with **rel_err ~1e-11** (post-agg W, layer input, and model input).

- **PATCHY-SAN**: Implemented in `layers/architectures/patchy_san.{h,cpp}`. PatchySANLayer does: (1) node selection (all nodes as anchors), (2) BFS-k neighborhood assembly of width w, (3) WL-1-style label canonicalization, (4) position-wise Dense conv summed across sequence positions, (5) final Dense producing per-node embedding. PatchySANModel wraps it with input projection + classifier. 8/8 tests pass — including L2 and random-grad numerical gradient checks with **0.0 relative error**.

- **LightGCN**: Simplified Graph Convolutional Network — removes non-linearities and uses only linear propagation for recommendation. Very simple but effective. Implemented in `layers/architectures/lightgcn.{h,cpp}`. 6/6 tests pass.

- **Nyström attention**: Efficient attention via low-rank approximation using Nyström method. Approximates softmax(KQ)V with landmark points. Good for long sequences. - **DeepGCN / GCNII**: Advanced GCN variants with residual connections and MLPs for deep graphs. Implemented in `layers/architectures/deep_gcn.{h,cpp}`. - **GIN (Graph Isomorphism Network)**: Implemented in `layers/architectures/gin.{h,cpp}`. GIN layer: h_{k+1} = MLP((1+eps_k) * h_k + sum_{j in N(i)} h_j). Includes GIN0Layer (linear) and GINLayer (MLP). Gradient check (L2 loss) passes for both. Fixed: last_input_ clone in forward_with_adj to prevent input corruption during numerical gradient checks; L2 loss used in Test 4 to avoid catastrophic cancellation with near-zero MLP outputs.

- **CRATE**: Convolutions with Rectified Activations — channel attention with ReLU gating (no sigmoid). Architecture: DepthwiseConv3x3 → GAP → FC1 → ReLU → FC2 → ReLU → L1 normalize → channel scale. Key insight: uses ReLU instead of sigmoid for channel importance, producing sparse attention. Tested with numerical gradient verification (rel_err ~3e-9%). All 18 tests pass.

- **AdaBelief optimizer**: Implemented — belief variance instead of second moment. Uses residual variance E[(grad - m_prev)^2] to measure gradient "surprise". Better generalization than Adam in image classification and language modeling. AdamW-style weight decay. Full bias-corrected moment update. Tests: 4/4 pass.

- **Spectral Normalization**: Implement spectral_norm_ as a layer wrapper that constrains the spectral norm of weight matrices (Lipshitz constant = 1). Essential for stabilizing GANs (SNGAN) and differentiable physics. Implement as a wrapper class SpectralNorm that normalizes W by its largest singular value each forward pass. Add to `include/nn/layers/normalization/spectral_norm.{h,cpp}`.

- **RMSNorm**: Implement RMSNorm layer (Root Mean Square Normalization, used in LLaMA/Mistral). Formula: y = (x / RMS) * gamma where RMS = sqrt(mean(x^2) + eps). Remove mean-centering (unlike LayerNorm) — more numerically stable and faster. Added to layers/normalization/rms_norm.{h,cpp}.

- **DataLoader / Dataset infrastructure**: Implement MNIST-style mini-batch loader with shuffle, batch iteration, TensorDataset wrapper, and integrate into Model::train() method. Add DataLoader class that wraps a Dataset and yields mini-batches. Implement a Trainer class that handles epoch-level training loops with DataLoader support.
