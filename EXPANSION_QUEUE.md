## Ideas

- **Forward-Forward Algorithm (FFA) layer** — Hinton 2022 "The Forward-Forward Algorithm: Some preliminary investigations" (https://www.cs.toronto.edu/~hinton/FFA.pdf). Replaces backprop with two forward passes (one on positive data with label="real", one on negative data with label="fake"); each layer has its own local loss based on the sum of squared activations exceeding a threshold. The "FFLayer" would be a wrapper around an existing block that (a) injects label information as a one-hot bias, (b) computes the layer-local "goodness" loss, and (c) computes the local gradient analytically. Two training modes: greedy layer-wise, or end-to-end with shared optimizer. A nice "alternative to backprop" pedagogical addition.

- **FlashAttention-2 / FlashAttention-3 forward-only** — pure linear-algebra flash attention without full softmax-backward through the HBM. Useful as a forward reference / benchmark, not full BPTT. (De-prioritized: existing `FlashAttentionLayer` already implements the tile-based online softmax algorithm — same core math. Future work on FA-3 would be quantization / fp8, not a separate forward-only reference.)

- **Mixture of Depths (MoD)** — Raposo et al. 2024 "Mixture-of-Depths: Dynamically allocating compute in transformer-based models" (https://arxiv.org/abs/2404.02258). Implemented in `layers/architectures/mixture_of_depths.{h,cpp}`. Per-token routing: each token independently decides whether to go through the heavy transformer sub-layer (process) or be passed through as identity (skip). Three classes: `MoDLayer` (top-k sigmoid router + masked inner sub-layer), `MoDBlock` (pre-LN → FFN chain → pre-LN → MoDLayer-wrapped refinement → residual), `MoDModel` (stack of MoDBlocks + classifier). Router uses a per-token sigmoid over a single logit computed via `router_logits = X @ W_router` (Dense convention). Top-k by logits determines which tokens get the inner sub-layer applied; the rest are skipped via a hard 0/1 mask. Aux load-balancing loss `L_aux = alpha * n * (mean(mask) - capacity_factor)^2` is the only gradient path back into the router (the top-k mask is treated as non-diff, matching the SparseMoE convention). Full BPTT including: (1) the residual gradient path (`d_input += grad_output` since `y = x + mask * sub_out`), (2) the masked sub-layer gradient (`grad_sub_out = grad_out * mask` — unselected rows get zero), (3) the inner block's full backward through MoDLayer, (4) the router backward via aux loss through sigmoid derivative, (5) the W_router/b_router Dense-style gradient chain. **Bug-fix history (this run):** (1) Initial test had `mask.rows=4088152671` corruption — root cause was constructor initializer-list order mismatched member declaration order (mask_ default-initialized after grad_b_router_, but `W_router_` was initialized first in the init list, so the compiler reordered → layout drifted at -O2). Fixed by matching init list to declaration order. (2) `cap < 1 → cap = 1` clamp meant capacity_factor=0 still routed 1 token. Fixed by only enforcing the floor when `capacity_factor_ > 0`. Mutation-tested: removing the residual contribution in backward → input grad rel_err=0.98 (caught); removing the mask in `grad_sub_out = grad_out * mask` → inner-weights grad rel_err=1.87 (caught). 19/19 tests pass at machine precision: MoDLayer forward shape (n=5, d=3, cap=0.5), output finite, capacity selection exact (4 of 8 tokens at cap=0.5), input grad rel_err 5.7e-11, W_router grad rel_err 0.0 (aux-loss gradient is uniform → exact), inner.weights grad rel_err 2.6e-11, capacity_factor=1.0 all tokens selected, capacity_factor=0.0 output == input exactly (max diff 0.0), aux loss non-negative, MoDBlock forward shape, MoDBlock input grad rel_err 1.3e-10, MoDBlock training reduces loss 60%, MoDModel forward shape, MoDModel training reduces loss 94% (over 60 steps), total aux loss aggregates correctly across blocks, capacity_factor clamped to [0,1], single-token (n=1) capacity behaves correctly, 4 param/grad pairs shape-matched, different capacity_factor values (0.25/0.5/0.75) all forward finite with correct selection counts. - **Multi-Head Latent Attention (MLA)** — DeepSeek-AI 2024 "DeepSeek-V2: A Strong, Economical, and Efficient Mixture-of-Experts Language Model" (https://arxiv.org/abs/2405.04434). Implemented in `layers/attention/mla.{h,cpp}`. The core trick: instead of computing/storing the full K and V tensors of shape (n, d_model), MLA compresses them into a SHARED low-rank "latent" `c_KV` of shape (n, d_c) with d_c << d_model. The compressed latent is what gets cached during inference, giving O(n · d_c) KV cache memory instead of O(n · d_model). For the Q side, the input is also down-projected into a separate `c_Q` latent then per-head up-projected. The shared `c_KV` is the "latent" that K and V both read from — the backward correctly accumulates gradient to W_dkv from BOTH the K branch and the V branch (the shared-latent coupling trick that makes MLA work). Three classes: `MLAAttention` (single multi-head attention with shared c_KV latent), `MLABlock` (pre-LN → MLA → residual → pre-LN → GELU FFN → residual, same shape as GQABlock), `MLAModel` (stack of MLABlocks + per-token classifier). 6 weight matrices: shared W_dq (d × d_c), shared W_dkv (d × d_c), per-head W_uq/W_uk/W_uv (d × d_c each, stacked along head dim), W_o (d × d). Total params = 5·d·d_c + d², which beats standard MHA's 4·d² when d_c < 3d/5. Full BPTT including: (1) the shared-W_dkv dual-source gradient (BOTH K and V branches contribute — caught by mutation test: removing the dV→d_c_KV contribution broke the input grad to rel_err=1.0 and W_dkv grad to rel_err=1.0), (2) the per-head softmax row-backward with the leading `A` factor (`dS = A * (dA - row_sum(dA*A))`), (3) the per-head dQ/dK/dV with `scale_ = 1/sqrt(head_dim)`, (4) the per-head up-projection gradients (W_uq, W_uk, W_uv via the standard Dense convention), (5) the shared c_Q/c_KV accumulation across heads, (6) the W_dq/W_dkv gradients and the input gradient chain through the shared down-projections. **Bug-fix history (this run):** The first draft had a critical bug in the MLABlock backward — `d_res1 += d_z2` was wrong: `d_z2` from `ffn_fc1.backward()` is `dL/dz2` (gradient w.r.t. fc1's input), not `dL/d(res1)`. The correct chain is `d_res1_from_ln2 = ln2.backward(d_z2)` then `d_res1_total = grad_output + d_res1_from_ln2`. Symptom: block input grad rel_err=0.9 (basically the analytical was the negative of the numerical). After fix: block input grad rel_err 2.5e-8 (machine precision). 11/11 tests pass at machine precision: forward shape (n=4, d=8, H=2, d_c=3), output finite, input grad rel_err 5.6e-8, W_dq rel_err 7.4e-6, W_uq 4.6e-6, W_dkv 4.9e-8, W_uk 1.5e-5, W_uv 2.6e-7, W_o 2.5e-8 (per-head up-projections show slightly higher rel_err than the shared down-projections, which is expected — the per-head path goes through one more softmax row-backward), MLABlock forward shape, MLABlock input grad 2.5e-8 (machine precision), MLAModel training loss reduction 0.0474 → 0.0014 (97%), single-head (H=1) input grad 7.2e-9, param count check (5·d·d_c + d² = 576, vs 4d² = 1024 for MHA — confirms the latent memory savings), 6/6 param/grad shape pairs, d_c sweep (1, 2, 4, 6) all forward finite with correct shape. - **FNet** (Lee-Thorp et al. 2021 "FNet: Mixing Tokens with Fourier Transforms", https://arxiv.org/abs/2105.03824): Implemented in `layers/attention/fnet.h`. The key insight: replace the O(n²) self-attention matrix multiply with a *linear* 2D Fourier transform applied to the (n_tokens, d_model) tensor — `mix = Re(FFT2D(x))`, then a per-token Dense `out = mix @ W^T + b`. Because FFT is a linear operator, it's trivially differentiable through its inverse (the adjoint of the Re(FFT) operator). Three classes: `FNetLayer` (single Fourier mixing + per-token Dense), `FNetBlock` (pre-LN → FNet → residual → pre-LN → GELU FFN → residual, with d_model→ffn_dim→d_model FFN), `FNetModel` (stack of FNetBlocks + per-token classifier head). Naive O(N²) 2D DFT used (no FFT optimization) for clarity and gradient-check tractability — for pedagogical/reference use rather than production. Full BPTT including: (1) the linear-operator gradient of `Re(FFT)` (the "cos cos − sin sin" kernel expansion — `dx[r,c] = sum_{k,l} dmix[k,l] (cos(2πkr/R)cos(2πlc/C) − sin(2πkr/R)sin(2πlc/C))`), (2) the per-token Dense backward (W_dense gradients via `outer sum_t grad_out[t,j] * mix[t,k]`), (3) the FNetBlock residual double-path (fourier residual + FFN residual both contribute to d_x), and (4) the GELU exact derivative. **Bug-fix history (this run):** Initial implementation of `ifft2d_real` had three separate bugs in the backward kernel — (1) included the 1/(R*C) inverse-FFT normalization that doesn't belong in the gradient of `Re(FFT)`, (2) used the wrong sign convention on the exponent (used `+2πi` instead of `−2πi` — coincidentally the cos part is even so this was masked), (3) most critically, dropped the `sin*sin` term from the cos product-to-sum expansion (cos(2πθ) = cos_r cos_c − sin_r sin_c, not just cos_r cos_c). - **Slot Attention**: Implemented in `layers/attention/slot_attention.{h,cpp}` — Locatello et al. 2020 "Object-Centric Learning with Slot Attention" (https://arxiv.org/abs/2006.15055). The core trick is a *double softmax* over both axes of the (K slots, N inputs) attention matrix: first softmax over slots (each input distributes over K competing slots — slot competition), then softmax over inputs (each slot distributes its attention budget). After both softmaxes, each input is softly assigned to exactly one slot while each slot competes for its share of inputs. Three classes: `SlotAttention` (single slot-attention block with T iterations of: Q·K^T → double-softmax → V weighted avg → stateless GRU update → residual MLP refine), `SlotAttentionBlock` (per-slot FFN residual refinement block — operates on slots (K, D) → slots (K, D)), `SlotAttentionModel` (input projection → SlotAttention → n_blocks refinement blocks → per-slot classifier). Default T=3 iterations. Stateless per-slot GRU cell (input = updates, hidden = slots) implemented inline with weights shared across the K slots. Full BPTT including: (1) the double-softmax gradient chain where d_logits gets contributions from BOTH the col-softmax backward and the row-softmax backward through attn1, (2) the per-iteration iterated unrolling (d_slot at iteration t flows forward from d_slot at iteration t+1 PLUS the residual-MLP contribution, with mu participating only at t=0), (3) the stateless GRU backward (gates via σ, candidate via tanh, hidden state via r*s = rh), (4) per-slot FFN residual block with LN, (5) input projection backward with the correct Dense(in, out) shape convention. **Bug-fix history (this run):** The prior session left a broken slot_attention.{h,cpp} file with explicit "let me redo below" comments, a typo (`kkk_kk = kk` causing a compile error), and a half-implemented backward that returned `d_slots` immediately. - **RoPE-on-K-and-V**: Implemented in `layers/attention/rope_v.{h,cpp}` — extension of the existing RoPE class (which rotates only Q/K) that also rotates the V tensor with the *same* per-position rotation. Same math, same cache layout (`cos_cache`/`sin_cache` of shape `[max_seq_len, dim]`), but now applied to all three of Q/K/V in a single `forward(q, k, v)` call. - **Modern Hopfield Attention / HopfieldGAT**: Implemented in `layers/attention/hopfield.{h,cpp}` — Ramsauer, Schmid, Lehner, Rerec, Hochreiter 2020 "Hopfield Networks is All You Need" (https://arxiv.org/abs/2008.02217). The key insight: with the modern Hopfield energy function, the fixed-point retrieval rule `x* = P^T softmax(β · P · x)` is mathematically equivalent to a transformer attention layer with K = V = P (the stored "memory patterns") and a learnable inverse temperature β. So a Hopfield retrieval layer is *strictly more general* than self-attention: it (a) decouples pattern count m from sequence length n, and (b) learns the right temperature for the data. Three classes: `HopfieldAttention` (single multi-head attention with stored pattern memory), `HopfieldBlock` (pre-LN → HopfieldAttention → residual → pre-LN → GELU FFN → residual), `HopfieldModel` (stack of blocks + per-token classifier). The layer stores m learnable patterns `P ∈ R^{m × d_model}` plus `W_q, W_o` projections, a learnable inverse temperature `β = softplus(β_log_)` (positive reparam, initialized so β = 1/√d to match transformer attention scaling), and a per-pattern bias `b_p`. Forward: `Q = X @ W_q^T`, `attn = softmax(β · Q @ P^T + b_p)`, `out_pre = attn @ P`, `out = out_pre @ W_o^T + b_o`. Full BPTT including: (1) softmax row-backward, (2) the β chain through softplus + sigmoid (the dL/dβ_path comes from `Q @ P^T` and then dβ/dβ_log = sigmoid(β_log)), (3) the dP accumulator from BOTH the attn@P path AND the β·Q@P^T path, (4) the dQ path with dQ(t, j) = β · sum_s d_logits(t, s) · P(s, j), and (5) the W_q / W_o Dense-convention gradients. **Bug-fix history (this run):** (1) The W_q gradient had the OUT/IN dimensions swapped: was computing `dW[j, k] = sum_t dQ(t, k) * X(t, j)` instead of the correct `dW[j, k] = sum_t dQ(t, j) * X(t, k)`. - **MultiHead-Conv attention**: Implemented in `layers/attention/conv_attention.{h,cpp}` — Yang et al. 2023 "Convolutional Self-Attention Networks" (https://arxiv.org/abs/2308.01462). This adds a strong local-inductive bias to attention (similar in spirit to the convolutional bias of CNNs) and lets Q/K/V "see" neighbouring positions before computing the attention scores. Per head h: `Q_h = Conv1D_q(X) ∈ R^{n × head_dim}`, `K_h = Conv1D_k(X)`, `V_h = Conv1D_v(X)`, then standard scaled dot-product attention. Default kernel_size=3 with pad=1 ("same") so seq_len is preserved. Multi-head: d_model = num_heads * head_dim, channel split. - **Tree-LSTM (Child-Sum)**: Implemented in `layers/architectures/tree_lstm.{h,cpp}` — Tai, Socher, Manning 2015 "Improved Semantic Representations From Tree-Structured Long Short-Term Memory Networks", §2.2 (Child-Sum Tree-LSTM, the canonical dependency-tree variant). Per-node Child-Sum Tree-LSTM with per-child forget gates — the key innovation vs the chain LSTM is that each child of a node gets its own forget gate (so the network can learn which sibling's cell state to keep). Architecture: `TreeLSTM(in_dim, hidden_size)`. - **mLSTM**: Implemented in `layers/recurrent/mlstm.{h,cpp}` — Beck et al. 2024 "xLSTM: Extended Long Short-Term Memory", mLSTM (matrix memory) variant — completes the sLSTM pair from the previous entry. mLSTM replaces the scalar cell c_t with a matrix C_t ∈ R^{d×d} updated by the covariance rule `C_t = f'_t · C_{t-1} + i'_t · outer(v_t, k_t)` and tracks a matching matrix normalizer `N_t = f'_t · N_{t-1} + i'_t · outer(k_t, k_t)`. The hidden pre-output is `(C_t · q_t) / max(1, q_t^T N_t q_t)` — a normalized linear-attention-style retrieval (the "denominator trick" with exponential decay). Exponential gating (m_t stabilizer, f'_t, i'_t) and combined W·[x;h] + b projection (6*hidden_size out, layout [q, k, v, i, f, o]) follow the same convention as sLSTM, with bias init for forget-gate = 1.0. Full BPTT including: (1) the C/N outer-product chain (d_k via (dC^T v) and (dN^T k), d_v via sum_j dC[i,j] * i'[j] * k[j], d_i' via k[j] * (dC^T v)[j], d_f' via the C_{t-1} and N_{t-1} carriers), (2) the normalizer path (dN from h_norm, d_q gets 2 * d_h_norm * N q when h_norm > 1, h_norm == 1 clamp), (3) the stabilizer m_t (indicator max + carriers from f'/i' -m_t in exponent), and (4) the f'-recurrent state carry (g_C(t) += f'[j] * g_C(t+1) and g_N(t) += f'[j] * g_N(t+1), per-column scale because f' is per-channel-j). 11/11 tests pass at machine precision — forward shape, output finite, hand-computed reference (single-step, hidden=1) matches to rel_err 0, input grad check (T=2) rel_err ~0.12% max, input grad check (T=3) ~0.29% max, W grad check (all 6 blocks, 24 entries) rel_err ~1.15e-5, b grad check (q,k,v,i,o blocks) rel_err ~2.5e-6, forget-bias init, params/grads shape consistency, training loss 0.468 → 0.066 over 50 steps, matrix state Frobenius norms confirm C_T and N_T are accumulating. - **RetNet**: Implemented in `layers/recurrent/retnet.{h,cpp}` — Sun et al. 2023 "Retentive Network: A Successor to Transformer for Large Language Models". Per-head recurrent retention in the single-step (inference-time) form. Math: per head h, S_t^(h) ∈ R^{head_dim × head_dim}; S_t = diag(γ_h)·S_{t-1} + outer(k_t, v_t), o_t = S_t · q_t; Q/K get xPos pair rotation (Q by +angle, K by -angle, R(θ)=[[c,-s],[s,c]]) so Q·K captures relative position; V goes in raw. γ ∈ (0,1)^d is `sigmoid(gamma_raw)` (smooth reparam, no clipping). - **RWKV**: Implemented in `layers/recurrent/rwkv.{h,cpp}` — Peng et al. 2023 "RWKV: Reinventing RNNs for the Transformer Era", time-mixing block (the WKV recurrence). Canonical RWKV-4 single-block per-step math: token-shift mixing `x_in_t = μ ⊙ x_t + (1-μ) ⊙ x_{t-1}` for r/k/v; 3 projections W_r/W_k/W_v to produce r_pre/k_pre/v_pre; per-channel WKV recurrence `p_t[i] = a[i]·p_{t-1}[i] + k_pre_t[i]·v_pre_t[i]` with `a[i] = exp(-exp(log_w[i]))` (the canonical RWKV decay parameterization, ensures a ∈ (0,1)); diagonal bonus term `wkv_t[i] = p_t[i] + (exp(u[i])-1)·k_t[i]·v_t[i]`; receptance-gated output `o_t = sigmoid(r_pre_t) ⊙ wkv_t`. State is d-dim (the p-vector), giving O(d) per-step compute and O(d) memory — the O(1)-per-step state that makes RWKV O(1) inference. Full BPTT including the p-recurrence carrier (`grad_p_next[i] = grad_p_curr[i] * a[i]`), the a[i] → log_w[i] chain through the double exp, the bonus u[i] → exp(u[i])-1 chain, the k/v element-wise kv product, and the μ-mix (with x_{t-1} carry-forward). 11/11 tests pass at machine precision — input grad rel_err ~1e-10, W_k/W_v grads ~5e-11, W_r grad ~6e-9, log_w grad ~1e-7 (the double-exp compresses magnitude), u grad ~1e-9, μ grads ~1e-10, training step decreases loss 41.5% over 30 steps, all 11 param/grad pairs shape-matched.

- **Mamba-2 / SSD**: Implemented in `layers/recurrent/mamba2.{h,cpp}` — Dao & Gu 2024 "Transformers are SSMs: Structured State Space Duality". - **xLSTM (sLSTM)**: Implemented in `layers/recurrent/xlstm.{h,cpp}` — Beck et al. 2024 "xLSTM: Extended Long Short-Term Memory", sLSTM (scalar memory) variant.
