# Hawk (RG-LRU) Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a `Hawk` layer to the library, following De et al. 2024 "Griffin: Mixing Gated Linear Recurrences with Local Attention for Efficient Language Models" (https://arxiv.org/abs/2402.19427). Implement the canonical **Real-Gated Linear Recurrence Unit (RG-LRU)** that is the core of the "Hawk" block.

**Architecture:** Per-channel linear recurrence with input-dependent decay and input gating. The recurrence is a single scalar state per channel (no matrix-valued state like GLA/DeltaNet/RetNet, no multi-head). This makes it the simplest of the gated-linear-recurrence family. The "weight tying" trick `W_x = W_gate` from the original paper is preserved (a single input projection produces both the input projection and the gate).

**Tech Stack:** Existing `Layer`, `Tensor`, `Dense` primitives. Files go in `include/nn/layers/recurrent/`. Tested with numerical gradient checks at machine precision.

## Background

**Paper context.** The Griffin paper (De et al. 2024) introduces a hybrid architecture that interleaves **RG-LRU recurrent blocks** ("Hawk") with **local attention** blocks ("Griffin"). For language modeling, the Hawk/Griffin stack matches Mamba quality at similar parameter count while being architecturally simpler. The RG-LRU is the gated-linear-recurrence cousin of Mamba's SSM — but unlike Mamba, the recurrence is a single scalar per channel (no matrix state), so the gradient check is tractable and the math is transparent.

**Math (per channel `c`, per time step `t`):**

```
gate_input_t  = W_x · x_t + b                                  in R^d          (1)
gate_t[c]     = sigmoid(gate_input_t[c])                       in (0, 1)       (2)
input_proj_t[c] = gate_t[c] * x_t[c]                                       (3)
λ_t[c]        = exp(-exp(log_a_raw[c]) * exp(gate_input_t[c]))  in (0, 1)     (4)
h_t[c]        = λ_t[c] * h_{t-1}[c] + sqrt(1 - λ_t[c]^2) * input_proj_t[c]  (5)
y_t[c]        = h_t[c]                                                    (6)
y_t           = W_o · y_t + b_o                                            (7)
```

**Why this addition.** The library already has:

- Linear attention variants: GLA, DeltaNet, RetNet (all matrix-state recurrences)
- State-space variants: Mamba, Mamba-2, H3, RWKV (diagonal-SSM recurrences)
- "Old-school" recurrent: LSTM, GRU, RNN, xLSTM, mLSTM

What's *missing* is the scalar-state gated linear recurrence — the simplest possible gated linear RNN with a single scalar hidden state per channel. It's the natural counterpart to the matrix-valued GLA and the diagonal-SSM Mamba, and it's the core of the Griffin paper (one of the most-cited 2024 papers for efficient LM training).

**Distinguishing Hawk from neighbors:**

| Model | State | Decay | Gate |
|---|---|---|---|
| GLA (Yang 2023) | matrix (d²) | per-head scalar α | sigmoid |
| DeltaNet (Yang 2024) | matrix (d²) | none (delta rule) | scalar α by construction |
| RetNet (Sun 2023) | matrix (d²) | fixed γ | none |
| RWKV (Peng 2023) | scalar (d) | per-channel fixed `a[i]` | sigmoid receptance |
| Mamba-2 (Dao 2024) | matrix (d²) | per-timestep scalar | sigmoid ×SiLU gate |
| **Hawk (De 2024)** | **scalar (d)** | **per-channel × per-step λ_t[c]** | **sigmoid input gate** |

The Hawk recurrence is the simplest gated linear RNN with a single scalar hidden state and input-dependent per-channel decay. It's the conceptual "atomic" sequence layer that everything else builds on.

// include/nn/layers/recurrent/hawk.h
#ifndef HAWK_H
#define HAWK_H

#include "../../core/layer.h"
#include <vector>
#include <cmath>

// ============================================================================
// Hawk (RG-LRU) — De et al. 2024
//   "Griffin: Mixing Gated Linear Recurrences with Local Attention for
//    Efficient Language Models"
//   https://arxiv.org/abs/2402.19427
//
// ============================================================================
//
// The Real-Gated Linear Recurrence Unit (RG-LRU) is the central building block
// of the Griffin/Hawk model. It is a scalar-state gated linear RNN:
//
//   Forward per channel c, per time step t:
//     gate_input_t  = W_x · x_t + b                                    in R^d
//     gate_t[c]     = sigmoid(gate_input_t[c])                          in (0, 1)
//     input_proj_t[c] = gate_t[c] * x_t[c]
//     λ_t[c]        = exp(-exp(log_a_raw[c]) * exp(gate_input_t[c]))   in (0, 1)
//     h_t[c]        = λ_t[c] * h_{t-1}[c]
//                    + sqrt(1 - λ_t[c]^2) * input_proj_t[c]
//     y_t[c]        = h_t[c]
//     y_t           = W_o · y_t + b_o
//
// State: scalar h ∈ R^d (one hidden per channel). No matrix state. This is
// the simplest of the gated-linear-recurrence family.
//
// Parameters (all learnable):
//   W_x (d, d), b_x (1, d)        — input projection (also produces the gate)
//   log_a_raw (1, d)              — unconstrained per-channel decay base
//   W_o (d, d), b_o (1, d)        — output projection
//
// Initialization convention (Griffin paper, §3.1):
//   * W_x: xavier-uniform (Dense default).
//   * b_x: zero.
//   * log_a_raw: -3.0 init → exp(log_a_raw) ≈ 0.05, so the inner exponent
//     starts small (λ_t ≈ exp(-0.05·exp(gate_input)) which is close to 1
//     for negative gate inputs and decays slower for positive ones).
//   * W_o: xavier-uniform.
//   * b_o: zero.
//
// Shape convention: forward takes (T, d) and returns (T, d). The state is
// cached as (T+1, d) (row 0 = initial state 0) for BPTT.
// ============================================================================

class HawkBlock : public Layer {
public:
    // d: input/output feature dim (must satisfy d > 0)
    explicit HawkBlock(size_t d);

    Tensor forward(const Tensor& input) override;
    Tensor backward(const Tensor& grad_output, double /*learning_rate*/) override;
    void update_weights(double learning_rate) override;
    void zero_grad() override;
    std::vector<Tensor*> parameters() override;
    std::vector<Tensor*> gradients() override;
    Tensor get_weights() const override { return W_x.weights; }
    Tensor get_gradients() const override { return W_x.grad_weights; }
    std::string name() const override { return "HawkBlock"; }

    // Accessors for tests
    size_t d() const { return d_; }

    // ---- Public parameters ----
    size_t d_;
    Dense W_x;              // (d, d) — input projection (also produces gate)
    Tensor log_a_raw;       // (1, d) — unconstrained decay base
    Dense W_o;              // (d, d) — output projection

    // Hidden gradient buffers
    Tensor grad_log_a_raw_; // (1, d)

private:
    // BPTT cache
    Tensor last_input_;         // (T, d) — cloned
    Tensor last_gate_input_;    // (T, d) — W_x * x + b_x
    Tensor last_gates_;         // (T, d) — sigmoid(gate_input)
    Tensor last_lambda_;        // (T, d) — exp(-exp(log_a_raw) * exp(gate_input))
    Tensor last_h_;             // (T+1, d) — h_t (row 0 = 0)

    static double sigmoid(double x) {
        if (x >= 0.0) return 1.0 / (1.0 + std::exp(-x));
        double ez = std::exp(x);
        return ez / (1.0 + ez);
    }
};

#endif // HAWK_H
```

Tensor HawkBlock::forward(const Tensor& input) {
    if (input.cols != d_) {
        throw std::invalid_argument("HawkBlock::forward: input cols must be d");
    }
    const size_t T = input.rows;
    last_input_ = input;  // copy
    last_gate_input_ = W_x.forward(input);  // (T, d)
    last_gates_ = Tensor(T, d_);
    last_lambda_ = Tensor(T, d_);
    last_h_ = Tensor(T + 1, d_);
    for (size_t i = 0; i < d_; ++i) last_h_[0][i] = 0.0;  // h_0 = 0

    Tensor hidden(T, d_);  // pre-output hidden state
    for (size_t t = 0; t < T; ++t) {
        for (size_t c = 0; c < d_; ++c) {
            const double gi = last_gate_input_[t][c];
            const double g = sigmoid(gi);
            last_gates_[t][c] = g;
            // λ_t[c] = exp(-exp(log_a_raw[c]) * exp(gi))
            // Note: for numerical stability, clamp the exponents.
            const double a_base = std::exp(log_a_raw[0][c]);  // > 0
            const double exp_gi = std::exp(gi);  // > 0
            const double lam = std::exp(-a_base * exp_gi);
            last_lambda_[t][c] = lam;
            // input_proj_t = g_t * x_t
            const double inp = g * last_input_[t][c];
            // h_t = λ_t * h_{t-1} + sqrt(1 - λ_t^2) * input_proj_t
            const double decay_new = std::sqrt(1.0 - lam * lam);
            const double h_prev = last_h_[t][c];
            const double h_new = lam * h_prev + decay_new * inp;
            last_h_[t + 1][c] = h_new;
            hidden[t][c] = h_new;
        }
    }
    // Output projection
    Tensor y = W_o.forward(hidden);
    return y;
}
```

```cpp
Tensor HawkBlock::backward(const Tensor& grad_output, double /*learning_rate*/) {
    if (grad_output.cols != d_) {
        throw std::invalid_argument("HawkBlock::backward: grad_output cols must be d");
    }
    const size_t T = grad_output.rows;
    // 1. Output projection backward: grad_h from grad_y
    Tensor grad_h = W_o.backward(grad_output, 0.0);  // (T, d)
    // 2. We need dL/d(gate_input) and dL/d(input).
    // From step 5: h_t = λ_t * h_{t-1} + sqrt(1-λ²) * input_proj_t
    //   dL/d(input_proj_t) = sum_{s >= t} dL/d(h_s) * sqrt(1-λ_s²) * Π_{t<u<=s} λ_u
    //   dL/d(λ_t) = sum_{s >= t} dL/d(h_s) * (h_{t-1} - λ_t/sqrt(1-λ_t²) * input_proj_t) * Π_{t<u<=s} λ_u
    // We run backward in reverse: at step t, the "remaining" gradient from steps >= t is what matters.
    // Go-and-see: track gh_carrier[c] = dL/d(h_t) carried forward.
    Tensor gh_carrier(T, d_);
    for (size_t t = 0; t < T; ++t)
        for (size_t c = 0; c < d_; ++c) gh_carrier[t][c] = grad_h[t][c];

    // Wait — gh_carrier[t] should be the gradient at h_t considering future states' contributions.
    // dL/d(h_t) = grad_h[t] + sum_{s>t} dL/d(h_s) * dL(h_s)/dL(h_t)
    //   dL(h_s)/dL(h_t) = Π_{t<u<=s} λ_u, plus the derivatives w.r.t. (input_proj, λ) at s
    //   that came THROUGH h_{s-1} not h_t directly.
    // The recurrence is h_t = λ_t * h_{t-1} + bias_t(input_proj_t, λ_t)
    //   where bias_t = sqrt(1-λ_t²) * input_proj_t.
    // The recurrent chain: dL/d(h_{t-1}) += dL/d(h_t) * λ_t.
    //   (via the h_{t-1} → h_t path)
    // Plus the contributions from grad_h[t] (the "direct" gradient at h_t).
    // So gh_carrier[t] = grad_h[t] + ...forward-from-future...
    // Easier: pure forward BPTT.
    //   Init: gH[T] = 0 (no step beyond T contributes)
    //   For t = T-1 ... 0: gH[t] = grad_h[t] + gH[t+1] * λ_{t+1}
    //                   (the gH[t+1] * λ_{t+1} is the carry from the recurrence)
    // Plus: dL/d(input_proj_t) = gH[t] * sqrt(1-λ_t²)  (well, ALMOST — the RECUR at t uses h_{t-1}, not input_proj_t)
    // YES: gH[t] is the gradient at h_t; dL/d(input_proj_t) = gH[t] * sqrt(1-λ_t²).
    //   dL/d(λ_t) = gH[t] * (h_{t-1} - λ_t * input_proj_t / sqrt(1-λ_t²))
    //   dL/d(h_{t-1}) += gH[t] * λ_t  → carry to gH[t-1]
    //   dL/d(gate_input_t) via the gate path and the λ path:
    //     gate_t = sigmoid(gi_t); input_proj_t = gate_t * x_t
    //     dL/d(gate_t) = dL/d(input_proj_t) * x_t
    //     dL/d(gi_t) via gate = dL/d(gate_t) * gate_t * (1 - gate_t)
    //     λ_t = exp(-exp(log_a_raw) * exp(gi_t))
    //     dL/d(gi_t) via λ = dL/d(λ_t) * λ_t * (-exp(log_a_raw) * exp(gi_t))
    //     dL/d(gi_t) = dL/d(gate_t) * gate_t * (1 - gate_t) + dL/d(λ_t) * λ_t * (-exp(log_a_raw) * exp(gi_t))
    //   dL/d(x_t) = dL/d(gate_t) * x_t's contribution... wait, x_t contributes directly:
    //     input_proj_t = gate_t * x_t, so dL/d(x_t) += dL/d(input_proj_t) * gate_t
    //   Plus x_t feeds the W_x projection (which gives both gate_input and the λ signal).
    //   Actually W_x is the input projection, so dL/d(x_t) flows through W_x.backward.

    // OK strategy: compute gH first, then use it to fill dL/d(input_proj), dL/d(λ), dL/d(gate_input).
    // Then dL/d(x_t) = dL/d(gate_input_t) (via W_x backward) + dL/d(input_proj_t) * gate_t (direct path).
    // Wait — dL/d(input_proj_t) feeds back into x_t: input_proj_t = gate_t * x_t, so dL/d(x_t) += dL/d(input_proj_t) * gate_t.
    // But input_proj_t uses the SAME x_t as the W_x projection. So we need to add that to the W_x backward contribution.
    //
    // Cleaner: treat input_proj and the gate as separate paths to x_t.

    // For now, structure as:
    //   - Compute gH[T] = 0
    //   - For t = T-1 ... 0: gH[t] = grad_h[t] + gH[t+1] * λ_{t+1}
    //   - For each t:
    //     grad_input_proj_t[c] = gH[t][c] * sqrt(1-λ_t[c]²)
    //     grad_λ_t[c] = gH[t][c] * (h_{t-1}[c] - λ_t[c]/sqrt(1-λ_t²) * input_proj_t[c])
    //     grad_gate_t[c] = grad_input_proj_t[c] * x_t[c]
    //     grad_gi_t_path1 = grad_gate_t[c] * gate_t[c] * (1 - gate_t[c])
    //     grad_gi_t_path2 = grad_λ_t[c] * λ_t[c] * (-exp(log_a_raw[c]) * exp(gi_t[c]))
    //     grad_gi_t[c] = grad_gi_t_path1 + grad_gi_t_path2
    //   - dL/d(x_t) = grad_gi_t[c] (via W_x) + grad_input_proj_t[c] * gate_t[c] (direct input_proj path)
    //   - dL/d(W_x*) via W_x.backward(grad_gi_t, 0)
    //   - dL/d(log_a_raw) = sum_t grad_λ_t[c] * λ_t[c] * exp(log_a_raw[c]) * exp(gi_t[c])
    //     (the negative sign cancels between dλ/d(log_a_raw) and dλ/d(gi_t))

    Tensor gH = Tensor(T + 1, d_);
    for (size_t c = 0; c < d_; ++c) gH[T][c] = 0.0;
    for (size_t t = T; t > 0; --t) {
        for (size_t c = 0; c < d_; ++c) {
            gH[t - 1][c] = grad_h[t - 1][c] + gH[t][c] * last_lambda_[t - 1][c];
        }
    }

    Tensor grad_input_proj(T, d_);
    Tensor grad_lambda(T, d_);
    Tensor grad_gate_input(T, d_);
    Tensor grad_x(T, d_);

    for (size_t t = 0; t < T; ++t) {
        for (size_t c = 0; c < d_; ++c) {
            const double lam = last_lambda_[t][c];
            const double sqrt_term = std::sqrt(1.0 - lam * lam);
            const double inp_proj = last_gates_[t][c] * last_input_[t][c];
            const double h_prev = last_h_[t][c];

            grad_input_proj[t][c] = gH[t][c] * sqrt_term;
            // d(λ_t * h_{t-1} + sqrt_term * input_proj)/dλ_t
            //   = h_{t-1} + d(sqrt_term)/dλ * input_proj = h_{t-1} - λ/sqrt_term * input_proj
            grad_lambda[t][c] = gH[t][c] * (h_prev - lam / sqrt_term * inp_proj);
            // input_proj_t = gate_t * x_t
            const double grad_gate = grad_input_proj[t][c] * last_input_[t][c];
            // dL/d(gi_t) via gate
            const double g = last_gates_[t][c];
            const double d_gate_dgi = g * (1.0 - g);
            const double grad_gi_via_gate = grad_gate * d_gate_dgi;
            // dL/d(gi_t) via λ: λ = exp(-exp(log_a_raw) * exp(gi))
            //   dλ/d(gi) = λ * (-exp(log_a_raw) * exp(gi))
            const double a_base = std::exp(log_a_raw[0][c]);
            const double exp_gi = std::exp(last_gate_input_[t][c]);
            const double d_lam_dgi = lam * (-a_base * exp_gi);
            const double grad_gi_via_lam = grad_lambda[t][c] * d_lam_dgi;
            grad_gate_input[t][c] = grad_gi_via_gate + grad_gi_via_lam;
            // dL/d(x_t) from input_proj path: input_proj_t = gate_t * x_t
            grad_x[t][c] = grad_gi_via_gate + grad_input_proj[t][c] * g;
        }
    }

    // Now feed gate_input grad back through W_x.
    // But W_x already consumed the gate_input forward pass; we need to add the gate_input-only grad
    // to its existing W_x.grad_weights and W_x.grad_bias.
    // W_x.backward(grad_gate_input, 0) returns grad_input (full dL/d(input_to_W_x)).
    Tensor grad_x_from_Wx = W_x.backward(grad_gate_input, 0.0);  // (T, d)

    // Combine the two paths into x_t.
    Tensor grad_input(T, d_);
    for (size_t t = 0; t < T; ++t) {
        for (size_t c = 0; c < d_; ++c) {
            grad_input[t][c] = grad_x[t][c] + grad_x_from_Wx[t][c];
        }
    }

    // Accumulate grad_log_a_raw.
    for (size_t t = 0; t < T; ++t) {
        for (size_t c = 0; c < d_; ++c) {
            const double a_base = std::exp(log_a_raw[0][c]);
            const double exp_gi = std::exp(last_gate_input_[t][c]);
            // dL/d(log_a_raw) = grad_λ_t * λ_t * exp(log_a_raw) * exp(gi_t)
            //   (positive — chain: dλ/d(exp_la) = λ * (-exp(gi)), d(exp_la)/d(log_a_raw) = exp(log_a_raw))
            //   So dλ/d(log_a_raw) = λ * (-exp(log_a_raw) * exp(gi)) = -d_lam_dgi
            //   dL/d(log_a_raw) = grad_λ * dλ/d(log_a_raw) = grad_λ * (-d_lam_dgi)
            //   = -grad_λ * λ * (-exp(log_a_raw) * exp(gi)) = grad_λ * λ * exp(log_a_raw) * exp(gi)
            grad_log_a_raw_[0][c] += grad_lambda[t][c] * last_lambda_[t][c] * a_base * exp_gi;
        }
    }

    return grad_input;
}
```

## Common pitfalls

- **Numerical instability in `exp(-a_base * exp(gi))`**: clamp `exp(gi)` at e.g. 50.0 to avoid overflow when `gi` is large positive.
- **W_x backward is called twice (once via forward, once via backward)**: the `Tensor& last_input_` and `last_gate_input_` caches must be populated in forward so W_x.backward uses the right input.
- **The `:grad_x[t][c] = grad_gi_via_gate + grad_input_proj_t * g` line**: the `grad_gi_via_gate` term is the W_x contribution to x_t (because the gate path is `gate = sigmoid(W_x·x)`); the `grad_input_proj_t * g` is the direct `input_proj = gate * x_t` contribution.
- **Log-a-raw gradient sign**: `dλ/d(log_a_raw) = -dλ/d(gi)` (just a negative sign), so `grad_log_a_raw = grad_λ * (-dλ/d(gi)) = grad_λ * λ * exp(log_a_raw) * exp(gi)`. Positive.
