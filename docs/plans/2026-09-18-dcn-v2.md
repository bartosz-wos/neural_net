# Deep & Cross Network v2 (DCN-v2) Implementation Plan

> **For Hermes:** Use test-driven-development skill to implement this plan task-by-task.

**Goal:** Implement Deep & Cross Network v2 (Wang et al. WWW 2021, https://arxiv.org/abs/2008.13535, "DCN V2: Improved Deep & Cross Network and Practical Lessons for Web-scale Learning to Rank Systems") — a tabular architecture that combines an MLP ("deep tower") with a stack of explicit feature-cross layers ("cross network"), producing a final logit via a stack Dense. The cross network's v2 improvement is the **low-rank** parameterization that replaces the original O(d²) weight with two O(d·r) factors (r ≪ d), making it cheap to scale. The cross network's defining property: **each layer multiplies the original input x_0 elementwise with a learned transform of the previous layer's output, then adds the previous layer back as a residual** — this exposes explicit polynomial feature interactions of every degree that the network has layers.

**Architecture:** Four classes — (1) `CrossNetworkLayer(d, r)` — one low-rank cross layer; (2) `CrossNetwork(d, num_layers, r)` — stack of `num_layers` cross layers; (3) `DCNv2(input_dim, cross_r, deep_dims, output_dim)` — wires `CrossNetwork` + a `Dense` deep tower + a final `StackLayer` Dense; (4) `DCNv2Regression(input_dim, cross_r, cross_layers, deep_hidden, deep_layers, output_dim)` — convenience wrapper for regression/classification with sensible defaults (reuses an internal `DCNv2`).

**Math (DCN-v2 low-rank cross layer):** for input `x_0 ∈ R^{B×d}` and layer l = 1, …, L:
- `p_l = C_l · x_{l-1}`, where `C_l ∈ R^{r×d}`
- `q_l = U_l · p_l`, where `U_l ∈ R^{d×r}`
- `x_l = x_0 ⊙ q_l + x_{l-1}`  (residual + elementwise cross with the original input)

The two factors `(C_l, U_l)` together parameterize a `(d, d)` effective weight `W_l = U_l · C_l` while costing only `2·d·r` parameters (paper §3.1, Eq. 6). Setting r = d recovers the original full-rank cross (paper §3.1, "structure of cross network"). Total parameters across L layers: `2 · L · d · r`.

**Backward through one cross layer** (given `dx_l`):
- `dq = x_0 ⊙ dx_l`
- `dx_{l-1} = dx_l + C_l^T · (U_l^T · dq)`  (residual + propagated contribution)
- `dU_l = dq^T · p_l`  (treating `p_l` as activations; shape is (d, r))
- `dC_l = (U_l^T · dq)^T · x_{l-1}`  (shape is (r, d))
- Accumulate `dx_0 += dx_l ⊙ q_l` (the per-layer contribution to the input gradient)

**Deep tower:** standard MLP. `input_dim → deep_dims[0] → deep_dims[1] → … → deep_dims[-1]` using ReLU + Dense. The last deep layer's output `h_deep ∈ R^{B × deep_dims[-1]}` is concatenated with `x_L ∈ R^{B × d}` and fed into the stack Dense.

**Stack layer:** `out = W_stack · [x_L; h_deep] + b_stack`, shape `(B, output_dim)`. This is what makes DCN-v2 different from "cross OR deep": both towers see the same input and their outputs are mixed by a final dense.

**Tech Stack:** C++17, `Tensor`, `Dense`, hand-derived backward (cross chain through `x_0 ⊙ q` + residual + two matmul factors + deep tower).

## Design Decisions

- **Low-rank cross (v2)** as the default. `cross_r = d` recovers full-rank; that's the explicit regression test (cross_r = d ⇒ behavior matches a hand-implemented full-rank cross layer for the same `W = U · C`).
- **No bias on cross layer output** (paper §3.1 convention). All cross math is purely linear in the activations; biases live on the deep tower and the stack layer.
- **ReLU on deep tower** (paper convention). No batch norm / layer norm — the original DCN-v2 paper deliberately leaves the deep tower bare for production stability. v1 keeps this.
- **`r` validation:** constructor throws if `r == 0` (cross can't be built) or `r > d` (low-rank factorization loses meaning). Constructor also throws if `cross_layers == 0` (no cross at all ⇒ just a deep MLP — call DeepMLP directly instead, don't pretend).
- **Deep tower dims validation:** `deep_dims` must be non-empty and all positive. `deep_layers = 0` ⇒ skip the deep tower entirely (and the stack layer takes only the cross output) — useful for the ablation test "DCN-v2 with no deep tower = pure deep-cross".
- **Stack layer always required** — `output_dim > 0`.
- **Per-layer caches:** forward caches `x_0, x_l, p_l, q_l` for each layer so backward can recompute the residual contribution and the factor gradients without re-running forward.
- **No `Layer` inheritance for `CrossNetworkLayer` itself** — it is a stateless helper that operates on batched tensors and is composed inside `CrossNetwork`. `CrossNetwork` and `DCNv2`/`DCNv2Regression` ARE `Layer` subclasses (the Layer contract requires `forward(input)`, `backward(grad_output, lr)`, `update_weights(lr)`, `zero_grad()`, `parameters()`, `gradients()`, `get_weights()`, `get_gradients()`, `name()`).

**Note on Tensor matmul convention**: `Tensor::operator*` is elementwise (Hadamard). The codebase does NOT have a built-in matmul operator on Tensor. Need to compute `(B, d) × (d, r)` manually via nested loops. (Verify by grepping — `grep -n "operator\*" include/nn/core/tensor.h` confirms `operator*` is elementwise, `transpose()` exists, no matmul.) So:

```cpp
Tensor matmul(const Tensor& A, const Tensor& B) {
    // A: (M, K)  B: (K, N)  →  result: (M, N)
    Tensor C(A.rows, B.cols);
    for (size_t i = 0; i < A.rows; ++i)
        for (size_t k = 0; k < A.cols; ++k) {
            double a = A(i, k);
            for (size_t j = 0; j < B.cols; ++j)
                C(i, j) += a * B(k, j);
        }
    return C;
}
```

Add this as a static helper in `dcn_v2.cpp` (file-local). Forward:

```cpp
Tensor CrossNetwork::forward(const Tensor& input) {
    last_x0_ = input.clone();
    Tensor x = input.clone();    // x_l
    for (auto& L : layers_) {
        L.last_x_lm1 = x.clone();
        L.last_p = matmul(x, L.C.transpose());   // (B, d) × (d, r) → (B, r)
        L.last_q = matmul(L.last_p, L.U.transpose());  // (B, r) × (r, d) → (B, d)
        Tensor x_new(input.rows, input.cols);
        for (size_t i = 0; i < input.rows; ++i)
            for (size_t j = 0; j < input.cols; ++j)
                x_new(i, j) = input(i, j) * L.last_q(i, j) + x(i, j);
        x = x_new;
    }
    last_xL_ = x.clone();
    return x;
}
```

The backward chain:

This is gnarly. Let me give the **complete** derivation in the implementation step. (The above sketch is intentionally wrong in indexing to surface the need to do the math carefully.)

**Full correct backward** (hand-derived, paper §3.1 + chain rule):

Given `x_l = x_0 ⊙ q_l + x_{l-1}` with `q_l = U_l · (C_l · x_{l-1})`:

`d x_l = grad_output` (per layer, top-down).

```
dq = x_0 ⊙ d x_l                                  (B, d)
dU = (dq)^T · p_l            where p_l = C_l · x_{l-1}  (B, r);  dU is (d, r)
tmp = U_l^T · dq                                  (r, d)
dC = (tmp)^T · x_{l-1}                            (r, d)
   → x_{l-1} is (B, d); tmp is (r, d); output (r, d)

prop = C_l^T · (U_l^T · dq)                       =  C_l^T · tmp     (B, d)
d x_{l-1} = d x_l + prop                          (B, d)

contrib_x0 = d x_l ⊙ q_l                          (B, d)
d x_0 += contrib_x0                               (accumulated across all layers)
```

In C++ terms:

```cpp
Tensor CrossNetwork::backward(const Tensor& grad_output, double /*lr*/) {
    const size_t B = last_x0_.rows;
    const size_t d = d_;
    Tensor dx0(B, d);
    dx0.fill(0.0);
    Tensor dx_l = grad_output.clone();   // (B, d)

    for (size_t idx = num_layers_; idx > 0; --idx) {
        auto& L = layers_[idx - 1];
        // p_l = L.last_p (B, r),  q_l = L.last_q (B, d),
        // x_{l-1} = L.last_x_lm1 (B, d),  x_0 = last_x0_ (B, d)

        // dq = x_0 ⊙ dx_l
        Tensor dq(B, d);
        for (size_t i = 0; i < B; ++i)
            for (size_t j = 0; j < d; ++j)
                dq(i, j) = last_x0_(i, j) * dx_l(i, j);

        // dU_l = dq^T · p_l    shape (d, r)
        // dU_l(i, j) = Σ_b dq(b, i) * p_l(b, j)
        Tensor dU(d, L.r);
        for (size_t b = 0; b < B; ++b)
            for (size_t i = 0; i < d; ++i)
                for (size_t j = 0; j < L.r; ++j)
                    dU(i, j) += dq(b, i) * L.last_p(b, j);

        // tmp = U_l^T · dq    U_l is (d, r), tmp is (r, d)
        // tmp(r, j) = Σ_i U_l(i, r) * dq(b, j)  → wait, this has b as a batch dim. Re-derive:
        // For each batch b: tmp_b(r, j) = Σ_i U_l(i, r) * dq(b, j) ? No — U_l is shared across batch, so:
        // tmp(r, j) = Σ_i U_l(i, r) * dq(b, j) → still has b. Re-think.
        // Correct: for each b, we compute tmp_b(r, j) = Σ_i U_l(i, r) * dq(b, j) and accumulate dC.
        // The dC formula is: dC(r, j) = Σ_b tmp_b(r, j) * x_{l-1}(b, j).
        // In code, we can fold the b loop into dC directly:
        // dC(r, j) = Σ_b Σ_i U_l(i, r) * dq(b, j) * x_{l-1}(b, j)
        Tensor dC(L.r, d);
        for (size_t r = 0; r < L.r; ++r)
            for (size_t j = 0; j < d; ++j) {
                double s = 0;
                for (size_t b = 0; b < B; ++b) {
                    double ui = 0;
                    for (size_t i = 0; i < d; ++i)
                        ui += L.U(i, r) * dq(b, j);
                    s += ui * L.last_x_lm1(b, j);
                }
                dC(r, j) = s;
            }
        // (Naive O(B · d² · r) per layer; fine for test sizes.)

        // dx_{l-1} = dx_l + C_l^T · (U_l^T · dq)   shape (B, d)
        // (B, d) ← (B, d) + (d, r) · (r, d)  equivalent: dx_{l-1}(b, j) = dx_l(b, j) + Σ_r C_l^T(b, r) · (U_l^T · dq)(r, j)
        // C_l^T(b, r) = x_{l-1}(b, r)?  No — C_l is (r, d), C_l^T is (d, r), shared across batch.
        // dx_{l-1}(b, j) = dx_l(b, j) + Σ_{r, i} C_l(r, i) * L.U(i, r') * dq(b, j') ?  This is getting tangled.
        // Re-derive cleanly:
        //   Let M_l = U_l · C_l   (d, d).   q_l = M_l · x_{l-1}.
        //   Then x_l = x_0 ⊙ (M_l · x_{l-1}) + x_{l-1}.
        //   d x_{l-1} contribution from the x_0 term: ⊙ M_l^T · (x_0 ⊙ d x_l)
        //   PLUS the residual contribution: d x_l
        //   So: d x_{l-1} = d x_l + M_l^T · dq
        //       where dq = x_0 ⊙ d x_l
        // Compute M_l^T · dq = (C_l^T · U_l^T) · dq.
        // For each batch b:  (C_l^T · U_l^T)(i, j)  is (d, d); then times dq(b, :) gives (d,).
        Tensor dx_prev(B, d);
        for (size_t b = 0; b < B; ++b)
            for (size_t j = 0; j < d; ++j) {
                double s = dx_l(b, j);
                for (size_t r = 0; r < L.r; ++r) {
                    double Ui = 0;
                    for (size_t i = 0; i < d; ++i)
                        Ui += L.U(i, r) * L.C(r, i);
                    s += Ui * dq(b, j);
                }
                dx_prev(b, j) = s;
            }

        // Accumulate d x_0 contribution
        for (size_t i = 0; i < B; ++i)
            for (size_t j = 0; j < d; ++j)
                dx0(i, j) += dx_l(i, j) * L.last_q(i, j);

        // Accumulate gradients
        for (size_t i = 0; i < d; ++i)
            for (size_t j = 0; j < L.r; ++j)
                L.gU(i, j) += dU(i, j);
        for (size_t i = 0; i < L.r; ++i)
            for (size_t j = 0; j < d; ++j)
                L.gC(i, j) += dC(i, j);

        dx_l = dx_prev;
    }

    return dx0;
}
```

(Note: the inner loops are O(B · d² · r) per layer which is fine for tests. A production implementation would cache `M = U · C` once per layer — but caching saves only constant factor for the small d, r used in tests, so v1 keeps it inline.)

void test_dcn_v2_gradient() {
    nn::DCNv2 m(4, 3, 2, {5}, 1);  // small dims for FD speed
    nn::Tensor x(2, 4);

        nn::Tensor y = m_.forward(x_);

        for (size_t i = 0; i < y.rows; ++i)
            for (size_t j = 0; j < y.cols; ++j)
                s += y(i, j) * y(i, j);
        return s;
    };
    // Analytical
    nn::Tensor y = m.forward(x);
    nn::Tensor grad(y.rows, y.cols);
    for (size_t i = 0; i < y.rows; ++i)
        for (size_t j = 0; j < y.cols; ++j)

    m.zero_grad();

## Common pitfalls

- **Matmul convention**: `Tensor::operator*` is elementwise. There is NO built-in matmul. We compute `(M, K) × (K, N)` with nested loops. The pattern is `(A · B.T())` for `(rows_A, cols_B)`-shaped outputs and `(A.T() · B)` for `(cols_A, rows_B)`-shaped outputs. Verify with a hand fixture if the FD gradient check fails — most index bugs surface as `rel_err > 1`.
- **Cross layer ordering in backward**: layers iterate `for (size_t idx = num_layers_; idx > 0; --idx)`, accessing `layers_[idx - 1]`. Off-by-one here causes silent gradient corruption.
- **`x_0` accumulation**: every layer contributes `dx_l ⊙ q_l` to the input gradient. Forgetting to accumulate across all layers (only using the last layer's contribution) gives a 50%-wrong input gradient.
- **ReLU mask on cached pre-acts**: `last_h_pre_relu_[i]` must be the value BEFORE applying ReLU on layer i. Apply the mask in backward: `d_h *= (last_h_pre_relu_[i] > 0)`.
- **Stack layer split**: `d_concat` has `d + deep_dims[-1]` columns; split as `[0, d)` → `d_xL`, `[d, end)` → `d_h`. Off-by-one in the split boundary corrupts both sub-networks.
- **`last_h_deep_` ≠ pre-ReLU**: it's the FINAL post-ReLU output, used only for the final forward result. Per-layer pre-ReLU caches go in `last_h_pre_relu_`.
- **Random init must be non-uniform for FD**: `Tensor::random(scale)` with non-trivial scale (e.g. 0.3) is the default. Uniform init (all 0.1) hides row-vs-column confusion in the matmul gradients.
