# HGRN (Hierarchically Gated Recurrent Neural Network) Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add an `HGRNCell` (per-token gated linear RNN) and an `HGRNModel` (stacked blocks + classifier) to the library, following Mehrdad et al. 2023 "Hierarchically Gated Recurrent Neural Network" (https://arxiv.org/abs/2307.02226). Complements the existing GLA (single scalar gate), Hawk/RG-LRU (input-tied gate), RetNet (fixed decay), and DeltaNet (delta-rule).

**Architecture:** Per-channel scalar-state linear RNN with separate forget gate `f`, input gate `i`, and tanh candidate `z`. Two variants per the paper:
- **HGRN-1** (lower bound, output = state): `c_t = f_t * c_{t-1} + i_t * z_t`, `h_t = c_t`.
- **HGRN-2** (upper bound, output gated): `h_t = o_t * c_t` where `o_t = sigmoid(W_o x_t + b_o)`.

Both are gated RNNs in the same family as GRU/LSTM but with elementwise (per-channel) gating instead of multiplicative gating — closer in spirit to GLA/Hawk but with three distinct gates.

**Tech Stack:** Existing `Layer`, `Tensor`, `Dense` primitives. Files go in `include/nn/layers/recurrent/`. Tested with numerical gradient checks at machine precision.

## Background

### Paper context

HGRN (Mehrdad, Cevher, Giannakis; 2023, https://arxiv.org/abs/2307.02226) is a simple but powerful gated linear RNN. Compared to the existing recurrent layers in this repo, HGRN sits between GRU/LSTM (full additive gates, no state coupling) and the linear-attention family (GLA, Mamba, DeltaNet — single scalar decay).

The key insight is **separate forget and input gates**, both elementwise (per-channel). Per-channel scalar state. The forward is:

```
f_t[c] = sigmoid(W_f x_t + b_f)[c]      ∈ (0, 1)
i_t[c] = sigmoid(W_i x_t + b_i)[c]      ∈ (0, 1)
z_t[c] = tanh(W_z x_t + b_z)[c]         ∈ (-1, 1)
c_t[c] = f_t[c] * c_{t-1}[c] + i_t[c] * z_t[c]
h_t[c] = c_t[c]                          (HGRN-1)
h_t[c] = sigmoid(W_o x_t + b_o)[c] * c_t[c]   (HGRN-2)
```

### Math we need to derive

**Forward (no surprise).** Elementwise recurrence, single state per channel.

**Backward (single-step BPTT).** Per channel `c`:

- `dc_t = dh_t + f_{t+1} * dc_{t+1}` (recursive: gradient of state c_t comes from output h_t plus state c_{t+1} scaled by the f_{t+1} it carries through).
  - In code: `grad_c[t] = grad_h[t] + grad_c[t+1] * f[t+1]` for t = T-1 ... 0 (with grad_c[T] = 0).
- `df_t[c] = grad_c[t][c] * c_{t-1}[c]` — variation of c_t w.r.t. f_t is the c_{t-1} it multiplied.
- `di_t[c] = grad_c[t][c] * z_t[c]`
- `dz_t[c] = grad_c[t][c] * i_t[c]`
- `grad_x` accumulates: `grad_x_t += W_f^T · grad_f_t + W_i^T · grad_i_t + W_z^T · grad_z_t (+ W_o^T · grad_o_t for HGRN-2)`.
- `grad_W_f += grad_f_t ⊗ x_t`, `grad_b_f += grad_f_t`, etc.

This is the standard 3-gate linear RNN backward — straightforward and tractable.

### Why this addition

- **Coverage gap.** The repo has GLA (single scalar gate), Hawk/RG-LRU (input-tied gate), RetNet (fixed decay), DeltaNet (delta rule), Mamba/Mamba2 (input-dependent SSM), H3 (Shift-SSM + diag-SSM), RWKV (a-decay), mLSTM, xLSTM — but NO layer with the **separate forget/input/output** gates that GRU/LSTM-style architectures rely on, and HGRN is the canonical linear-time, linear-state version of that family.
- **Educational value.** It cleanly demonstrates how the GRU/LSTM gating structure collapses to elementwise per-channel operations when the state is scalar-valued, not vector-valued (so gates and candidate share the same dimension).
- **Composition.** HGRN is a great drop-in alternative to GLA for tasks where you want simple, fast, well-behaved gated recurrence.

## Phase 0 — Design decisions

### D1: API surface

```cpp
class HGRNCell : public Layer {
public:
    HGRNCell(size_t input_dim, size_t hidden_dim, bool use_output_gate = false);

    // Input:  (T, input_dim)   Output: (T, hidden_dim)
    Tensor forward(const Tensor& input) override;
    Tensor backward(const Tensor& grad_output, double learning_rate) override;
    void update_weights(double learning_rate) override;
    void zero_grad() override;

    std::vector<Tensor*> parameters() override;
    std::vector<Tensor*> gradients() override;

    Tensor get_weights() const override { return W_f.weights; }
    Tensor get_gradients() const override { return W_f.grad_weights; }
    std::string name() const override { return "HGRNCell"; }

    // Accessors
    size_t input_dim() const { return input_dim_; }
    size_t hidden_dim() const { return hidden_dim_; }
    bool use_output_gate() const { return use_output_gate_; }

    // Public Dense accessors for testing
    Dense W_f, W_i, W_z;          // (input_dim → hidden_dim) each
    Dense W_o;                    // (input_dim → hidden_dim) — only if use_output_gate
};
```

For `use_output_gate=true`, `W_o` is constructed; otherwise it's a default-constructed (empty) Dense that participates in neither forward nor backward.

### D2: Why not `Dense` for the gate projections? — Use Dense

`Dense` works on `(batch, in_features) → (batch, out_features)`. We need to project each token `x_t` (shape `(1, input_dim)` after our row-per-token convention) through `W_f`, `W_i`, `W_z` to produce `(1, hidden_dim)` per-token. So `Dense(input_dim, hidden_dim)` is exactly what we want. The `W_o` for HGRN-2 is the same shape.

### D3: HGRNModel — simple stack + classifier

```cpp
class HGRNModel : public Layer {
public:
    HGRNModel(size_t input_dim, size_t hidden_dim, size_t output_dim,
              size_t num_layers = 1, bool use_output_gate = false);

    Tensor forward(const Tensor& input) override;   // (T, input_dim) → (1, output_dim) via last-step + classifier
    // ... standard overrides

    // Public for testing
    std::vector<std::unique_ptr<HGRNCell>> cells;
    Dense classifier;     // (hidden_dim → output_dim)
};
```

The model takes a sequence `(T, input_dim)`, runs each token through `num_layers` HGRN cells (each takes `(T, input_dim → hidden_dim)` and returns `(T, hidden_dim)`, where the next cell's input is the previous cell's output), then takes the **last timestep** and passes it through a classifier `Dense(hidden_dim, output_dim)` to produce `(1, output_dim)`.

For the per-token HGRNCell, we operate in `(T, input_dim)` layout (the natural row-per-token convention), so `Dense` doesn't need reshaping.

### D4: Numerical gradient check strategy

For the **cell**: test `use_output_gate=false` (HGRN-1, 6 parameter tensors: W_f.weights/bias, W_i.weights/bias, W_z.weights/bias) and `use_output_gate=true` (HGRN-2, 8 parameter tensors: + W_o.weights/bias). Use centered FD with `eps = 1e-4` and `d = 2..4`, `T = 3..5`. Per-element relative error target `< 1e-7`.

For the **model**: test forward shape + finiteness + training reduces loss (50 SGD steps, expect >50% loss reduction on a synthetic sequence regression task).

### D5: Layout convention

In this codebase, `Tensor` is 2D. We'll treat sequences as `(T, dim)` (row = timestep, col = feature). `Dense` projects each row independently. This matches GLA/Hawk/H3/RWKV conventions. The HGRNCell `forward` returns `(T, hidden_dim)` — one hidden vector per input token.

```cpp
// In forward:
Tensor forward(const Tensor& input) override {
    size_t T = input.rows;
    cache_input_ = input.clone();
    Tensor h(T, hidden_dim_);
    h.fill(0.0);

    // Per-token projections: batch through Dense (Dense treats input as batched)
    Tensor gate_f = W_f.forward(input);     // (T, hidden_dim)
    Tensor gate_i = W_i.forward(input);     // (T, hidden_dim)
    Tensor z_proj = W_z.forward(input);     // (T, hidden_dim)

    cache_f_.resize(T, hidden_dim_); cache_f_.fill(0.0);
    cache_i_.resize(T, hidden_dim_); cache_i_.fill(0.0);
    cache_z_.resize(T, hidden_dim_); cache_z_.fill(0.0);
    cache_c_.resize(T, hidden_dim_); cache_c_.fill(0.0);

    for (size_t t = 0; t < T; ++t) {
        for (size_t c = 0; c < hidden_dim_; ++c) {
            double ft = sigmoid(gate_f[t][c]);
            double it_ = sigmoid(gate_i[t][c]);
            double zt = std::tanh(z_proj[t][c]);
            double c_prev = (t == 0) ? 0.0 : cache_c_[t-1][c];
            double ct = ft * c_prev + it_ * zt;
            cache_f_[t][c] = ft;
            cache_i_[t][c] = it_;
            cache_z_[t][c] = zt;
            cache_c_[t][c] = ct;
            h[t][c] = ct;
        }
    }
    return h;
}
```
