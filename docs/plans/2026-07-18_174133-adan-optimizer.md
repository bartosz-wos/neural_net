# Adan Optimizer — Implementation Plan

> **For Hermes:** Implement with TDD following the project convention. Single file pair + test file + Makefile/nn.h wiring.

**Goal:** Add an `Adan` (Adaptive Nesterov Momentum) optimizer class to the standard adaptive-optimizer lineup. Adan (Xie et al. 2022 NeurIPS, https://arxiv.org/abs/2208.06677) achieves 2× faster convergence than Adam on ViT/CNN/Transformer training and is the default optimizer in DeepSeek's StableDiffusion3 pipeline, NVIDIA NeMo, timm, and InternLM. The repo already has Adam/AdamW/Lion/Sophia/Muon/AdEMAMix/SAM but not Adan.

**Architecture:**

- `Adan` class derived from `Optimizer` (matches `Yogi` / `RAdam` / `AdaBelief` style).
- Three-EMA algorithm (the official sail-sg/Adan canonical implementation):
  ```
  State per param (lazy-init on first step):
    m, v, n           : three EMA tensors (all init 0), same shape as param
    neg_prev_grad     : -g_{k-1} stored negated (memory-saving trick)

  Bias corrections (per-step, on the optimizer):
    bc1      = 1 - β1^t
    bc2      = 1 - β2^t
    bc3_sqrt = sqrt(1 - β3^t)

  Per parameter update (matches sail-sg/Adan _single_tensor_adan verbatim):
    g        = grad
    diff     = g - prev_g                        # (recovered from neg_prev_grad + g in code)
    m        = β1 * m + (1 - β1) * g
    v        = β2 * v + (1 - β2) * diff
    n        = β3 * n + (1 - β3) * (g + β2 * diff)²
    denom    = sqrt(n / bc3) + eps
    step_m   = (lr / bc1) * m / denom
    step_v   = (lr * β2 / bc2) * v / denom
    param    = (param - step_m - step_v) / (1 + wd * lr)        # integrated weight decay (no_prox=False)
  ```

  NOTE on the algorithm: the paper's pseudocode (Algorithm 1) writes
    `n_k = (1-β3)*n_{k-1} + β3 * (g + (1-β2)*(g - prev_g))²`,
  but the official PyTorch reference code uses
    `n_k = β3*n_{k-1} + (1-β3) * (g + β2*(g - prev_g))²`
  with the β3 placement swapped. We follow the **official reference implementation** (used by NVIDIA NeMo, timm, InternLM) which is what most reproductions ship; we document the discrepancy in a code comment.

- `handles_weight_decay() = true` (integrated `param / (1 + wd * lr)` form).
- Optional `no_prox` flag (`false` by default, matches paper convention) — when `true`, uses AdamW-style decoupled `param *= (1 - lr*wd)`.
- State per parameter: `(m, v, n, neg_prev_grad)` — 4 tensors, ~4× Adam footprint.

**Tech Stack:** C++17, `Tensor`/`Layer`/`Model`/`Optimizer` in this repo, no external deps.

**Verification — must pass (machine precision unless noted):**

1. **Defaults + accessors**: `Adan()` → lr=1e-3, betas=(0.98, 0.92, 0.99), eps=1e-8, wd=0, t=1.
2. **Constructor args + mutators**: non-default constructor round-trips; `set_*` mutators validate (b1, b2, b3 ∈ [0,1), eps > 0).
3. **Validation throws**: beta=0 ok (boundary), beta>=1 throws, eps<=0 throws. Mutator validation too.
4. **State lazy-init**: state tensors empty before first step; after step(), m/v/n have correct shape matching param shape.
5. **t increments** through steps correctly.
6. **First-step closed-form** (the canonical "Adam-style" first step check):
   With lr=0.1, betas=(0.98, 0.92, 0.99), eps=1e-8, wd=0, g=2.0 on a 1x1 param starting at 0:
   - diff = g - prev_g = 2 - 2 = 0  (because neg_prev_grad was init'd to -g)
   - m = β1 * 0 + (1-β1) * 2 = 0.02 * 2 = 0.04
   - v = β2 * 0 + (1-β2) * 0 = 0  (since diff=0)
   - n = β3 * 0 + (1-β3) * (g + β2*diff)² = 0.01 * 4 = 0.04
   - bc1 = 1 - 0.98 = 0.02
   - bc2 = 1 - 0.92 = 0.08
   - bc3_sqrt = sqrt(1 - 0.99) = sqrt(0.01) = 0.1
   - n/bc3 = 0.04 / 0.01 = 4
   - denom = sqrt(4) + 1e-8 ≈ 2
   - step_m = (0.1 / 0.02) * 0.04 / 2 = 5 * 0.02 = 0.1
   - step_v = (0.1 * 0.92 / 0.08) * 0 / 2 = 0
   - param_new = (0 - 0.1 - 0) / (1 + 0) = -0.1

   Verify m, v, n exactly and verify closed-form param update to ~1e-7 (FP floor).

7. **v_t uses gradient-difference** (the Adan "soul"): after step 1 with g=2, set g=4 next step:
   - diff = 4 - 2 = 2
   - v = β2 * 0 + (1-β2) * 2 = 0.08 * 2 = 0.16
   This is the **key Adan property** — v tracks gradient changes, not squared gradient.

8. **n_t uses gradient-plus-β2-scaled-diff** (the Adan second-moment signature):
   - With g=2 (first step), then g=4 (second step):
   - After step 1: prev_g=2, m=0.04, v=0, n=0.04.
   - After step 2: diff=2, m=0.98*0.04 + 0.02*4 = 0.0392+0.08 = 0.1192
   - v = 0.92*0 + 0.08*2 = 0.16
   - n_inside = (4 + 0.92*2)² = (4 + 1.84)² = 5.84² = 34.1056
   - n = 0.99*0.04 + 0.01*34.1056 = 0.0396 + 0.341056 = 0.380656
   Verify n_t matches this.

9. **Weight decay**: with wd>0 and zero gradient, param strictly shrinks by `lr*wd*param` (integrated prox form).
10. **Determinism**: two fresh Adan instances with the same grad sequence produce identical params bit-for-bit.
11. **End-to-end training**: 60-step Adan on linear regression `y=2x+1` reduces MSE loss and drives W+b ≈ target.
12. **Signature test vs Adam**: Adam v update is `β2*v + (1-β2)*g²`; Adan v update is `β2*v + (1-β2)*(g-prev_g)`. Under a non-trivial g sequence they DIFFER. With constant g=2, Adam's v grows monotonically while Adan's v stays at 0 (since diff=0 every step). This is the **non-vacuous** distinguishing property.
13. **Mutation test (non-vacuousness)**: temporarily replace `(1 - β2) * diff` with `(1 - β2) * g` in v update → breaks Test 7 (v_t with constant grad should be 0, becomes nonzero). This proves the gradient-difference structure is actually exercised.
