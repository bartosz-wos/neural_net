# MEGA — Moving Average Equipped Gated Attention Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Implement the MEGA architecture block (Ma et al. 2022, https://arxiv.org/abs/2209.10655) — an EMA-equipped gated attention sequence mixer — as a clean, fully-tested C++17 layer in `include/nn/layers/architectures/mega.{h,cpp}`, with companion `MegaModel` for end-to-end training, and a `tests/test_mega.cpp` suite hitting machine precision on every parameter gradient.

**Architecture:** A MEGA block is a pre-norm residual sequence mixer that (1) applies a per-channel exponential moving average over input features, (2) projects to Q/K/V via standard Dense layers, (3) computes gated soft attention with relative position bias and an output gate (the original paper's "gated attention" is essentially softmax(QKᵀ/√d + bias)·V followed by sigmoid(W_g·u)·o_t), and (4) sums into the residual stream. The model stacks `MegaBlock` + dense FFN + final LayerNorm + classifier head. The EMA + gated attention split is the key insight: EMA gives sublinear long-range mixing, gated attention gives precise local retrieval.

**Tech Stack:** C++17, g++ -O2, repo's `Tensor`, `Dense`, `LayerNorm`, `Softmax` primitives. No new dependencies.

---

## Architecture math (per `MegaBlock(d_model, num_heads, ffn_mult)`)

For one block, input x ∈ R^(T × d_model):

1. **EMA smoothing** (per-channel decay α ∈ R^(d_model), parametrized as α = sigmoid(W_α)):
   u_0 = 0
   u_t = α ⊙ u_{t-1} + (1 - α) ⊙ x_t       for t = 0..T-1
   u ∈ R^(T × d_model) is the smoothed feature stream.

2. **Q/K/V projections** from u (NOT x — gated attention sees the EMA'd features):
   q_t = u_t · W_q^T            ∈ R^(d_inner = d_model)   (we keep single-head = num_heads = 1
   k_t = u_t · W_k^T               by default; multi-head works but inflates params.)
   v_t = u_t · W_v^T
   z_t = sigmoid(u_t · W_g^T)    (output gate, applied AFTER attention)

3. **Gated soft attention** with relative position bias β ∈ R^(2T-1) (per-head is overkill
   for v1; one bias vector covers all positions and is added to the score matrix):
   score[t,s] = q_t · k_s / sqrt(d_inner) + β[t - s + (T-1)]      for s ≤ t  (causal)
   attn[t,:]  = softmax(score[t, 0..t])
   o_t        = Σ_{s=0..t} attn[t,s] · v_s
   g_t        = o_t ⊙ z_t                                       (output gate)

4. **Output projection**:
   h_t = g_t · W_o^T            ∈ R^(d_model)

5. **Residual + FFN** (canonical pre-norm residual block):
   y_t = x_t + h_t
   y_t = y_t + FFN(LN(y_t))     where FFN(d → mult*d → d) is GELU

**Backwards is straightforward BPTT through the EMA recurrence (per-channel chain
through α → u_t → u_{t+1} → ... → u_T) and the standard attention backward through
softmax + score + QK projections, plus the output gate chain (g → z) and the W_o
projection. The relative position bias enters as dscore/dβ = attn-1hot at each (t,s).**

## Task 2: Implement MegaBlock::forward

**Files:** `include/nn/layers/architectures/mega.cpp`

Implement the forward path as described above:
1. Run the EMA recurrence to compute `u` (T, d_model).
2. Compute Q, K, V via Dense forward.
3. Compute Z = sigmoid(W_g · u).
4. Compute the (T, T) score matrix with relative position bias β (only the lower
   triangle + diagonal; upper triangle is −inf for causal masking).
5. Row-softmax the score matrix to get `attn`.
6. Compute o = attn @ V.
7. Apply output gate: g = o ⊙ Z.
8. Output projection via W_o.
9. Residual add + FFN block (LN → Dense → GELU → Dense).

Cache: u, Q, K, V, Z, O, score (pre-softmax, for backward), attn, FFN pre-acts.

**Acceptance:** Test 2 (`forward_shape_finite_nonzero`) passes.

## Task 3: Implement MegaBlock::backward

**Files:** `include/nn/layers/architectures/mega.cpp`

Implement analytical backward through:
1. **FFN backward** (standard Dense+GELU+Dense chain, including LN backward).
2. **Residual add** passes gradients to both branches.
3. **W_o backward**: dL/dW_o += g^T · grad_h (Dense convention).
4. **Output gate**: dZ = grad_h ⊙ o (gating chain); dO = grad_h ⊙ z.
5. **Attention backward**: standard softmax backward (ds = attn ⊙ (grad_O - sum(attn * grad_O))).
   Then dQ += ds · K / √d; dK += ds^T · Q / √d; dV += attn^T · grad_O.
6. **Position bias β**: dβ[delta] += attn[t,s] for the (t, s) entry actually used
   (= score[t,s] - max; standard softmax backward handles the rest).
7. **Q/K/V Dense backward**: each one is a standard Dense backward (D, T) → (T, D).
8. **W_g backward**: dW_g += dZ^T · u, with sigmoid derivative.
9. **EMA backward (the tricky bit)**: u_t depends on u_{t-1}, so the gradient is
   time-reversed. For the per-channel α: du_t/dα = (u_{t-1} - x_t) ⊙ α ⊙ (1 - α).
   Reverse-time recurrence: du_{t-1} += du_t ⊙ α + (u_{t-1} - x_t) ⊙ dα from t.
10. **W_α backward**: per-channel dα += du_t · (u_{t-1} - x_t) for all t.
11. **Input gradient**: dx_t = (1 - α) ⊙ du_t (plus direct FFN path which is x_t).

**Acceptance:** Tests 3 (input grad FD), 4-9 (per-parameter FD checks) all pass at rel_err < 1e-4.

## Risks & mitigations

1. **EMA backward chain might have a sign/recurrence error.** Diagnostic: the
   EMA forward is `u_t = α ⊙ u_{t-1} + (1-α) ⊙ x_t`; reverse-time, the gradient
   at u_{t-1} is `du_{t-1} += du_t ⊙ α` (the α-multiplied carry) PLUS the
   `du_t/dα` term that loops into grad_α. Forgetting either piece breaks Test 3.
   Fix recipe: derive from scratch — `u_t = α ⊙ u_{t-1} + β ⊙ x_t` (β = 1-α), then
   `du_{t-1}/dα = u_{t-1} - x_t` propagates back through every t > 0.
2. **Position bias index off-by-one.** The bias vector has `2T-1` entries; the
   index for offset (t - s) is `(t - s) + (T - 1)` so it spans [0, 2T-2].
   Off-by-one here makes Test 5 fail (W_v grad check) because the bias gradient
   contaminates via the V path.
3. **Multi-head being added later.** For v1 we throw if `num_heads != 1`. This
   keeps the gradient check tractable; multi-head can be added incrementally
   once single-head is stable.
4. **Softmax + causal mask interaction.** A `-inf` in the score row would make
   softmax NaN if the entire row is masked. For T ≥ 1 and causal masking, the
   diagonal is always unmasked so this is safe — but assert with a T=1 test
   that forward + backward are finite.
