# MLP-Mixer Architecture Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Implement MLP-Mixer (Tolstikhin, Dosovitskiy, Beyer, Kolesnikov, Uszkoreit, Houlsby — Google Brain, 2021) — "An all-MLP Architecture for Vision". Patch-tokenize an image into S patches of dimension C (channels), then alternate token-mixing MLPs (operate across patches, sharing weights per channel) and channel-mixing MLPs (operate across channels, sharing weights per patch). Add full backward pass with numerical gradient checks.

**Architecture:** Three classes:
1. `MlpMixerBlock(dim, seq_len, token_dim, channel_dim)` — pre-norm → token-mixing MLP → residual → pre-norm → channel-mixing MLP → residual.
2. `MlpMixerLayer` (alias of `MlpMixerBlock`, for naming clarity matching the paper).
3. `MlpMixerModel(image_size, patch_size, in_channels, num_classes, dim, depth, token_dim, channel_dim)` — patch embed via Conv2D(stride=patch_size) → S = (image_size/patch_size)² tokens → stack of `depth` MixerBlocks → LayerNorm → global average pooling over S → classifier.

**Why this addition:** The repo has `gmlp.{h,cpp}` (token-axis linear with a fixed (S,S) matrix), `kan.{h,cpp}` (learned-activation MLPs), and `vit.{h,cpp}` (transformer encoder). MLP-Mixer is the iconic "patches → MLPs only" architecture that, together with ViT and gMLP, completes the canonical 2021 vision-architecture triangle. Unlike gMLP, Mixer uses *transposed* MLPs (operate independently across S for the token-mix and across C for the channel-mix — the same MLP weights broadcast over rows/cols), which is genuinely distinct.

**Tech Stack:** Existing — `Tensor`, `Dense`, `LayerNorm`, `Conv2D` (in `include/nn/layers/convolutions/conv_layer.h`); GELU activation from `activations.h`. No new external dependencies.

**Reference:**
- Paper: https://arxiv.org/abs/2105.01601 (Tolstikhin et al., 2021)
- Official TF implementation: https://github.com/google-research/vision_transformer/blob/main/vit_jax/models_mixer.py

## Mathematical Specification

### Patch embedding

Input image: `(B, C_in, H, W)` flat as `(B, C_in*H*W)`.

Apply Conv2D with `kernel_size = patch_size`, `stride = patch_size`, `in_channels = C_in`, `out_channels = dim`, zero-padding (i.e. each patch is independently linearly projected to `dim` channels). Output: `(B, S*dim)` flat where `S = (H/patch_size) * (W/patch_size)`. (Identity-style patch embedding: no bias; equivalent to slicing patches and applying a per-pixel dense layer. The Conv2D formulation matches the paper's reference impl and is already used by `vit.h`.)

### Mixer block

Per token position `i ∈ {1..S}` and channel `j ∈ {1..dim}`:
- `U_{*,i}` = LayerNorm(X_{*,i})_patchwise_i.e._per_token, shape `(B, S, dim)` — actually: apply LayerNorm per token (over the `dim` axis), independently across the `S` tokens. Concretely: `(B, S*dim)` → reshape → for each of S tokens, LayerNorm over dim → flatten back.
- `Y` = token-mix MLP: transpose to `(B, dim, S)`, apply 2-layer Dense MLP with hidden width `token_dim` (GELU between), broadcast over the `dim` axis. Transpose back to `(B, S, dim)`. **The MLP weights are SHARED across all `dim` channels** — i.e. the same Dense goes from S → token_dim → S for every channel independently.
- `X = Y + U` (residual).
- `V_{*,j}` = LayerNorm(X_{*,j})_channelwise_j.e._per_channel, shape `(B, S, dim)` — apply LayerNorm per channel (over the S axis), independently across the `dim` channels.
- `Z` = channel-mix MLP: apply 2-layer Dense MLP with hidden width `channel_dim` (GELU between), broadcast over the S axis. **The MLP weights are SHARED across all S tokens** — i.e. the same Dense goes from dim → channel_dim → dim for every token independently.
- `out = Z + V` (residual).

### Model head

`H` = LayerNorm(out) per token (LN over dim axis, applied to the `(B, S*dim)` representation), then mean pool over S → `(B, dim)`, then classifier Dense(`num_classes`, `dim`).

### Backward pass (the critical part)

Per block:
1. `dZ = grad_out` (residual2) — shape `(B, S*dim)`.
2. `dV = dZ` (residual1), then `dV_per_channel_LN = LN_backward(dV_after_residual)`.
3. Channel-mix MLP backward: input is `X_after_residual1` (shape `(B, S, dim)` flattened). MLP is a single shared Dense applied per row. Per row independently: standard Dense backward for weights shared across S rows. This means `grad_W1` accumulates across S rows (and across B batch). `grad_b1` accumulates across S rows.
4. `dX_residual1 = dV_after_residual` (skip). Add: `dX = grad_back_through_MLP(V)`.
5. Apply token-mix residual: `dY = dX`.
6. Token-mix LN backward (LN applied per token over dim axis).
7. Token-mix MLP backward: input is `U` reshaped to `(B, dim, S)`. MLP applied per row (per channel independently). For each of B*dim rows: standard Dense backward. `grad_W` accumulates across B*dim rows. `grad_b` accumulates across B*dim rows.
8. Apply token-mix residual: `dU = dY`. `grad_in = dU` for the block.

The two LN applications are independent — LN_per_token LN's over the dim axis per token; LN_per_channel LN's over the S axis per channel. The dense MLPs are shared Dense applied per row, so the backward is standard Dense-backward-per-row with weight-grad accumulation across rows.

### Existing utilities we use

- `LayerNorm(dim)` from `include/nn/layers/normalization/layer_norm.h` — applies to the last axis.
- `Dense(out, in)` from `include/nn/core/layer.h` — `y = x W^T + b`, W is `(out, in)`.
- `Conv2D` from `include/nn/layers/convolutions/conv_layer.h` — for patch embedding.
- GELU activation struct from `include/nn/activations/activations.h`.

### Task 2: Implement `MlpMixerBlock::forward` (RED-green for shape)

**Files:**
- Modify: `include/nn/layers/architectures/mlp_mixer.cpp` (create + impl)

**Step 1:** Stub out all four methods. Implement `forward` fully. The forward path:
1. `last_input_` ← input. Shape `(B, S*dim)`.
2. `last_z_` ← `LN_per_token(input)`. Reshape `(B, S, dim)`; per row of length dim, apply LayerNorm forward; flatten back to `(B, S*dim)`.
3. `last_u_t_` ← token-mix: reshape `last_z_` to `(B, dim, S)`. For each row (length S), apply shared Dense(token_dim, S) → GELU → Dense(S, token_dim). Flatten back to `(B, S*dim)`.
4. `last_y_` ← `last_z_ + last_u_t_` (residual1).
5. `last_v_` ← `LN_per_channel(last_y_)`. Reshape `(B, S, dim)`; for each column of length S, apply LayerNorm forward (transpose to (B, dim, S), apply LN row-wise which is per-channel over S, transpose back).
6. `last_out_` ← channel-mix: reshape `last_v_` to `(B, S, dim)`. For each row (length dim), apply shared Dense(channel_dim, dim) → GELU → Dense(dim, channel_dim). Flatten back to `(B, S*dim)`.
7. Return `last_y_ + last_out_` (residual2).

**Helper functions (private, in the .cpp):**
- `static Tensor ln_per_token_forward(const Tensor& x, size_t S, size_t D)` — `x` shape `(B, S*D)`, returns same shape. Computes mean/var over D per token.
- `static Tensor ln_per_channel_forward(const Tensor& x, size_t S, size_t D)` — `x` shape `(B, S*D)`, returns same shape. Computes mean/var over S per channel.
- The Dense apply-per-row: implement a small helper `apply_dense_per_row(const Tensor& x, const Dense& d)` that loops over rows and concatenates.

**LayerNorm forward internals**: since `LayerNorm(D)` in this repo's `layer_norm.h` is a `Layer` subclass with its own `gamma`, `beta`, we need to either compose two `LayerNorm(dim)` instances (one applied per-token by reshaping) or implement LN manually. **Simpler approach:** use `LayerNorm(D)` and apply it independently per token (reshape `(B, S, D)` → loop over B*S rows → each row `(1, D)` goes through LN forward → flatten back). Same trick for the per-channel LN: transpose to `(B, D, S)` and use the same LN class.

**Step 2:** Compile and run a quick smoke test (manual at first; tests in Task 5). Verify it produces a `(B, S*dim)` output of correct shape.

**Files:**
- Modify: `include/nn/layers/architectures/mlp_mixer.cpp`

**Step 1:** Implement `forward`:
1. Apply `Conv2D` patch embed (stride = patch_size, kernel = patch_size) → `(B, dim*H_patch*W_patch)` flat.
2. Stack of `depth` MixerBlocks → `(B, S*dim)`.
3. `LN_per_token` → mean-pool over S → `(B, dim)`.
4. Classifier Dense(num_classes, dim) → `(B, num_classes)`.

**Step 2:** Implement `backward`:
1. Classifier Dense backward (standard).
2. Broadcast gradient back from `(B, dim)` to `(B, S*dim)` by repeating across S (since mean-pool distributes gradient uniformly).
3. LN per-token backward.
4. Iterate `depth` MixerBlocks in reverse, calling each `backward`.
5. Conv2D patch-embed backward.

## Pitfalls & Verification

1. **Per-token vs per-channel LN direction:** easy to mix up. `ln_per_token_forward(x, S, D)` computes mean over D per token; `ln_per_channel_forward(x, S, D)` computes mean over S per channel. Use transposes to reuse `LayerNorm(D)` for both.
2. **Dense weight sharing:** the same Dense instance is applied per row in the forward, so the weight gradient in backward must accumulate over rows. Don't accidentally create per-row Denses.
3. **Mean-pool gradient distribution:** when pooling `X ∈ R^{S×D}` to `x̄ = mean_t X[t]`, the upstream grad `(B, D)` becomes `(B, S*D)` by repeating each entry S times (NOT by copying `S*grad` — that's the standard mean-pool grad).
4. **Conv2D patch embed backward:** the `Conv2D` in `conv_layer.h` has its own backward. Use it as-is. Verify `(in_channels * H_in * W_in)` is divisible by `(patch_size * patch_size * in_channels)` (i.e. patch_size must divide H and W).
5. **Gradient check tolerance:** start with `rel_err < 1e-3` (the FD step ε=1e-5 is the right scale for this code base's FP32-equivalent double precision).
