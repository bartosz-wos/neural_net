# RAdam Optimizer — Implementation Plan

> **For Hermes:** Implement with TDD following the project convention. Single file pair + test file + Makefile/nn.h wiring.

**Goal:** Add a `RAdam` (Rectified Adam) optimizer class to the standard adaptive-optimizer lineup. RAdam is one of the most popular Adam variants in practice — it fixes Adam's high-variance early-training step by gating the adaptive learning rate by a `ρ_t`-based rectification.

**Architecture:**

- `RAdam` class derived from `Optimizer` (matches `Yogi` / `AdaBelief` / `Adafactor` / `AdamW` style).
- Algorithm per parameter:
  ```
  m_t = β1 · m_{t-1} + (1 − β1) · g_t
  v_t = β2 · v_{t-1} + (1 − β2) · g_t²              (same as Adam)
  m̂_t = m_t / (1 − β1^t)
  
  ρ_∞ = 2 / (1 − β2) − 1                          (constant; depends only on β2)
  ρ_t = ρ_∞ − 2 · t · β2^t / (1 − β2^t)           (current effective SMA length)
  
  if ρ_t > 4:                                       # adaptive branch (warmup done)
      l_t = sqrt( ((ρ_t − 4)(ρ_t − 2) ρ_∞) / ((ρ_∞ − 4)(ρ_∞ − 2) ρ_t) )
      param = param − lr · (l_t · m̂_t / (sqrt(v̂_t) + ε) + wd · param)
  else:                                             # SGD-like branch (warmup phase)
      param = param − lr · (m̂_t + wd · param)
  ```
  Note `v̂_t = v_t / (1 − β2^t)` is only needed in the adaptive branch.
- `handles_weight_decay() = true` (AdamW-style decoupled path).
- State per parameter: `(m, v)` like Adam.

**Tech Stack:** C++17, `Tensor`/`Layer`/`Model`/`Optimizer` in this repo, no external deps.

**Verification — must pass (machine precision unless noted):**

1. **Defaults + accessors**: `RAdam()` → lr=1e-3, β1=0.9, β2=0.999, ε=1e-8, wd=0, t=1.
2. **Constructor args + mutators**: non-default constructor round-trips; `set_*` mutators validate (β1,β2 ∈ (0,1), ε > 0).
3. **Validation throws**: β1=0, β1≥1, β2=0, β2≥1, ε≤0 all throw `std::invalid_argument`. Mutator validation too.
4. **State lazy-init**: `get_m`/`get_v` return (0,0) before first `step()`; after `step()`, get_m/v returns correct shape (matches param shape).
5. **t increments**: t=1 initially; t=2 after first step; t=6 after 5 steps.
6. **ρ_t formula** (the rectification's first building block): given β2=0.999, t=1, compute ρ_t = ρ_∞ − 2·1·β2^1/(1−β2^1) and verify against hand-derived value.
7. **ρ_∞ formula**: at t=1, ρ_t < 0 (with β2=0.999 → ρ_t ≈ −2·1·0.999/0.001 + 1999 = −1996.002). At t=4, still <0 (warmup). At t=5 with β2=0.999, ρ_t crosses 4 → adaptive branch.
8. **Early-step branch (ρ_t ≤ 4)**: param update at t=1 with grad=2, β1=0.9, m_prev=0: m_new = 1.8, m_hat = 1.8/(1−0.9) = 18.0. param_new = param − lr · 18.0 (SGD-like, no v denominator).
9. **Late-step branch (ρ_t > 4)**: after enough steps for ρ_t > 4, param update uses adaptive l_t · m̂/(sqrt(v̂)+ε).
10. **l_t formula at t=5, β2=0.999**: hand-compute ρ_t at t=5 (should be ~4.something), then l_t = sqrt(((ρ_t−4)(ρ_t−2)ρ_∞)/((ρ_∞−4)(ρ_∞−2)ρ_t)), verify against impl.
11. **Weight decay**: with wd>0 and zero gradient, param strictly decreases by `lr·wd·param`.
12. **Determinism**: two fresh RAdam instances with the same grad sequence produce identical params bit-for-bit.
13. **End-to-end training**: 60-step RAdam on linear regression `y=2x+1` reduces MSE loss and drives W+b ≈ target.
14. **RAdam vs Adam signature test**: at t=1 with the same grad, RAdam takes the SGD-like branch (param move = lr · m̂), while Adam's move is `lr · m̂ / (sqrt(v̂)+ε)` — proving the adaptive denominator is gated.
15. **Mutation test (non-vacuousness)**: a temporary in-source edit that drops the `if ρ_t > 4` branch (always uses adaptive) breaks at least the early-step-SGD-like test and the ρ_t-boundary test.
