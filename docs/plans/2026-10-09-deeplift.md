# DeepLIFT (Rescale Rule) Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship DeepLIFT with the Rescale rule as `include/nn/interpretability/deeplift.{h,cpp}` — the fifth and final interpretability method family, and the O(1)-forward-pass counterpart to the already-shipped Integrated Gradients (which needs `n_steps` forward+backward passes per instance).

**Architecture:** A two-pass multiplier recursion. Forward once on the reference baseline `x'` and once on the input `x`, caching **every layer's** input and output activation, then walk the layer stack backward carrying an "adjoint" `G` that is **not** a gradient. For an elementwise nonlinear layer the Rescale multiplier `m = Δout/Δin` rescales `G_in = G_out ⊙ m`; for a linear layer `G_in = G_out`. Each layer's contribution is `(a - a') ⊙ G_in`, and the input layer's contribution IS the attribution. Sum of all contributions = `F(x) - F(x')` (completeness).

**Tech Stack:** C++17, existing `Tensor` (2-D, real), existing `Layer`/`Model` (`Model::layers` is a **public** member — that is how the recursion reads intermediates without touching the base class).

| D6 | Run the **reference forward FIRST**, then the input forward, then walk backward. | `Dense::backward` reads its cached `last_input`. ## Math to implement (all read from captum, not memory)

Rescale rule, per neuron `i` of an elementwise nonlinear layer:

```
m_i   = (a_i(out) - a'_i(out)) / (a_i(in) - a'_i(in))
G_in  = G_out ⊙ m
contrib = (a(in) - a'(in)) ⊙ G_in
```
with `_compute_diffs` (`dl_core.py:1147-1156`) being a plain difference of the input half and reference half, and the ε-guard of D3 applied **elementwise** (`torch.where` is per-element, so the branch must be per-element here too).

Linear layers: `G_in = G_out`, i.e. the layer's own `backward` is reused verbatim — for a linear map, `∂out/∂in` is a matrix and `dL/d(in) = J^T dL/d(out)`, which is exactly what `backward` computes. The elementwise "multiplier" form is only defined for elementwise-nonlinear layers, which is precisely why captum keeps a separate `SUPPORTED_NON_LINEAR` dispatch (`dl_core.py:1160-1171`).

Completeness (the axiom, and the strongest single test):

```
Σ over ALL layers of contrib_ℓ  ==  F(x) - F(x')
```

**The headline closed-form oracle.** On a **purely linear** network every multiplier is the identity, so DeepLIFT reduces to multiplying the exact gradient by `(x - x')`:

```
attribution_i = (x_i - x'_i) · ∂F/∂x_i
```

For an MLP with no activation this is hand-computable from the weights with no tolerances at all — the same oracle style that caught two real bugs in the shipped LIME entry.

**Step 1: Add the hooks to `Layer`**

Insert after `virtual std::string name() const { return "Layer"; }`:

```cpp
    // ---- DeepLIFT Rescale-rule hooks (see docs/plans/2026-10-09-deeplift.md) ----
    // True only for elementwise nonlinear layers, where the Rescale multiplier
    // m = (f(a) - f(a')) / (a - a') is a well-defined per-neuron scalar. Every
    // other layer is linear or shape-changing and keeps the identity multiplier.
    // Defaulted so the ~250 existing layers need no change.
    virtual bool supports_rescale() const { return false; }
    // Given dL/d(output) for the INPUT forward pass and the matching reference
    // activations, return dL/d(input) under the Rescale rule. The default is the
    // linear identity G_in = G_out; elementwise nonlinear layers override it.
    virtual Tensor rescale_backward(const Tensor& grad_output, const Tensor& input,
                                    const Tensor& input_ref, double eps) const {
        return grad_output;
    }
```

**Step 2: Override in `Activation<F>`**

`Activation<F>` currently has no `F`-type introspection beyond `func`, so both overrides go in the class body:

```cpp
    bool supports_rescale() const override { return true; }
    Tensor rescale_backward(const Tensor& grad_output, const Tensor& input,
                            const Tensor& input_ref, double eps) const override {
        Tensor res(grad_output.rows, grad_output.cols);
        for (size_t i = 0; i < res.rows; ++i) {
            for (size_t j = 0; j < res.cols; ++j) {
                const double delta_in = input[i][j] - input_ref[i][j];
                if (std::abs(delta_in) < eps) {
                    // L'Hôpital limit: the multiplier degenerates to f'(a).
                    // NOT zero and NOT a division by delta_in (see plan D3).
                    res[i][j] = grad_output[i][j] * func.derivative(input[i][j]);
                } else {
                    const double delta_out =
                        func(input[i][j]) - func(input_ref[i][j]);
                    res[i][j] = grad_output[i][j] * delta_out / delta_in;
                }
            }
        }
        return res;
    }
```

`Activation` already pulls in `<cmath>` transitively via `tensor.h`; if the build complains, add `#include <cmath>` to `layer.h`.

`deeplift.cpp` core:

```cpp
DeepLiftResult deep_lift(Model& model, const Tensor& input,
                         const Tensor& baseline, size_t target, double eps) {
    if (input.rows != baseline.rows || input.cols != baseline.cols)
        throw std::invalid_argument("deep_lift: baseline shape must match input");
    if (eps <= 0.0)
        throw std::invalid_argument("deep_lift: eps must be > 0");

    const size_t L = model.layers.size();
    if (L == 0) throw std::invalid_argument("deep_lift: model has no layers");

    for (auto& l : model.layers) l->zero_grad();

    // Per-layer (input, output) for the reference pass and the input pass.
    // Reference FIRST so cached last_input belongs to the input pass (plan D6).
    std::vector<Tensor> ref_in, ref_out, act_in, act_out;
    auto run = [&](const Tensor& seed, std::vector<Tensor>& ins,
                   std::vector<Tensor>& outs) {
        Tensor cur = seed;
        for (auto& l : model.layers) {
            ins.push_back(cur);
            cur = l->forward(cur);
            outs.push_back(cur);
        }
    };
    run(baseline, ref_in, ref_out);
    run(input, act_in, act_out);

    Tensor out = act_out.back();
    if (target >= out.cols)
        throw std::out_of_range("deep_lift: target index out of range");

    Tensor G = Tensor::zeros(out.rows, out.cols);
    for (size_t i = 0; i < out.rows; ++i) G[i][target] = 1.0;

    DeepLiftResult res;
    res.n_layers = L;
    double contrib_sum = 0.0;

    for (size_t k = L; k-- > 0;) {
        auto* layer = model.layers[k].get();
        Tensor g_in = layer->supports_rescale()
            ? layer->rescale_backward(G, act_in[k], ref_in[k], eps)
            : layer->backward(G, 0.0);          // linear: identity multiplier
        Tensor delta = act_in[k] - ref_in[k];    // (a - a')
        contrib_sum += delta.hadamard(g_in).sum();
        if (k == 0) res.attributions = delta.hadamard(g_in);
        G = g_in;
    }

    double fx = act_out.back()[0][target];
    double fp = ref_out.back()[0][target];
    res.completeness_delta = res.attributions.sum() - (fx - fp);

    for (auto& l : model.layers) l->zero_grad();  // leave no training residue
    return res;
}
```

`hadamard` is the elementwise product (`tensor.h:63`); `Tensor::zeros` is `tensor.h:54`. Keep `contrib_sum` only if a test needs the per-layer breakdown; otherwise drop it rather than shipping an unused accumulator (YAGNI).

## Task 3: Test suite — multipliers and the ε-fallback

**Objective:** Cover the nonlinear path and the two branches of D3.

**Tests (add to `tests/test_deeplift.cpp`):**

1. **Single-ReLU hand-computed oracle.** Model = `Activation<ReLU>` only. For `x_i > 0 > x'_i`, `m_i = (x_i - 0)/(x_i - x'_i) = 1`, so `attribution_i = x_i - x'_i`. For `x_i < x'_i < 0`, `f` is constant 0, `m_i = 0/neg = 0`, so `attribution_i = 0`. Exact values, no tolerance.
2. **Two-layer ReLU+Dense, hand weights**, completeness `Σ == F(x) - F(x')` to 1e-12.
3. **ε-fallback, `delta_in` LARGE** (normal path): assert the multiplier is `Δout/Δin`, not the derivative. Hand-set so the two differ by >10× — otherwise the test cannot tell them apart.
4. **ε-fallback, `x_i == x'_i` exactly** (D3 branch). Both passes identical ⇒ attribution 0 and **no NaN anywhere**. This is the test that fails loudly if someone writes `delta_out/delta_in` unguarded.
5. **ε-fallback is the DERIVATIVE, not zero** — at a point where `Δin == 0` but `Δout != 0` (constructible by choosing `x'_i` such that `f(x_i) == f(x'_i)` with `x_i != x'_i`… **only possible for a flat region**. Use `Tanh` at a saturated point, or better: assert via a `Dense`-free single-`Softplus` layer where `Δin == 0` ⇒ `Δout == 0` and the fallback gives `grad·f'(x)`. Test: `Softplus` model, `x == x'`, multiplier equals `f'(x)` ⇒ attribution 0 but **no NaN and no Inf**.
6. **Whole-batch `input == baseline`** ⇒ all attributions exactly 0, `completeness_delta == 0`, all finite.
7. **Completeness on a deep net** (3 Dense + 2 ReLU, random non-uniform init) — `|completeness_delta| < 1e-9`. **Use random init, never uniform** (uniform masks row-vs-column confusion).
8. **Validation errors**: baseline shape mismatch, `target` out of range, `eps <= 0`, empty model.
9. **No residue**: parameter gradients are zero after the call (mirrors `input_gradient`).
10. **Determinism**: two calls bit-identical.
11. **DeepLIFT ≠ IG on a nonlinear net** — on a ReLU net they differ; guards against accidentally shipping an IG copy.
12. **`deep_lift_shap`** with K=3 baselines equals the mean of 3 `deep_lift` calls to 1e-15; K=1 equals plain `deep_lift`.

## Anti-patterns this plan exists to prevent

- **Guessing the arXiv ID.** Two bad IDs have already shipped from this queue (Greenwell/PD, and this one). D1 records the correction in the plan *and* the Done entry so it cannot be re-introduced.
- **Unguarded `Δout/Δin`.** Produces NaN on the perfectly ordinary case `x == x'`. D3 pins the fallback to the true gradient; test 4 and test 6 exist solely to catch it.
- **Uniform init in a gradient test.** Row-sum == column-sum by construction, so a row-vs-column mix-up passes vacuously. Test 7 mandates random init.
- **Skipping the umbrella-header compile.** A focused test including only `deeplift.h` cannot see a collision introduced into the shared `layer.h` that ~250 layers include. The `nn.h`-standalone gate is not optional.
- **A test that passes on the first run.** If any Task 3 test is green before its implementation exists, it is testing the wrong thing — per TDD, fix the test, not the code.
