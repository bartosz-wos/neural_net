# DiT (Diffusion Transformer) Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a DiT-style sequence diffusion model (Peebles & Xie 2023, "Scalable Diffusion Models with Transformers", https://arxiv.org/abs/2212.09748) to the repo's generative folder — adaLN-Zero modulation, multi-head attention with per-token conditioning, full diffusion training and DDPM-style sampling, and a sequence-level unpatchify to keep the API general (not tied to 2-D images).

**Architecture:**
- `DiTAdaLNZero(d_model)` — the canonical adaLN-Zero modulation layer: takes 6 modulation vectors `(shift_msa, scale_msa, gate_msa, shift_mlp, scale_mlp, gate_mlp)`, computes `LN(x) * (1 + scale) + shift`, gates the residual with `gate`, and initializes the final linear of MLP/attn to zero (the "Zero" in adaLN-Zero). This is the shared per-block structure reused by both DiTBlock paths.
- `DiTBlock(d_model, n_heads, mlp_ratio=4.0)` — DiT block. Two-layer: pre-LN → MHA (with adaLN-Zero modulation `gamma_1`) → residual, then pre-LN → MLP (with adaLN-Zero modulation `gamma_2`) → residual. Modulation vectors are produced from the concatenated time + class embedding (a small Dense from `2*d_model → 6*d_model`, then chunked).
- `DiTTimeEmbed(max_period=10000, hidden_dim)` — sinusoidal Vaswani-style time embedding followed by a 2-layer MLP with SiLU (matches the DDPM `TimeEmbedding` pattern in `ddpm.h`).
- `DiTLabelEmbed(num_classes, d_model)` — learned `(num_classes, d_model)` embedding table for class-conditional generation. Zero class index is the unconditioned token (`num_classes` user-allocated indices).
- `SequencePatchEmbed(in_dim, d_model, patch_len)` — projects `(B, T, in_dim)` to `(B, T/patch_len, d_model)` via a Dense + reshape (mirrors `ViTPatchEmbedding` for the 1-D sequence case).
- `SequenceUnpatchify(d_model, out_dim, patch_len)` — inverse: `(B, S, d_model)` → `(B, S*patch_len, out_dim)`.
- `DiT(d_model, depth, n_heads, in_dim, patch_len, num_classes=0, mlp_ratio=4.0)` — full transformer-style denoiser: SequencePatchEmbed → stack of DiTBlocks → final LayerNorm (modulated) → final linear (initialized to zero, the "Zero" output projection) → SequenceUnpatchify. Optional class conditioning via `DiTLabelEmbed`. Optional dropout-style stochastic depth on the residual paths.
- `DiTDiffusion(d_model, depth, n_heads, in_dim, patch_len, T=1000, num_classes=0, beta_start=1e-4, beta_end=0.02)` — wraps a `DiT` denoiser with a `NoiseScheduler` (re-uses the existing `NoiseScheduler` from `ddpm.h` for the forward noising and DDPM-style sampling). Provides:
  - `add_noise(x0, t, noise)` — convenience pass-through to `NoiseScheduler::q_sample`.
  - `training_loss(x0, t)` — sample noise, compute `x_t`, predict `eps_θ(x_t, t)`, MSE to `noise`.
  - `sample(n, n_steps, class_labels)` — DDPM reverse-process sampling from `t=T-1` to `t=0`.

**Tech Stack:** Existing `Tensor`, `Layer`, `Dense`, `LayerNorm`, `TimeEmbedding` (from `ddpm.h`), `NoiseScheduler` (from `ddpm.h`), `Embedding` (from `dense/embedding.h`). Standard `<random>`, `<cmath>`, `<algorithm>`, `<memory>`. New file lives in `include/nn/layers/generative/dit.{h,cpp}`.

**Paper references:**
- Peebles & Xie, "Scalable Diffusion Models with Transformers" (ICCV 2023), https://arxiv.org/abs/2212.09748 — the canonical DiT paper. We follow its adaLN-Zero formulation (Sec 3.1, Fig 4 / Table 1) for the block structure.
- Nichol & Dhariwal, "Improved Denoising Diffusion Probabilistic Models" (2021) — for the DDPM sampling algorithm that `DiTDiffusion::sample` implements.

**Why now:** The repo has DDPM, VAE, WGAN-GP, RealNVP, Neural Spline Flow, PixelCNN, Consistency, Flow Matching, but no transformer-based diffusion model. DiT is the architecture behind Stable Diffusion 3 and Sora's latents, and it fills the architectural gap (DDPM uses a 1-D U-Net; Consistency uses the same; DiT replaces the U-Net denoiser with a transformer). Sequence-DiT also ties together the existing `TransformerBlock` and `MultiHeadAttention` work in a way no other layer currently does.

**Design notes / scope:**
- We implement DiT for **sequences** (1-D data, `(B, T, in_dim)`), not 2-D images. This is intentional: the repo already has `ViT` (image-only) and `DDPM/DenoisingUNet` (sequence-only). A sequence-DiT fills the architectural gap and is mathematically equivalent to image-DiT (the patch embed is just `(B, T, in_dim) → (B, T/patch_len, d_model)`). Users wanting image-DiT can stack their own Conv2D patch embed before the model.
- We follow the original DiT paper's adaLN-Zero formulation exactly. The "Zero" comes from initializing the final linear of the modulation MLP and the final output projection to zero, so at initialization the model is a constant function (the constant can be made to match the noise prior by setting the final layer bias to the appropriate mean). For our small test config, zero-init suffices.
- We expose `last_modulation()` so tests can verify the per-block modulation vectors.
- `DiTDiffusion::sample` uses the DDPM posterior mean formula (not DDIM) — matches what the existing `DenoisingUNet` would do, keeps the API symmetric.

## Phase 0 — Plan the gradient chain (critical, no code yet)

The diffusion-training loss is just `MSE(eps_pred, eps)`. The gradient chain we need to verify (all against centered finite differences):

1. **`training_loss(x0, t)`** = `||eps_pred(x_t, t) - noise||² / N` where `x_t = sqrt_alpha_bar_t * x0 + sqrt_one_minus_alpha_bar_t * noise`.
2. **`d_loss / d_eps_pred`** = `2/N * (eps_pred - noise)` — standard MSE.
3. **`d_loss / d_x0` (when noise is fixed)** — through the noise injection + the denoiser backward.
4. **`d_eps_pred / d_W`** — standard transformer backward through the chain (LN → MHA/MLP → adaLN modulation → final LayerNorm → final linear).
5. **`d_eps_pred / d_t`** — through the `TimeEmbedding` → `Dense` modulation chain.
6. **`d_eps_pred / d_y_class`** (when class conditioning is active) — through `LabelEmbed` → modulation.

For the adaLN-Zero modulation, the gradient chain has two paths:
- The "easy" path: modulation enters as `(1 + scale) * LN(x) + shift`, so `d_loss / d_LN_output = (1 + scale) * d_loss / d_x_after_ln`. Modulation gradients come from both the scale (multiplicative on the LN output) and the shift (additive). The gate path: `x + gate * h` → `d_gate = (d_loss / d_h) ⊙ h`, then `d_h = gate * d_loss / d_h`.

```cpp
#include "dit.h"
#include <stdexcept>

namespace nn {

DiTTimeEmbed::DiTTimeEmbed(int hidden_dim, int max_period)
    : hidden_dim_(hidden_dim), max_period_(max_period),
      mlp_in_(hidden_dim, hidden_dim),
      mlp_out_(hidden_dim, hidden_dim) {}

void DiTTimeEmbed::initialize_() {
    if (initialized_) return;
    initialized_ = true;
}

Tensor DiTTimeEmbed::forward(int t) const {
    Tensor sinusoid(1, hidden_dim_);
    for (int i = 0; i < hidden_dim_; ++i) {
        double freq_exp = static_cast<double>(i) / hidden_dim_;
        double freq = 1.0 / std::pow(max_period_, freq_exp);
        double arg = static_cast<double>(t) * freq;
        sinusoid[0][i] = (i % 2 == 0) ? std::cos(arg) : std::sin(arg);
    }
    last_sinusoidal_ = sinusoid;
    Tensor h = mlp_in_.forward(sinusoid);
    // SiLU: x * sigmoid(x)
    for (size_t i = 0; i < h.rows; ++i)
        for (size_t j = 0; j < h.cols; ++j)
            h[i][j] = h[i][j] / (1.0 + std::exp(-h[i][j]));
    Tensor out = mlp_out_.forward(h);
    return out;
}

std::vector<Tensor*> DiTTimeEmbed::parameters() {
    return {&mlp_in_.weights, &mlp_in_.bias, &mlp_out_.weights, &mlp_out_.bias};
}

std::vector<Tensor*> DiTTimeEmbed::gradients() {
    return {&mlp_in_.grad_weights, &mlp_in_.grad_bias, &mlp_out_.grad_weights, &mlp_out_.grad_bias};
}

void DiTTimeEmbed::zero_grad() {
    mlp_in_.zero_grad();
    mlp_out_.zero_grad();
}

}  // namespace nn
```

Tensor DiTLabelEmbed::forward(int class_idx) const {
    if (class_idx < 0 || class_idx > num_classes_) {
        throw std::out_of_range("DiTLabelEmbed: class_idx out of range (0=null, 1..num_classes)");

        if (class_idxs[i] < 0 || class_idxs[i] > num_classes_) {
            throw std::out_of_range("DiTLabelEmbed: class_idx out of range");

    }
    return embed_.forward(idx);

```cpp
SequencePatchEmbed::SequencePatchEmbed(int in_dim, int d_model, int patch_len)
    : in_dim_(in_dim), d_model_(d_model), patch_len_(patch_len),
      proj_(in_dim * patch_len, d_model) {}

Tensor SequencePatchEmbed::forward(const Tensor& x) const {
    int B = static_cast<int>(x.rows);
    int total = static_cast<int>(x.cols);
    if (total % (in_dim_ * patch_len_) != 0) {
        throw std::invalid_argument("SequencePatchEmbed: T*in_dim not divisible by patch_len*in_dim");
    }
    int S = total / (in_dim_ * patch_len_);
    int patch_in = in_dim_ * patch_len_;
    Tensor out(B, S * d_model_);
    for (int b = 0; b < B; ++b) {
        for (int s = 0; s < S; ++s) {
            Tensor patch(1, patch_in);
            for (int k = 0; k < patch_in; ++k) {
                patch[0][k] = x[b][s * patch_in + k];
            }
            Tensor projected = proj_.forward(patch);  // (1, d_model)
            for (int d = 0; d < d_model_; ++d) {
                out[b][s * d_model_ + d] = projected[0][d];
            }
        }
    }
    return out;
}

std::vector<Tensor*> SequencePatchEmbed::parameters() { return proj_.parameters(); }
std::vector<Tensor*> SequencePatchEmbed::gradients() { return proj_.gradients(); }
void SequencePatchEmbed::zero_grad() { proj_.zero_grad(); }

SequenceUnpatchify::SequenceUnpatchify(int d_model, int out_dim, int patch_len)
    : d_model_(d_model), out_dim_(out_dim), patch_len_(patch_len),
      proj_(d_model, out_dim * patch_len) {}

Tensor SequenceUnpatchify::forward(const Tensor& x) const {
    int B = static_cast<int>(x.rows);
    int total = static_cast<int>(x.cols);
    if (total % d_model_ != 0) {
        throw std::invalid_argument("SequenceUnpatchify: S*d_model not divisible by d_model");
    }
    int S = total / d_model_;
    int patch_out = out_dim_ * patch_len_;
    Tensor out(B, S * patch_out);
    for (int b = 0; b < B; ++b) {
        for (int s = 0; s < S; ++s) {
            Tensor tok(1, d_model_);
            for (int d = 0; d < d_model_; ++d) tok[0][d] = x[b][s * d_model_ + d];
            Tensor proj = proj_.forward(tok);  // (1, out_dim*patch_len)
            for (int k = 0; k < patch_out; ++k) {
                out[b][s * patch_out + k] = proj[0][k];
            }
        }
    }
    return out;
}

std::vector<Tensor*> SequenceUnpatchify::parameters() { return proj_.parameters(); }
std::vector<Tensor*> SequenceUnpatchify::gradients() { return proj_.gradients(); }
void SequenceUnpatchify::zero_grad() { proj_.zero_grad(); }

## Task 5: Add `DiTAdaLNZero` modulation helper and `DiTBlock`

**Objective:** Implement the canonical DiT block:

Tensor DiTBlock::forward(const Tensor& x, const Tensor& cond) {
    int B = static_cast<int>(x.rows);
    int total = static_cast<int>(x.cols);
    if (total % d_model_ != 0) {
        throw std::invalid_argument("DiTBlock: x.cols must be divisible by d_model");
    }
    int S = total / d_model_;

    // 1. Modulation
    Tensor m = modulation(cond);  // (1, 6*d_model)
    auto slice = [&](int start, int end) {
        Tensor s(1, end - start);
        for (int i = start; i < end; ++i) s[0][i - start] = m[0][i];
        return s;
    };
    Tensor shift_msa = slice(0, d_model_);
    Tensor scale_msa = slice(d_model_, 2 * d_model_);
    Tensor gate_msa = slice(2 * d_model_, 3 * d_model_);
    Tensor shift_mlp = slice(3 * d_model_, 4 * d_model_);
    Tensor scale_mlp = slice(4 * d_model_, 5 * d_model_);
    Tensor gate_mlp = slice(5 * d_model_, 6 * d_model_);

    // 2. MHA path with adaLN-Zero modulation
    // Apply LN per-token (each row of length d_model_ is a token)
    Tensor ln1_out = ln1_.forward(x);  // (B, S*d_model) — LN applied per-token
    // Apply (1 + scale_msa) * ln1_out + shift_msa
    Tensor mod1(B, S * d_model_);
    for (int b = 0; b < B; ++b)
        for (int s = 0; s < S; ++s)
            for (int d = 0; d < d_model_; ++d) {
                int idx = s * d_model_ + d;
                mod1[b][idx] = (1.0 + scale_msa[0][d]) * ln1_out[b][idx] + shift_msa[0][d];
            }

    // QKV projection (per-token)
    Tensor qkv = attn_qkv_.forward(mod1);  // (B, S*3*d_model)
    // Reshape into (B*S, 3*d_model), split Q/K/V
    // For simplicity, do single-head attention within each head dim:
    // We'll use a simple per-head split.
    int head_dim = d_model_ / n_heads_;
    Tensor attn_out(B, S * d_model_);
    attn_out = Tensor::zeros(B, S * d_model_);
    // For each batch and each query position, compute Q · K^T / sqrt(d_k) per head
    Tensor Q = Tensor::zeros(B * S, d_model_);
    Tensor K = Tensor::zeros(B * S, d_model_);
    Tensor V = Tensor::zeros(B * S, d_model_);
    for (int b = 0; b < B; ++b)
        for (int s = 0; s < S; ++s) {
            for (int d = 0; d < d_model_; ++d) {
                Q[b * S + s][d] = qkv[b][s * 3 * d_model_ + d];
                K[b * S + s][d] = qkv[b][s * 3 * d_model_ + d_model_ + d];
                V[b * S + s][d] = qkv[b][s * 3 * d_model_ + 2 * d_model_ + d];
            }
        }
    // Per-head attention (single batch, no batching across heads for simplicity)
    double scale = 1.0 / std::sqrt(static_cast<double>(head_dim));
    for (int b = 0; b < B; ++b) {
        for (int h = 0; h < n_heads_; ++h) {
            // For each query in this batch, compute attention over the S keys in this batch
            for (int sq = 0; sq < S; ++sq) {
                std::vector<double> scores(S);
                double max_s = -1e30;
                for (int sk = 0; sk < S; ++sk) {
                    double dot = 0;
                    for (int d = 0; d < head_dim; ++d) {
                        dot += Q[b * S + sq][h * head_dim + d] * K[b * S + sk][h * head_dim + d];
                    }
                    scores[sk] = dot * scale;
                    if (scores[sk] > max_s) max_s = scores[sk];
                }
                double sum_exp = 0;
                for (int sk = 0; sk < S; ++sk) {
                    scores[sk] = std::exp(scores[sk] - max_s);
                    sum_exp += scores[sk];
                }
                for (int sk = 0; sk < S; ++sk) scores[sk] /= sum_exp;
                for (int d = 0; d < head_dim; ++d) {
                    double v = 0;
                    for (int sk = 0; sk < S; ++sk) {
                        v += scores[sk] * V[b * S + sk][h * head_dim + d];
                    }
                    attn_out[b][sq * d_model_ + h * head_dim + d] = v;
                }
            }
        }
    }
    // Output projection
    Tensor attn_proj = attn_o_.forward(attn_out);  // (B, S*d_model)
    last_attn_out_ = attn_proj;
    // Apply gate_msa and add to x
    Tensor h1(B, S * d_model_);
    for (int b = 0; b < B; ++b)
        for (int s = 0; s < S; ++s)
            for (int d = 0; d < d_model_; ++d) {
                int idx = s * d_model_ + d;
                h1[b][idx] = x[b][idx] + gate_msa[0][d] * attn_proj[b][idx];
            }

    // 3. MLP path with adaLN-Zero modulation
    Tensor ln2_out = ln2_.forward(h1);
    Tensor mod2(B, S * d_model_);
    for (int b = 0; b < B; ++b)
        for (int s = 0; s < S; ++s)
            for (int d = 0; d < d_model_; ++d) {
                int idx = s * d_model_ + d;
                mod2[b][idx] = (1.0 + scale_mlp[0][d]) * ln2_out[b][idx] + shift_mlp[0][d];
            }
    Tensor mlp_h = mlp_w1_.forward(mod2);  // (B, S*mlp_dim)
    // GELU
    for (size_t i = 0; i < mlp_h.rows; ++i)
        for (size_t j = 0; j < mlp_h.cols; ++j)
            mlp_h[i][j] = GELU()(mlp_h[i][j]);
    Tensor mlp_out = mlp_w2_.forward(mlp_h);  // (B, S*d_model)
    last_mlp_out_ = mlp_out;
    // Apply gate_mlp and add to h1
    Tensor out(B, S * d_model_);
    for (int b = 0; b < B; ++b)
        for (int s = 0; s < S; ++s)
            for (int d = 0; d < d_model_; ++d) {
                int idx = s * d_model_ + d;
                out[b][idx] = h1[b][idx] + gate_mlp[0][d] * mlp_out[b][idx];
            }
    return out;
}

Tensor DiT::forward_with_cond(const Tensor& x, const Tensor& cond) {
    int B = static_cast<int>(x.rows);
    Tensor h = patch_embed_.forward(x);  // (B, S*d_model)
    int S = static_cast<int>(h.cols) / d_model_;
    for (int i = 0; i < depth_; ++i) {
        h = blocks_[i]->forward(h, cond);
    }
    // Final LN per-token
    h = final_ln_.forward(h);
    // Final linear (applied per-token: reshape to (B*S, d_model), project, reshape back)
    Tensor h_flat(B * S, d_model_);
    for (int b = 0; b < B; ++b)
        for (int s = 0; s < S; ++s)
            for (int d = 0; d < d_model_; ++d)
                h_flat[b * S + s][d] = h[b][s * d_model_ + d];
    Tensor proj_flat = final_linear_.forward(h_flat);  // (B*S, in_dim*patch_len)
    Tensor h_proj(B, S * (in_dim_ * patch_len_));
    for (int b = 0; b < B; ++b)
        for (int s = 0; s < S; ++s)
            for (int k = 0; k < in_dim_ * patch_len_; ++k)
                h_proj[b][s * (in_dim_ * patch_len_) + k] = proj_flat[b * S + s][k];
    Tensor out = unpatchify_.forward(h_proj);  // (B, T*in_dim)
    return out;
}

Tensor DiT::forward(const Tensor& x, int t, int class_idx) {
    Tensor t_emb = time_embed_.forward(t);  // (1, d_model)
    Tensor cond(1, cond_dim_);
    // First d_model = time embedding, last d_model = class embedding (or zero)
    for (int i = 0; i < d_model_; ++i) cond[0][i] = t_emb[0][i];
    if (label_embed_ != nullptr) {
        Tensor y_emb = label_embed_->forward(class_idx < 0 ? 0 : class_idx);
        for (int i = 0; i < d_model_; ++i) cond[0][d_model_ + i] = y_emb[0][i];
    } else {
        for (int i = 0; i < d_model_; ++i) cond[0][d_model_ + i] = 0.0;
    }
    return forward_with_cond(x, cond);
}

    : dit_(d_model, depth, n_heads, in_dim, patch_len, num_classes, mlp_ratio),
      scheduler_(T, beta_start, beta_end),

Tensor DiTDiffusion::add_noise(const Tensor& x0, int t, const Tensor& noise) const {
    return scheduler_.q_sample(x0, t, noise);
}

double DiTDiffusion::training_loss(const Tensor& x0, int t, int class_idx) {
    int B = static_cast<int>(x0.rows);
    int D = static_cast<int>(x0.cols);
    std::mt19937 noise_rng(static_cast<unsigned>(t) * 1000u + 7u);
    std::normal_distribution<double> nd(0.0, 1.0);
    Tensor noise(B, D);
    for (size_t i = 0; i < noise.rows * noise.cols; ++i) (&noise[0][0])[i] = nd(noise_rng);
    Tensor x_t = scheduler_.q_sample(x0, t, noise);
    Tensor eps_pred = dit_.forward(x_t, t, class_idx);
    // MSE loss: mean over (B, D) of (eps_pred - noise)^2
    double sum = 0.0;
    for (size_t i = 0; i < eps_pred.rows * eps_pred.cols; ++i) {
        double diff = (&eps_pred[0][0])[i] - (&noise[0][0])[i];
        sum += diff * diff;
    }
    double loss = sum / static_cast<double>(B * D);
    last_x0_ = x0;
    last_noise_ = noise;
    last_x_t_ = x_t;
    last_eps_pred_ = eps_pred;
    last_t_ = t;
    last_class_idx_ = class_idx;
    // Pre-compute gradient of loss w.r.t. eps_pred: 2/N * (eps_pred - noise)
    last_grad_eps_pred_ = Tensor(B, D);
    for (size_t i = 0; i < eps_pred.rows * eps_pred.cols; ++i) {
        double diff = (&eps_pred[0][0])[i] - (&noise[0][0])[i];
        (&last_grad_eps_pred_[0][0])[i] = 2.0 / static_cast<double>(B * D) * diff;
    }
    return loss;
}

void DiTDiffusion::backward(double lr) {
    // The gradient of loss w.r.t. eps_pred is last_grad_eps_pred_ (MSE grad).
    // The DiT's backward returns grad_input. We discard grad_input (we have x0, not x_t).
    dit_.backward_with_loss_grad(last_grad_eps_pred_, lr);
    // For now, the DiT placeholder in earlier tasks needs to support backward_with_loss_grad.
    // We'll add it as a method that does backward() returning the input grad (not used).
}

Tensor DiTDiffusion::sample(int B, int n_steps, int class_idx, unsigned int seed) {
    if (n_steps < 0) n_steps = T_;
    if (T_ % n_steps != 0) {
        throw std::invalid_argument("DiTDiffusion::sample: n_steps must divide T");
    }
    int step_size = T_ / n_steps;
    int D_in = static_cast<int>(last_x0_.cols);  // need a way to get input dim
    // Re-derive input dim from dit_'s in_dim and the (T*in_dim) layout.
    // We assume the user has called training_loss at least once with a known D_in.
    if (last_x0_.rows == 0) {
        throw std::logic_error("DiTDiffusion::sample: call training_loss first to cache the input shape");
    }
    int D = static_cast<int>(last_x0_.cols);
    std::normal_distribution<double> nd(0.0, 1.0);
    std::mt19937 rng(seed);
    Tensor x(B, D);
    for (size_t i = 0; i < x.rows * x.cols; ++i) (&x[0][0])[i] = nd(rng);
    for (int step = 0; step < n_steps; ++step) {
        int t = T_ - 1 - step * step_size;
        Tensor eps_pred = dit_.forward(x, t, class_idx);
        // DDPM posterior mean formula:
        float alpha_bar_t = scheduler_.sqrt_alphas_cumprod(t) * scheduler_.sqrt_alphas_cumprod(t);
        float alpha_bar_tm1 = (t - step_size >= 0)
            ? scheduler_.sqrt_alphas_cumprod(t - step_size) * scheduler_.sqrt_alphas_cumprod(t - step_size)
            : 1.0f;
        float beta_t = scheduler_.betas[t];
        float alpha_t = 1.0f - beta_t;
        float sqrt_recip_alpha_t = scheduler_.sqrt_recip_alphas(t);
        // predicted x0 from eps_pred: x0_pred = (x - sqrt(1-alpha_bar_t)*eps) / sqrt(alpha_bar_t)
        for (size_t i = 0; i < x.rows * x.cols; ++i) {
            double xi = (&x[0][0])[i];
            double ei = (&eps_pred[0][0])[i];
            double x0_pred = (xi - std::sqrt(1.0 - alpha_bar_t) * ei) / std::sqrt(alpha_bar_t);
            // posterior mean = (sqrt(alpha_bar_{t-1}) * beta_t / (1 - alpha_bar_t)) * x0_pred
            //                + (sqrt(alpha_t) * (1 - alpha_bar_{t-1}) / (1 - alpha_bar_t)) * x
            double mean = (std::sqrt(alpha_bar_tm1) * beta_t / (1.0f - alpha_bar_t)) * x0_pred
                        + (std::sqrt(alpha_t) * (1.0f - alpha_bar_tm1) / (1.0f - alpha_bar_t)) * xi;
            (&x[0][0])[i] = mean;
        }
        // Add noise if not at t=0
        if (t > 0) {
            float post_var = scheduler_.posterior_variance(t);
            double std_dev = std::sqrt(post_var);
            for (size_t i = 0; i < x.rows * x.cols; ++i) {
                (&x[0][0])[i] += std_dev * nd(rng);
            }
        }
    }
    return x;
}
```
