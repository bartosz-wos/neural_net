## Paper specification (verified against arXiv:2201.03545)

§2.1, Eq. (1) — the ConvNeXt block, *isotropic* variant:

```
x_in                                  shape (N, C, H, W)
x     ← x_in + γ ⊙ f( LN(x_in) )      residual branch, γ = per-channel LayerScale
f(u)  = pwconv2( GELU( pwconv1( LN( dwconv7×7(u) ) ) ) )
pwconv1 : C → 4C   (1×1 conv, WITH bias)
pwconv2 : 4C → C   (1×1 conv, WITH bias)
dwconv  : C → C    (7×7 depthwise, NO bias, stride 1, pad 3)
γ init  = 1e-6   (paper: "initialize to small values"; 1e-6 for the 100M-param models)
```

Note the residual placement: `x = x_in + γ ⊙ f(LN(x_in))`. The **LayerNorm is inside the
residual branch** (post-norm, ResNet-v2 style) and the **dwconv comes before the LN**,
both of which are easy to get backwards. `dwconv` has no bias in the reference; both
pointwise convs do.

§2.2 — LayerScale is `γ ∈ R^C` per channel, applied to the residual branch *before* the
add. The repo already ships `LayerScale` (Cai et al. ICCV 2022) with exactly this
semantics, so this plan **reuses it rather than re-deriving it**.

§3, Table 11 (isotropic `ConvNeXt-B`): stem = 4×4 conv stride 4; stages
`[3, 96] [3, 192] [9, 384] [3, 768]`; downsampling = LayerNorm → 2×2 conv stride 2;
head = LayerNorm → GAP → linear.

**v1 simplifications (documented, not bugs):** isotropic only (no FLOPs-shaped ratios
of §3.2), no layer-scale/drop-path schedules (§4.1), no stochastic depth, no
`trunc_normal_(std=0.02)` init (Xavier via `Dense` is used instead — and note that
**zero-initialising `pwconv2` would make every gradient check on it vacuous**, since
`dL/dx_in` through the block would be identically zero at init, so the paper's init is
deliberately *not* replicated).

## Convention notes for this repo

- Flat tensor `(N, C*H*W)`, index `c*H*W + h*W + w` (this is `Conv2D`'s layout —
  see `Conv2D::im2col`, `input[n][c * H * W + h * W + w]`).
- `Dense` computes `y = x·Wᵀ + b` with `W ∈ R^{(out, in)}`; because matmul is
  row-independent, a `Dense(C, 4C)` over `(N, C*H*W)` **is** a 1×1 convolution over
  `N*H*W` spatial positions. This is the repo's established 1×1-conv idiom.
- `Layer` requires: `forward`, `backward(grad_output, lr)`, `update_weights(lr)`,
  `get_weights`, `get_gradients`, `parameters`, `gradients`, `zero_grad`, `name`.
- `Conv2D::backward` **accumulates** into `grad_weights` (`grad_weights = grad_weights + dW`),
  and its `update_weights` zeroes `grad_weights` afterwards. `DepthwiseSeparableConv`
  works around this by calling `pointwise_conv_.update_weights` inside its own
  `backward`. **`ConvNeXtBlock` must not do either** — it will call
  `sublayer.backward(grad, 0.0)` and update in its own `update_weights(lr)`, matching
  `ResBlock` (see `resnet.cpp:31`).
- Depthwise convolution: no single class exists. `DepthwiseSeparableConv` implements
  depthwise as **one `Conv2D(1,1,...)` per channel** (`depthwise_separable_conv.cpp:34`).
  `ConvNeXtBlock` follows the same established pattern.

```cpp
Tensor ChannelLayerNorm2D::forward(const Tensor& input) {
    const size_t N = input.rows;
    const size_t S = H_ * W_;
    if (input.cols != channels_ * S) throw std::invalid_argument(
        "ChannelLayerNorm2D::forward: expected cols = C*H*W");
    last_x = input;
    last_xhat = Tensor(N, S * channels_);
    last_inv_std = Tensor(N, S);
    Tensor out(N, channels_ * S);
    for (size_t n = 0; n < N; ++n) {
        for (size_t s = 0; s < S; ++s) {
            double mean = 0.0;
            for (size_t c = 0; c < channels_; ++c) mean += input[n][c * S + s];
            mean /= channels_;
            double var = 0.0;
            for (size_t c = 0; c < channels_; ++c) {
                double d = input[n][c * S + s] - mean; var += d * d;
            }
            var /= channels_;
            double inv = 1.0 / std::sqrt(var + eps);
            last_inv_std[n][s] = inv;
            for (size_t c = 0; c < channels_; ++c) {
                double xhat = (input[n][c * S + s] - mean) * inv;
                last_xhat[n][c * S + s] = xhat;
                out[n][c * S + s] = gamma[0][c] * xhat + beta[0][c];
            }
        }
    }
    return out;
}
```

```cpp
// loss = 0.5 * sum(y^2) with y = forward(x); grad_y = y (cheap, no extra cache)
static double ln_loss(ChannelLayerNorm2D& l, const Tensor& x) {
    Tensor y = l.forward(x); double s = 0.0;
    for (size_t i=0;i<y.rows;++i) for (size_t j=0;j<y.cols;++j) s += y[i][j]*y[i][j];
    return 0.5 * s;
}
static double fd_ln_input(ChannelLayerNorm2D& l, const Tensor& x, size_t i, size_t j, double eps) {
    Tensor p = x; p[i][j] += eps; double lp = ln_loss(l, p);
    p = x; p[i][j] -= eps; double lm = ln_loss(l, p);
    return (lp - lm) / (2.0 * eps);
}
static double fd_ln_param(ChannelLayerNorm2D& l, Tensor& par, size_t i, size_t j,
                          const Tensor& x, double eps) {
    double o = par[i][j];
    par[i][j] = o + eps; double lp = ln_loss(l, x);
    par[i][j] = o - eps; double lm = ln_loss(l, x);
    par[i][j] = o;
    return (lp - lm) / (2.0 * eps);
}
```

```cpp
Tensor ChannelLayerNorm2D::backward(const Tensor& grad_output, double /*lr*/) {
    const size_t N = grad_output.rows;
    const size_t S = H_ * W_;
    if (grad_output.cols != channels_ * S) throw std::invalid_argument(
        "ChannelLayerNorm2D::backward: expected cols = C*H*W");

    // zero_grad() zeroes the buffers; backward accumulates into them so that
    // multiple backward() calls before one update_weights() sum correctly.
    Tensor dxhat(N, channels_ * S);
    for (size_t c = 0; c < channels_; ++c) {
        double gg = 0.0, gb = 0.0;
        for (size_t n = 0; n < N; ++n) {
            for (size_t s = 0; s < S; ++s) {
                const double go = grad_output[n][c*S+s];
                gg += go * last_xhat[n][c*S+s];
                gb += go;
            }
        }
        grad_gamma[0][c] += gg;
        grad_beta[0][c]  += gb;
    }
    for (size_t n = 0; n < N; ++n) {
        for (size_t s = 0; s < S; ++s) {
            double inv = last_inv_std[n][s];
            // dMean and dXhatCross are reductions over the CHANNEL axis only.
            double dMean = 0.0, dXhatCross = 0.0;
            for (size_t c = 0; c < channels_; ++c) {
                const double dh = grad_output[n][c*S+s] * gamma[0][c];
                dxhat[n][c*S+s] = dh;
                dMean       += dh;
                dXhatCross  += dh * last_xhat[n][c*S+s];
            }
            dMean /= channels_;
            dXhatCross /= channels_;
            for (size_t c = 0; c < channels_; ++c) {
                last_dxhat[n][c*S+s] = inv * (dxhat[n][c*S+s] - dMean
                                             - last_xhat[n][c*S+s] * dXhatCross);
            }
        }
    }
    return last_dxhat;
}
```

Forward (order is the paper's, §2.1):
```cpp
Tensor ConvNeXtBlock::forward(const Tensor& input) {
    last_input_ = input;
    const size_t S = H_ * W_;
    // (1) depthwise 7x7 over the C channels, no bias, stride 1, pad kernel/2
    Tensor u = depthwise_forward(input);              // (N, C*S)
    // (2) ChannelLayerNorm2D
    u = ln_.forward(u);
    // (3) pwconv1 : C -> 4C  (1x1 conv == Dense over N*S rows)
    u = pwconv1_.forward(u);
    // (4) GELU
    u = gelu_forward(u);
    // (5) pwconv2 : 4C -> C
    u = pwconv2_.forward(u);
    // (6) gamma scale (LayerScale over the C channels)
    u = gamma_.forward(u);
    // (7) residual add
    Tensor out = input;
    for (size_t i=0;i<out.rows;++i) for (size_t j=0;j<out.cols;++j) out[i][j] += u[i][j];
    return out;
}
```
`depthwise_forward` loops channels, extracts `(N, S)`, calls `dw_[c].forward`, scatters
back — the exact structure of `DepthwiseSeparableConv::forward`
(`depthwise_separable_conv.cpp:79-99`), minus the pointwise stage. `gelu_forward` uses
`GELU` from `activations/activations.h`.

```cpp
static double blk_loss(ConvNeXtBlock& b, const Tensor& x) {
    Tensor y = b.forward(x); double s=0.0;
    for (size_t i=0;i<y.rows;++i) for (size_t j=0;j<y.cols;++j) s += y[i][j]*y[i][j];
    return 0.5*s;
}
static double fd_blk_input(ConvNeXtBlock& b, const Tensor& x, size_t i, size_t j, double eps) {
    Tensor p = x; p[i][j]+=eps; double lp=blk_loss(b,p);
    p = x; p[i][j]-=eps; double lm=blk_loss(b,p);
    return (lp-lm)/(2.0*eps);
}
static double fd_blk_param(ConvNeXtBlock& b, Tensor& par, size_t i, size_t j,
                           const Tensor& x, double eps) {
    double o=par[i][j];

    par[i][j]=o-eps; double lm=blk_loss(b,x);
    par[i][j]=o;

}
```

```cpp
Tensor ConvNeXtBlock::backward(const Tensor& grad_output, double /*lr*/) {
    Tensor g = grad_output;                       // (7) residual add: d/dx_in += g
    g = gamma_.backward(g, 0.0);                  // (6)
    g = pwconv2_.backward(g, 0.0);                // (5)
    g = gelu_backward(g, cached_pre_gelu);        // (4)
    g = pwconv1_.backward(g, 0.0);                // (3)
    g = ln_.backward(g, 0.0);                     // (2)
    Tensor g_dw = depthwise_backward(g, 0.0);     // (1)
    for (size_t i=0;i<g.rows;++i)                  // residual path into the dwconv input
        for (size_t j=0;j<g.cols;++j) g_dw[i][j] += grad_output[i][j];
    return g_dw;
}
```
