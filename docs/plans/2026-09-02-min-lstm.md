# MinLSTM Implementation Plan

> **For Hermes:** implement task-by-task with strict TDD (RED → GREEN → verify).

**Goal:** Add `MinLSTM` (Feng et al. 2024, "Were RNNs All We Needed?", https://arxiv.org/abs/2410.01201, Algorithm 3) — the minimalist LSTM companion to the already-shipped `MinGRU`.

**Architecture:** A per-channel linear recurrence with **two** input-only gates (forget + input) that are **normalized to sum to 1**, making the recurrence a convex combination and thus time-independent in scale (the paper's key stability trick, distinguishing MinLSTM from MinGRU's single gate). No hidden-to-hidden weights → parallel-scan-friendly.

**Tech Stack:** C++17, hand-rolled `Tensor`, `Layer` base class. Mirrors `include/nn/layers/recurrent/min_gru.{h,cpp}` conventions exactly.

## Math

Per timestep `t` (all products element-wise, per hidden channel):

```
z_f_t = W_f · x_t + b_f          f_t = sigmoid(z_f_t)
z_i_t = W_i · x_t + b_i          i_t = sigmoid(z_i_t)
c_t   = W_h · x_t + b_h                              (candidate, no nonlinearity)

s_t  = f_t + i_t
f'_t = f_t / s_t                 i'_t = i_t / s_t     (f'_t + i'_t == 1 exactly)

h_t = f'_t ⊙ h_{t-1} + i'_t ⊙ c_t
```

Contrast with `MinGRU`: `h_t = (1 - g_t) ⊙ h_{t-1} + g_t ⊙ c_t` — a single gate. MinLSTM
learns forget and input strengths independently and then normalizes.

### Backward (per timestep, `gh = dL/dh_t`)

```
df'  = gh ⊙ h_{t-1}
di'  = gh ⊙ c_t
dc   = gh ⊙ i'_t
dh_prev(direct) = gh ⊙ f'_t

∂f'/∂f =  i/s²    ∂f'/∂i = -f/s²
∂i'/∂f = -i/s²    ∂i'/∂i =  f/s²

df = (i/s²) · (df' - di')
di = (f/s²) · (di' - df')

dz_f = df ⊙ f ⊙ (1-f)
dz_i = di ⊙ i ⊙ (1-i)

grad_W_f += x_t ⊗ dz_f ; grad_b_f += dz_f
grad_W_i += x_t ⊗ dz_i ; grad_b_i += dz_i
grad_W_h += x_t ⊗ dc   ; grad_b_h += dc
grad_x_t  = dz_f · W_f^T + dz_i · W_i^T + dc · W_h^T
```

Note the antisymmetry `df ∝ (df' - di')`, `di ∝ -(df' - di')·(f/i)`-style structure — a
direct consequence of the normalization. **If both gates receive equal upstream gradient
(`df' == di'`), both gate gradients are exactly zero** — this is a good non-vacuous
signature test for the normalization chain.

## Tasks

### Task 1: Write `tests/test_min_lstm.cpp` (RED)

Mirror `tests/test_min_gru.cpp` structure (relative_error helper, l2_loss_value / l2_loss_grad,
`total`/`passed` counters, `=== Summary: N passed, M failed ===`).

Tests:
1. Constructor validation — `input_dim=0` and `hidden_size=0` both throw.
2. Forward shape `(T, input_dim) -> (T, hidden_size)`.
3. Forward finite for T=4 with mixed-sign inputs.
4. **Gate normalization invariant: `f'_t + i'_t == 1` to machine precision for every (t, channel).**
5. Hand-derived reference (T=1, input_dim=1, hidden=1) with forced weights.
6. Input gradient FD check (T=3).
7. `W_f` gradient FD check.
8. `W_i` gradient FD check.
9. `W_h` gradient FD check.
10. `b_f` / `b_i` / `b_h` gradient FD checks.
11. `zero_grad` clears all 6 gradients.
12. `update_weights` moves all 6 parameters.
13. Training reduces loss over 80 SGD steps.
14. Longer sequence (T=6) input gradient FD check (deeper BPTT).
15. **Signature test vs MinGRU: equal-gate symmetry.** With `W_f == W_i` and `b_f == b_i`,
    `f'_t == i'_t == 0.5` for all t, so `h_t = 0.5·h_{t-1} + 0.5·c_t` — assert against a
    hand-computed EMA. This distinguishes MinLSTM from any single-gate reduction.
16. `parameters()`/`gradients()` return 6 tensors each with matched shapes.

**All FD checks must use random (non-uniform) init** — the default Xavier init in
`init_weights()` satisfies this; do NOT overwrite with a constant fill in FD tests
(uniform init hides row-vs-column confusion in the `W ⊗ dz` accumulation).
