# RWKV-6 (Finch) Implementation Plan

> **For Hermes:** TDD, single-shot, full BPTT.

**Goal:** Implement Peng et al. 2024 "Eagle and Finch: RWKV with Matrix-Valued States and Dynamic Recurrence" (https://arxiv.org/abs/2404.05892), specifically **Finch (RWKV-6) time-mixing**, as a single Layer `RWKV6TimeMix` in `include/nn/layers/recurrent/rwkv6.{h,cpp}` with a focused test suite and full registration in the umbrella `nn.h` and Makefile.

**Architecture:** Single class `RWKV6TimeMix(d, num_heads=1, num_lora_ranks=32)` that mirrors the existing `RWKV7TimeMix`. Mirrors repo convention: time-mix only (channel-mix left for follow-up, consistent with the existing `RWKV4TimeMix` and `RWKV7TimeMix` v1 scope).

**Tech Stack:** C++17, existing `Tensor`, `Layer`, `Dense`. Multi-head matrix-valued state `s_t ∈ R^{num_heads × m × m}` where `m = d/num_heads`.

## Math (RWKV-6 / Finch)

Per head `h`, head_dim `m = d / num_heads`.

### DD-Lerp (data-dependent linear interpolation, Eq. 14–15)

```
lora_□(x) = λ_□ + tanh(x · A_□) · B_□     for □ ∈ {r, k, v, g, d, x}
                                              where A_□ : (d, R), B_□ : (R, d), λ_□ : (1, d), R = num_lora_ranks
                                              (For the special d LoRA we use R' = 2*R per Appendix I.)
ddlerp_□(a, b) = a + (b − a) ⊙ lora_□(a + (b − a) ⊙ µ_x)    (Eq. 15)
```

`µ_x ∈ R^d` is a learned shared base token-shift (initialized per Finch appendix I).

### Token-shift outputs (Eq. 16)

```
□_t = ddlerp_□(x_t, x_{t−1}) · W_□   for □ ∈ {r, k, v, g}
```

### Decay (Eq. 17–18) — **time-varying** (the key Finch innovation)

```
d_t = lorad(ddlerpd(x_t, x_{t−1}))     (single channel-wise projection)
w_t = exp(−exp(d_t))                   ∈ (0, 1)^d
```

(Note: per appendix I, the d-direction LoRA uses 2× ranks. We follow.)

### WKV (Eq. 19, 21–22, recurrent form)

```
kv_t = k_t^T · v_t                       ∈ R^{m × m}     (m × m outer product, not per-head outer)
s_t  = diag(w_t[h]) · s_{t−1} + kv_t    ∈ R^{m × m}
wkv_t = s_t + diag(u[h]) · kv_t          ∈ R^{m × m}     (bonus via diag(u))
o_t[h, j] = Σ_i r_t[h, i] · wkv_t[h, i, j]    ∈ R^m
```

### Output (Eq. 20)

```
out_t = concat_h(SiLU(g_t[h]) ⊙ LN_h(r_t · wkv_t)) · W_o
```

Where `LN_h` is per-head GroupNorm (paper §4.1.2: "LayerNorm operates on each of h heads separately, equivalent to GroupNorm on h groups"). For v1 we apply per-head mean-center + scale (true LayerNorm within each head's `m` channels) with no learnable gamma/beta (or with a single scalar gamma/beta per head — we'll match the existing rwkv4/rwkv7 no-LayerNorm convention to keep the gradient check tractable).

### Initializations (Appendix I)

- `µ_x ∈ R^d`: `1 − (i / D)^r1`
- `λ_□ ∈ R^d`: 0 (LoRA path is inactive at init → Finch reduces to Eagle-style token-shift at start)
- `A_□` and `B_□`: `U(−10^{-4}, 10^{-4})`
- `W_r`, `W_k`, `W_v`, `W_g`, `W_d`: xavier-uniform
- `b_r`, `b_k`, `b_v`, `b_g`, `b_d`: 0
- `u ∈ R^d`: `r0 · (1 − i / (D − 1)) + 0.1·((i + 1) mod 3)` (Eagle convention; r0 = l / (L − 1) — for v1 we use r0 = 0.5)

### State

`s_t ∈ R^{num_heads × m × m}`. Cached as `(T+1, num_heads · m · m)` row-major.

## TDD Cycles (overview)

Each task is RED → GREEN → REFACTOR. Tasks below are 2–5 minutes each.

### Task 1: Header + skeleton
Write `rwkv6.h` with class declaration, all parameter fields, all `last_*` cache fields. Stubbed `forward` / `backward` / `update_weights` / `zero_grad` / `parameters` / `gradients` to compile. Place a trivial `name() == "RWKV6TimeMix"` assertion and a constructor-validation test (5 cases).

### Task 2: Forward, no LoRA (just DD-Lerp disabled — Finch at LoRA-zero == Eagle)
Set all LoRA `A_□`, `B_□` to zero → `lora_□(x) ≡ λ_□`. Then `ddlerp_□(a, b) = a + (b − a) ⊙ λ_□`. If we additionally set `λ_□ = µ_□`, this is the standard lerp token-shift, the same as `RWKV4TimeMix`'s μ_□ token shift.

Test: at LoRA-disabled + `λ_□ = µ_□`, Finch's `r_t`, `k_t`, `v_t`, `g_t` match the output of a manually-computed Eagle / RWKV-4-style projection.

### Task 3: Forward — full math (Eq. 16–22)
Implement the full forward, including LoRA, time-varying w_t, recurrent state, and output projection.

Tests:
- Forward shape `(T, d) → (T, d)`, finite, nonzero.
- `T=1` reference: hand-derived closed-form (`s_0 = 0`, `wkv_0 = diag(u)·k_0^T·v_0`, `o_0 = r_0·wkv_0`) matches to rel_err < 1e-12.
- Output all-zero at init: at `W_o = 0` (initialization), `out ≡ 0` to < 1e-15.

### Task 4: Backward — input gradient
Hand-derived BPTT through the recurrent state. dL/dx_t computed from the full chain.

Tests:
- `T=1`: input gradient matches FD to < 1e-7.
- `T=3`: input gradient matches FD to < 1e-5.

### Task 5: Backward — parameter gradients
Hand-derived gradients for `W_r`, `W_k`, `W_v`, `W_g`, `W_d`, `W_o`, `A_*`, `B_*`, `λ_*`, `µ_x`, `u`.

Tests:
- Each parameter gradient matches FD to < 1e-5.

### Task 6: Backward — stateful / long sequences
- `T=6` input gradient matches FD.
- `T=8` input gradient matches FD with non-uniform init.

### Task 7: Mutation test
- Verify that zeroing `A_r.weights` (LoRA-r) changes the output (proves the LoRA path is actually wired).
- Verify that zeroing `b_d` (decay bias) changes `w_t` (proves decay chain).
- Verify that zeroing `u` removes the `diag(u)` bonus.

### Task 8: Training reduces loss
End-to-end training on a small regression target: `out_t → target_t` MSE for `T=4`, `d=8`. 50 SGD steps with `lr=0.01`. Assert loss decreases > 30%.

### Task 9: Determinism
Forward is bit-exact across two consecutive calls with same input and copied state.

### Task 10: zero_grad / update_weights
Verify all 21 parameters (4 W_□ + 4 b_□ + W_o + b_o + u + 5 A_□ + 5 B_□ + 5 λ_□ + µ_x + lorad_A + lorad_B + W_d... +b_d) move and that zero_grad clears them.

### Task 11: Registration
Add `#include` to `include/nn/nn.h`. Add `build/test_rwkv6` rule to Makefile. Add to `tests:` deps. Add `@echo "=== Running RWKV-6 Tests ===" && ./build/test_rwkv6` to `run_tests`.

### Task 12: Full test suite — no regressions
Run `make run_tests`. Verify no existing test breaks. Commit and push.
