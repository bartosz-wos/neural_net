# Griffin Hybrid Block Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add the full Griffin architecture (De et al. 2024, https://arxiv.org/abs/2402.19427) as a hybrid sequence block — gated linear recurrence (Hawk/RG-LRU) interleaved with local windowed attention and a residual MLP — with full analytical backward and machine-precision gradient checks.

**Architecture:** `GriffinBlock(d_model, num_heads, window_size, ffn_mult)` composes four sublayers via pre-norm residuals: (1) Hawk (RG-LRU) gated linear recurrence, (2) local sliding-window attention (causal, depthwise QKV projection + softmax within window), (3) dense GELU FFN, (4) the canonical Griffin residual scheme with `out = h + MLP(h) + Hawk(h) + Attn(h)` (parallel, NOT sequential). A `GriffinModel(input_dim, d_model, output_dim, num_layers, num_heads, window_size, ffn_mult)` stacks N GriffinBlocks + final classifier. Tests verify forward shape, analytical-vs-FD gradients at machine precision across the residual chain, and end-to-end training convergence.

**Tech Stack:** Existing infra — `Layer`/`Tensor`/`Dense` from core, reuses Hawk (`include/nn/layers/recurrent/hawk.h`), LayerNorm (`include/nn/layers/normalization/layer_norm.h`), Conv1D optional for local attention implementation. Activations: GELU. SGD optimizer.

## Background

The Griffin paper (De et al. 2024) introduces a hybrid sequence architecture combining:
1. **Hawk / RG-LRU** — gated linear recurrence (already implemented at `include/nn/layers/recurrent/hawk.{h,cpp}` as `HawkBlock`, 130/130 tests pass at machine precision).
2. **Local sliding-window attention** — short-window causal attention that captures the local patterns attention is good at.
3. **MLP** — standard GELU FFN for capacity.

Critically: the three sublayers are **combined in parallel** via residual addition, NOT sequentially. This is one of the key architectural distinctions from Jamba (which is sequential: SSM → Attn → FFN). The canonical Griffin block:

```
h = Hawk(LN_1(x)) + Attn_local(LN_2(x)) + MLP(LN_3(x))
out = x + h
```

Each sublayer operates on a pre-norm of x and the three outputs are summed into a single residual stream. (The original paper uses ONE shared LayerNorm across the three sublayers, but a 3-norm variant is also fine; we follow the canonical "single LN feeding three parallel branches" interpretation for fidelity to the paper.)

## Why Griffin is interesting

- Closes out the Griffin paper; we already have Hawk, we just need the parallel-composition block + local attention + MLP
- Different from Jamba's sequential hybrid — Griffin is parallel, Jamba is sequential
- The local-attention primitive is itself a useful addition (could power other architectures)
- Tests will stress the parallel-residual backward chain (3 separate paths summing into one gradient)

## Conventions

- `Layer` interface: `forward(T, d) → (T, d)`, `backward(grad_out, lr) → grad_in`, all in (T, d_model) layout
- Public members following the Hawk style (so tests can poke at caches directly)
- (T, d) input/output layout (T = time, d = features)

## Implementation tasks

Each task is sized for one TDD cycle: write failing test, watch fail, write minimal code, watch pass.

### Task 1: Header skeleton + test scaffold

**Step 1:** Write `tests/test_griffin.cpp` with the empty main + a `test_constructor_validates_dims` that fails (no header → compile error).

**Step 2:** Create `include/nn/layers/architectures/griffin.h` with class declarations but throwing `std::logic_error("not implemented")` for `forward/backward`. Confirm compile and the test reports "feature missing".

**Step 3:** Add `GriffinBlock` to `nn.h` umbrella and add Makefile rule. Confirm `make build/test_griffin` succeeds (compiles, links).

### Task 2: Forward shape + finiteness

**Test:** forward((T=4, d=8)) returns (4, 8), all finite, nonzero.

**Implement:** minimal forward — three separate paths summed with residual.

### Task 3: Local attention sublayer

**Test:** `LocalSlidingWindowAttention(d=4, window_size=3)` forward shape (T=5, 4) → (5, 4), finite, nonzero.

**Implement:** depthwise QKV projections via Dense, softmax over the sliding window of past `window_size` tokens (causal — query at t attends to keys at [max(0, t-w+1), ..., t]). Cache attention weights and Q/K/V for backward.

### Task 4: MLP sublayer

**Test:** `GriffinMLP(d=4, mult=2)` forward (T=3, 4) → (3, 4), finite.

**Implement:** Linear → GELU → Linear with hidden dim = mult*d.

### Task 5: Pre-norm residual parallel composition

**Test:** GriffinBlock forward shape (T=3, d=8) → (3, 8), and each sublayer receives LayerNorm'd input (verify by checking the cached LN1 output equals forward through the LN layer).

**Implement:** single shared LayerNorm across three branches, parallel residual: `out = x + hawk_branch + attn_branch + mlp_branch`. Cache all intermediates.

### Task 6: Backward — input gradient

**Test:** centered FD vs analytical backward on the input. rel_err < 1e-2 at eps=1e-4.

**Implement:** `backward(grad_out, lr)` returns grad_input — gradient of residual sum w.r.t. x is just `grad_out` (the three branches contribute via the residual) plus the chain through each pre-norm branch.

### Task 7: Backward — Hawk path gradient

**Test:** centered FD vs analytical gradient on Hawk's W_x.weights inside the Griffin block (rel_err < 1e-3).

**Implement:** route gradient through Hawk::backward, accumulating W_x.grad_weights.

### Task 8: Backward — local attention gradient

**Test:** centered FD vs analytical gradient on attention's W_q.weights (rel_err < 1e-3).

**Implement:** manual BPTT through the local attention — softmax backward within each window, then Dense backward on Q/K/V.

### Task 9: Backward — MLP gradient

**Test:** centered FD vs analytical gradient on MLP's W1.weights (rel_err < 1e-3).

**Implement:** standard 2-layer FFN backward.

### Task 10: Backward — LayerNorm gamma/beta gradient

**Test:** centered FD vs analytical gradient on LayerNorm.gamma (rel_err < 1e-3).

**Implement:** LayerNorm.backward for the shared pre-norm.

### Task 11: Determinism + training

**Test:** two fresh GriffinBlocks with copied params produce bit-identical forward (max abs err 0.0). Training reduces loss over 30 SGD steps by > 50%.

**Implement:** confirm existing determinism pattern (state cached only during forward).

### Task 12: GriffinModel (multi-block stack)

**Test:** GriffinModel(2 blocks) forward (B=2, T=4, d=8) → (2, output_dim), finite. Two blocks train end-to-end (loss decreases).

**Implement:** stack of GriffinBlocks + final LN + Dense classifier.

### Task 13: Test config non-degeneracy sweep + mutation probes

**Test:** each parameter's gradient check uses non-degenerate init (Tensor::random(0.3) or similar — NOT uniform 0.1, to avoid row/col sum confusion vacuity). Mutation: stub out one of the three sublayer backward contributions and confirm tests fail.

### Task 14: Register + commit

**Step 1:** Add `#include "layers/architectures/griffin.h"` to `include/nn/nn.h`.

**Step 2:** Add Makefile compile rule for `build/test_griffin`, add to `tests:` deps, add `=== Running Griffin Tests ===` to run_tests.

**Step 3:** Run `make build/test_griffin && ./build/test_griffin`, confirm all checks pass.
