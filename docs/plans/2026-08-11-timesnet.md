# TimesNet Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Implement TimesNet (Wu et al. 2023, ICLR) — a generic backbone for time-series analysis that converts 1-D time series into 2-D tensors and applies 2-D convolutions to capture both intraperiod and interperiod variations.

**Architecture:** The core insight is that 1-D time series contain *multiple* periodicities (periods). TimesNet:
1. Performs FFT on the time series
2. Finds the top-K dominant frequencies (= period candidates)
3. **Reshapes** the 1-D series of length `T` into a 2-D tensor of shape `(period_k, ceil(T/period_k))` for each chosen period
4. Pads these 2-D blocks so all top-K periods share the same shape (`(max_period, num_periods)`)
5. Concatenates into a single `(max_period, K * num_periods)` batch dim and runs a shared 2-D inception-style conv block on them
6. **Inverse-reshapes** back to 1-D, averages over K periods, then standard residual + FFN

This is a strong baseline model that consistently wins time-series forecasting competitions (AutoCon, NeurIPS 2023). The paper: https://arxiv.org/abs/2210.02186.

**Tech Stack:** Existing `Dense` (for embed/FFN), existing `Conv2D` (for the 2-D inception block), `Tensor` FFT (we'll add a small FFT helper using std::complex), GELU/SiLU activations.

## Architecture Sketch

```
Input: (B, T, in_dim) — time series with T steps, in_dim features per step

DataEmbedding:  // linear projection of in_dim → d_model (no positional embedding needed for forecasting)
  x = Dense(in_dim, d_model).forward(x)

stack of TimesBlock × e_layers:
  TimesBlock:
    B, T, D = x.shape
    # 1. FFT to find top-K periods
    fft_amp = FFT amplitude along T axis                          # (B, T)
    top-k periods p_1, ..., p_K                                 # K ints in [1, T]
    # 2. For each period, reshape B,T,D → (B, period, T/period, D)
    # 3. Pad to common shape (max_period, max(T_i/p_i))
    # 4. Concatenate over a "period-batch" axis: (B*K, max_period, max_len, D) → flatten to (B*K, max_period*max_len, D) for Conv2D
    # 5. Inception-style Conv2D block (per TimesNet: 2× (Conv2D + GELU + BN) + AvgPool → projection)
    # 6. Inverse-reshape back to (B, T, D), average over K periods
    # 7. Residual + FFN
    x = x + drop_path(conv_block(LN(x)))
    x = x + drop_path(ffn(LN(x)))

projector:  // project to forecast horizon
  out = Dense(d_model, pred_len).forward(x[:, -T_pred:, :])
```

**Simplification (vs paper):** we omit:
- Positional encoding (the convs are already position-aware via FFT-derived periods)
- Task-specific heads (classification, anomaly detection) — forecasting only
- Embed dropout on the data embedding (keep simple)
- The BN-Conv-GELU stack of the inception block uses a single 2-layer Conv2D stack instead of full Inception-V2 (4 parallel branches) for tractability

## Task 3: 2-D Conv block (TimesNet "Conv2dBlock")

**Objective:** Per-block shared 2-D conv. For tractability, use a 2-layer Conv2D stack:
- Conv2D(in_ch=d_model, out_ch=d_ff, k=3×3, pad=1) → GELU
- Conv2D(in_ch=d_ff, out_ch=d_model, k=3×3, pad=1) → GELU
- Project back via Conv2D(d_model, d_model, k=1) (or just Dense over the (max_period*max_len) flattened axis)

**Important**: the conv block operates on (B*K, max_period, max_len, d_model) tensors laid out as channels-last for Conv2D. Conv2D expects (N, C, H, W) layout — but the conv layer stores weights as (out_ch, in_ch*kH*kW) and inputs as (N, C*H*W) flat. We'll flatten (max_period, max_len, D) into C*H*W flat representation.

**Files:** timesnet.h/cpp.

**Tests:** forward shape (B*K, d_model, max_period, max_len) → (B*K, d_model, max_period, max_len); output finite.

## Task 4: PeriodReshape (1-D → 2-D → 1-D, the heart of TimesNet)

**Objective:** The reshape logic. For top-K periods:
- For each period p_k, slice `(B, T, D)` → `(B, p_k, T/p_k, D)` (assume T divisible by p_k for v1; pad if not)
- Pad each to `(max_p, max_len)` where max_len = max_k ⌈T/p_k⌉
- Stack into `(B*K, max_p, max_len, D)`, then `transpose` to `(B*K, D, max_p, max_len)` for Conv2D (channel-major)
- Forward through Conv2D block
- Inverse: back to (B*K, max_p, max_len, D), slice back to (B, p_k, T/p_k, D), flatten to (B, T, D)
- Average over K periods

## Bug Fix History / Notes

During implementation, watch for:
- **FFT length not power of 2**: use naive O(N²) DFT for arbitrary N, or Cooley-Tukey for power-of-2. Naive is simpler and fine for L ≤ 64 in tests.
- **Channel-major vs channel-last**: Conv2D uses (N, C*H*W) flat with channel-major (c*H*W + h*W + w). Confirmed by `include/nn/layers/convolutions/conv_layer.h:24`.
- **Padding for variable periods**: when T=10 and p_k ∈ {3, 4}, you need T/p_k = 3 and T/p_k = 2 (rounded) — pad the shorter ones to the max.
- **Top-K period selection**: must skip freq 0 (the DC term, which always dominates); only consider freqs 1..T//2.
- **Period integer from frequency index k**: period = T / k (only valid for k that divides T exactly; otherwise we round to nearest divisor and slice with `T/p * p` actual time steps).
- **Layer normalization axis**: LayerNorm in the repo normalizes per-row (per-token). For (B, T, D) flattened to (B*T, D), apply per-row.
