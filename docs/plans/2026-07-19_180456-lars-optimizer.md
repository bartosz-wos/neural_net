# LARS Optimizer Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a production-style Layer-wise Adaptive Rate Scaling (LARS) optimizer for stable large-batch SGD training, with canonical trust-ratio scaling, momentum, integrated weight decay, bias/norm exclusion, observability, and complete regression coverage.

**Architecture:** `LARS` will live in `include/nn/optimizers/lars.{h,cpp}` and implement the repository's `Optimizer` interface. Each parameter owns one lazily initialized momentum tensor; each update first forms `u = grad + weight_decay * param`, computes `q = trust_coefficient * ||param||₂ / (||u||₂ + epsilon)` when layer adaptation is enabled, then applies `momentum_buffer = momentum * momentum_buffer + q * u` and `param -= lr * momentum_buffer`. Bias/norm-shaped tensors (`rows == 1 || cols == 1`) are excluded from adaptation and weight decay by default, matching widely used self-supervised LARS recipes; both filters are configurable.

**Tech Stack:** C++17, repository `Tensor`/`Model`/`Layer` abstractions, Make-based build, hand-derived numerical assertions with deterministic fixtures.

---

## Reference behavior

Paper: You, Gitman, and Ginsburg, "Large Batch Training of Convolutional Networks" (2017), https://arxiv.org/abs/1708.03888.

Canonical update used by modern Barlow Twins / SimCLR-style implementations:

```text
u_t = g_t + lambda * w_t                          # coupled L2 decay
q_t = eta * ||w_t||₂ / (||u_t||₂ + epsilon)       # or 1 for excluded/zero-norm tensors
m_t = momentum * m_{t-1} + q_t * u_t
w_{t+1} = w_t - lr * m_t
```

This keeps weight decay inside the layer-adapted direction. Applying decay after the trust ratio would be a different algorithm and is explicitly out of scope.

The class will not redeclare `lr`: it uses public `Optimizer::lr` directly so `LRScheduler::apply()` changes the learning rate actually consumed by `step()`.

**Step 1: Add the public class**

Public contract:

```cpp
class LARS : public Optimizer {
public:
    explicit LARS(double lr = 0.1,
                  double momentum = 0.9,
                  double weight_decay = 1e-4,
                  double trust_coefficient = 1e-3,
                  double epsilon = 1e-8,
                  bool exclude_1d_from_adaptation = true,
                  bool exclude_1d_from_weight_decay = true);

    void step(Model& model) override;
    bool handles_weight_decay() const override { return true; }

    // validated setters, accessors, state/trust-ratio introspection
};
```

Do not redeclare `double lr`; constructor and `set_lr()` write inherited `Optimizer::lr`.

**Step 2: Add lazy state**

Use `std::map<void*, std::vector<Tensor>> momentum_state_`, with one zero-filled tensor matching each parameter. Keep a parallel `last_trust_ratios_` vector for diagnostics and tests.

**Step 3: Add the exact per-parameter update**

```cpp
const bool is_1d = param->rows == 1 || param->cols == 1;
const bool decay_enabled = !(exclude_1d_from_weight_decay && is_1d);
const bool adaptation_enabled = !(exclude_1d_from_adaptation && is_1d);

update[i][j] = grad[i][j] +
               (decay_enabled ? weight_decay * param[i][j] : 0.0);

q = 1.0;
if (adaptation_enabled && param_norm > 0.0 && update_norm > 0.0) {
    q = trust_coefficient * param_norm / (update_norm + epsilon);
}

momentum_buffer[i][j] = momentum * momentum_buffer[i][j] + q * update[i][j];
param[i][j] -= lr * momentum_buffer[i][j];
```
