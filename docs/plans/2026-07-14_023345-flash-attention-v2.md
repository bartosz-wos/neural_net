# FlashAttention-2 Work-Partitioned Attention Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a professional `FlashAttentionV2Layer` that preserves the repository's causal self-attention contract while applying FlashAttention-2's Q-block-outer online-softmax work partition and a memory-conscious recompute-on-backward strategy.

**Architecture:** The layer accepts the same feature-major `(d_model, seq_len)` input as the legacy `FlashAttentionLayer`, applies learned Q/K/V projections, computes causal multi-head attention, applies `W_o`, and returns the same shape. Unlike the legacy K/V-block-outer loop, the FA-2 kernel keeps each Q block and its online-softmax state resident while streaming over K/V blocks; forward caches Q/K/V, the pre-output context, and per-row log-sum-exp values rather than a full score matrix, while backward recomputes block probabilities and accumulates Q/K/V gradients.

**Tech Stack:** C++17, repository `Tensor`/`Layer` APIs, Make, centered finite differences, deterministic asymmetric fixtures, no external dependencies or GPU-specific claims.

**Reference:** Dao, “FlashAttention-2: Faster Attention with Better Parallelism and Work Partitioning,” arXiv:2307.08691. This scalar CPU implementation reproduces the algorithmic work partition and online-softmax recurrence for clarity; it does not reproduce CUDA warp scheduling or promise hardware speedups.

class FlashAttentionV2Layer : public Layer {
public:

Use the legacy right-multiplied convention exactly:

```cpp
Q[t,j] = sum_k x[t,k] * W_q[k,j];
output[t,j] = sum_k context[t,k] * W_o[k,j];
```

This keeps weight copying and parity tests unambiguous.

**Step 2: Implement projection and layout conversion**

The public layout remains `(d_model, seq_len)`. Internally transpose once to token-major `(seq_len, d_model)`, cache an explicit clone, and project Q/K/V to `(seq_len, d_model)`.

**Step 3: Implement the Q-block-outer kernel**

For every head and Q block:

```cpp
for (q_block : query_blocks) {
    m_i = -inf;                    // one value per row in this Q block
    l_i = 0;
    O_i = 0;
    for (kv_block : key_value_blocks) {
        S_ij = scale * Q_i * K_j^T;
        apply causal mask;
        m_block = rowmax(S_ij);
        m_new = max(m_i, m_block);
        alpha = exp(m_i - m_new);
        P_ij = exp(S_ij - m_new);
        l_new = alpha * l_i + rowsum(P_ij);
        O_i = alpha * O_i + P_ij * V_j;
        m_i = m_new;
        l_i = l_new;
    }
    O_i /= l_i;
    LSE_i = m_i + log(l_i);
}
```

Skip K/V blocks wholly beyond a causal Q block where possible, and set masked entries to `-infinity` conceptually (or branch them out) rather than exponentiating the legacy `-1e9` sentinel.

Cache only:

```cpp
last_input_;       // (tokens, d_model)
last_query_;       // (tokens, d_model)
last_key_;         // (tokens, d_model)
last_value_;       // (tokens, d_model)
last_context_;     // (tokens, d_model), before W_o
last_logsumexp_;   // (num_heads, tokens), flattened as (num_heads, tokens)
```

Do not cache `(num_heads * tokens, tokens)` scores or probabilities.

**Step 3: Backpropagate through W_o**

For `output[t,j] = sum_k context[t,k] * W_o[k,j]`:

```cpp
grad_context[t,k] = sum_j grad_output[t,j] * W_o[k,j];
grad_W_o[k,j] += sum_t last_context[t,k] * grad_output[t,j];
```

**Step 4: Recompute probabilities blockwise from LSE**

For each head, Q block, and causal-compatible K/V block:

```cpp
score = scale * dot(Q_i, K_j);
P_ij = exp(score - LSE_i);
```

Masked positions contribute exactly zero. Compute the FlashAttention backward row statistic:

```cpp
D_i = dot(grad_context_i, context_i);
```

Then per block:

```cpp
dV_j += P_ij^T * grad_context_i;
dP_ij = grad_context_i * V_j^T;
dS_ij = P_ij * (dP_ij - D_i);
dQ_i += scale * dS_ij * K_j;
dK_j += scale * dS_ij^T * Q_i;
```

The leading `P_ij` and attention `scale` must be present. Q-block ownership means `dQ_i` is local to its Q block; `dK_j` and `dV_j` accumulate across all Q blocks.

**Step 5: Backpropagate through all three input projections**

For each projection `Y = X @ W`:

```cpp
grad_W[k,j] += sum_t X[t,k] * grad_Y[t,j];
grad_X[t,k] += sum_j grad_Y[t,j] * W[k,j];
```

Return the sum of the Q, K, and V input paths, converted back to `(d_model, seq_len)`. The legacy layer returns only its Q path; V2 must not copy that defect.
