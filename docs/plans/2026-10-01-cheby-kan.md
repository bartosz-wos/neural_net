# ChebyKAN Implementation Plan

> **For Hermes:** Already executed. This plan documents the design decisions
> for ChebyKAN (Sidharth SSIDC 2024, https://arxiv.org/abs/2404.10978).

**Goal:** Add a KAN variant where each per-edge activation is a truncated
Chebyshev polynomial expansion of the first kind — a clean, efficient
alternative to the existing B-spline KAN and FourierKAN.

**Architecture:** `ChebyKANLayer(in, out, K)` + `ChebyKANModel(in, hidden_dims, out, K)`.
Single parameter tensor `coefs_` of shape `(out, in*(K+1))` storing coefficients
for Chebyshev polynomials T_0, ..., T_K. Forward uses the recurrence
`T_n = 2x·T_{n-1} - T_{n-2}` to compute T_k(x), then aggregates per-edge.
Backward uses the cached T_k values plus a derivative cache
`c_{i,j,k}·T'_k(x)` (computed via the derivative recurrence
`T'_0=0, T'_1=1, T'_n=2·T_{n-1}+2x·T'_{n-1}-T'_{n-2}`) so each gradient
contract is a single inner product per edge.

**Tech Stack:** C++17, mirrors `fourier_kan.{h,cpp}` structure exactly.

## Paper specification

Per-edge activation on the bounded input domain [-1, 1]:

```
phi_{l,i,j}(x) = Σ_{k=0..K} c_{l,i,j,k} · T_k(x)
```

Chebyshev polynomials of the first kind:
```
T_0(x) = 1
T_1(x) = x
T_n(x) = 2 x T_{n-1}(x) - T_{n-2}(x)   for n >= 2
```

Properties:
- Bounded on [-1, 1]: |T_k(x)| <= 1 (enforced by clamping x in forward)
- Orthogonal w.r.t. Chebyshev weight 1/sqrt(1-x²)
- Closed-form derivative via the same recurrence:
  T'_0(x) = 0, T'_1(x) = 1, T'_n(x) = 2 T_{n-1}(x) + 2x T'_{n-1}(x) - T'_{n-2}(x)

## Design decisions

### Data layout

`coefs_` shape `(out, in * (K+1))` flattened — row `i` col `j*(K+1)+k` holds
`c_{i,j,k}` for the (i, j, k)-th coefficient.

(K+1) coefficients per edge, not K — we include the k=0 (constant T_0=1) term
which is essential for fitting target functions with non-zero offset.

### Clamping

Forward clamps `x → min(max(x, -1), 1)` per element. Chebyshev basis is
naturally defined on [-1, 1] and unbounded outside; clamping prevents
|T_k| from growing polynomially for |x| > 1 (which would saturate the
output and destabilize training). This is the same convention FourierKAN
uses on its `[-1, 1]` Fourier basis.

### Backward returns d_input

`ChebyKANLayer::backward()` returns the gradient w.r.t. the layer's input
(the standard pattern in this codebase — e.g. `KANLayer`, `FourierKANLayer`
also return d_input). The model's backward loop threads the chain rule:
`for (i = layers.size()-1; i-- > 0; ) grad = layers[i]->backward(grad);`.

### Cache strategy

Forward populates two caches:
- `last_T_(b, j*(K+1) + k) = T_k(x[b, j])` — used for the `d_coefs` chain
- `last_dphi_dx_(b, i*(in*(K+1)) + j*(K+1) + k) = c_{i,j,k} · T'_k(x[b,j])`
  — used for the `d_input` chain

Both are computed in the same forward loop as the output (no extra pass).
The dphi/dx cache is the same shape pattern as `FourierKANLayer::last_dphi_dx_`.

### Initialization

`coefs_ ~ N(0, 1/in)` so initial `phi` has small magnitude. Matches the
variance convention used by `KANLayer` and is the sigma that keeps the
initial model output near zero (the per-edge sum over `in` terms each of
variance `1/in` has total variance `1` which then flows into the per-row
sum over `in*K` outputs — close to stable).

### No inter-layer nonlinearity

`ChebyKANModel` stacks ChebyKANLayers with no inter-layer activation.
Same as `KANModel` and `FourierKANModel`. Per-edge basis is already
nonlinear; adding a global nonlinearity makes the gradient chain
harder to verify.

## Deviations from the paper

None significant. The paper's algorithm is exactly `phi(x) = Σ c_k T_k(x)`
with no extra terms (no base activation, no grid extension, no per-layer
rescaling). The clamping x → [-1, 1] in forward is a domain-convention
choice (the basis is undefined outside this interval in the standard
formulation); not a deviation, just an explicit choice.

## Future work (NOT shipped)

- **Affine input rescaling**: paper §3.2 mentions optionally learning
  per-input scale/shift to map arbitrary-domain inputs to [-1, 1].
  Not needed for the canonical use case (KAN convention is inputs
  pre-normalized to [-1, 1]).
- **Per-edge DC offset**: FourierKAN ships without it; same call here.
- **Higher-order terms with adaptive grid**: B-spline KAN's adaptive
  grid extension is the closest analogue but doesn't apply to a
  fixed Chebyshev basis.
