# RWKV-5 "Eagle" Implementation Plan

> **For Hermes:** Use TDD to implement this plan task-by-task.

**Goal:** Add a third RWKV variant `RWKV5TimeMix` filling the gap between our shipped RWKV-4 (`RWKVTimeMix`) and RWKV-6 (`RWKV6TimeMix`). Eagle adds (a) **matrix-valued per-head states** `s_t ∈ R^{m × m}` (vs RWKV-4's vector state) and (b) a **vector-valued learned decay** `w ∈ R^d` shared across the sequence (vs RWKV-4's per-channel `w`).

**Architecture:** Per-head `s_t[h]` carried forward in time; per-token `kv_t = k_t^T · v_t` outer product; per-head `wkv_t[h] = s_t[h] + u[h] · kv_t[h]`; output `o_t = concat_h(r_t · wkv_t) · W_o`. Token-shift (RWKV-4 style) for r/k/v projections, no DD-Lerp (that's Finch).

**Tech Stack:** C++17, existing Tensor/Dense/Linear algebra.

**Source paper:** Peng, Goldstein, Yu, Belcak, Cong, Dang, Dery, Espeland, Gu, Heilman, et al., 2024. *"Eagle and Finch: RWKV with Matrix-Valued States and Dynamic Recurrence."* https://arxiv.org/abs/2404.05892 (Section 3, the "Eagle" part).

**File layout:**
- `include/nn/layers/recurrent/rwkv5.h`
- `include/nn/layers/recurrent/rwkv5.cpp`

- Register in `include/nn/nn.h` (after `rwkv6.h`).

## Math (RWKV-5 Eagle)

Per-head dimension `m = d / num_heads`. Head `h` carries state `s_t[h] ∈ R^{m × m}`. Indices `i, j ∈ [0, m)` index into the head dimension. Channel index `j` in d-dim is `h * m + j`.

```
Inputs: x_t ∈ R^d

Step 1 — Token shift (Peng, RWKV-4 convention, NOT DD-Lerp):
   r_in_t = μ_r ⊙ x_t + (1 - μ_r) ⊙ x_{t-1}
   k_in_t = μ_k ⊙ x_t + (1 - μ_k) ⊙ x_{t-1}
   v_in_t = μ_v ⊙ x_t + (1 - μ_v) ⊙ x_{t-1}
   with x_{-1} := 0.

Step 2 — Projections (Dense, W : (d, d), b : (1, d)):
   r_t = W_r · r_in_t + b_r
   k_t = W_k · k_in_t + b_k
   v_t = W_v · v_in_t + b_v

Step 3 — WKV recurrence (per head, matrix-valued state):
   decay[h, i] = -exp(w[h * m + i])      (negative, because w is the "log decay magnitude"; a = exp(-exp(w)) in (0, 1))
   kv_t[h, i, j] = k_t[h * m + i] · v_t[h * m + j]      (outer product, NOT element-wise!)
   s_t[h, i, j] = exp(decay[h, i]) · s_{t-1}[h, i, j] + kv_t[h, i, j]    (paper §3.1)
   wkv_t[h, i, j] = s_t[h, i, j] + (u[h * m + i]) · kv_t[h, i, j]         (paper §3.1, bonus)
   o_t[h * m + i] = Σ_j r_t[h * m + i] · wkv_t[h, i, j]                  (output before W_o)

Step 4 — Output projection:
   out_t = o_t · W_o^T + b_o                                            (Dense, W_o : (d, d), b_o : (1, d))
```

Notes:
- We store `s_t` flat as `(T+1, num_heads · m · m)` indexed `[t, h * m * m + i * m + j]` = state-after-step-t.
- `wkv_t[h, i, j]` is also matrix-valued per head, but is reduced to a vector by `Σ_j r_t[h, i] · wkv_t[h, i, j]` — so we cache wkv per token flat, shape (T, num_heads · m · m). At token t, `out_pre[h * m + i] = Σ_j r_t[h * m + i] · wkv_t[h, i, j]`.
- `decay` (vector, length d) is shared across the entire sequence (NOT time-varying — that's the Finch innovation we're omitting).

## Initialization

Per Appendix I:
- W_r, W_k, W_v, W_o: xavier-uniform (Dense default).
- b_r, b_k, b_v, b_o: 0.
- log_w: `-0.5` init (a slightly slower decay than RWKV-4's `-5`; Eagle uses `-0.5` per the paper).
  - In code we store `log_w` directly and compute `a[i] = exp(-exp(log_w[i]))`. With log_w=-0.5, `a = exp(-exp(-0.5)) = exp(-0.6065...) ≈ 0.5455`. Per-channel decay.
- u: 0.0 init (the "current-token bonus" is zero at start).
- mu_r, mu_k, mu_v: 0.5 init.

## BPTT sketch

Per token t (going backward):
```
d_o_t[i] = W_o^T · d_out_t[i]                  # already computed by W_o.backward
# d_o_pre_t[h * m + i] is what we have
# r · wkv: out_pre[h * m + i] = Σ_j r[h * m + i] · wkv[h, i, j]
# so d_wkv[h, i, j] = r[h * m + i] · d_o_pre[h * m + i]
# and d_r[h * m + i] += Σ_j wkv[h, i, j] · d_o_pre[h * m + i]

# wkv[h, i, j] = s[h, i, j] + u[h * m + i] · kv[h, i, j]
# d_s[h, i, j] = d_wkv[h, i, j]
# d_u[h * m + i] += Σ_j kv[h, i, j] · d_wkv[h, i, j]
# d_kv[h, i, j] = d_wkv[h, i, j] · u[h * m + i]

# s_t[h, i, j] = a[h * m + i] · s_{t-1}[h, i, j] + kv[h, i, j]
# d_s_{t-1}[h, i, j] = d_s[h, i, j] · a[h * m + i]    (recurrence carrier)
# d_a[h * m + i] += d_s[h, i, j] · s_{t-1}[h, i, j]   (for all j)
# d_kv[h, i, j] += d_s[h, i, j]                       (additive contribution from the state update)

# Combined d_kv[h, i, j] = d_wkv[h, i, j] · (1 + u[h * m + i]) + d_s[h, i, j]
# (this is the algebraic simplification that emerges from the two paths into kv)

# kv[h, i, j] = k[h * m + i] · v[h * m + j]
# d_k[h * m + i] += Σ_j d_kv[h, i, j] · v[h * m + j]
# d_v[h * m + j] += Σ_i d_kv[h, i, j] · k[h * m + i]

# chain into r_pre, k_pre, v_pre via the r/Σ·wkv and Dense projections
# chain into r_in/k_in/v_in via W_r, W_k, W_v (Dense.backward)
# chain into x_t/x_{t-1} via mu_mix; chain into mu via (x_t - x_{t-1})
```

Cache shapes (public for tests):
- `last_input_` (T, d)
- `last_x_shift_` (T, d) — x_{t-1} (row 0 = 0)
- `last_r_in_, last_k_in_, last_v_in_` (T, d)
- `last_r_, last_k_, last_v_` (T, d) — after W_* projection
- `last_kv_` (T, num_heads · m · m) — outer product (flat (i, j))
- `last_s_` (T+1, num_heads · m · m) — state-after-step-t
- `last_wkv_` (T, num_heads · m · m) — wkv_t flat (i, j)
- `last_out_pre_` (T, d) — r · wkv, before W_o
- `last_a_` (1, d) — exp(-exp(log_w))
- `last_decay_` (1, d) — -exp(log_w), used for d_a chain
