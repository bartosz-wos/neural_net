# Hyena Hierarchy Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Implement the **Hyena operator** (Poli et al. 2023, https://arxiv.org/abs/2302.10866) — a subquadratic sequence-mixing layer that combines implicit long convolutions with multiplicative element-wise gating. This is the canonical "attention-replacement" architecture for long-context models (Striped Hyena, Evo, HyenaDNA).

**Architecture:** Three classes:

1. `HyenaFilter(d_model, l_max, filter_order, num_inner=2)` — implicit long convolution kernel generator. Maps positional embeddings (per-frequency real+imag) through a small MLP (Linear → sin → Linear → sin → ... → Linear(d_model)), producing per-channel filter weights k ∈ R^{D × L}. Includes an exponential-decay modulation for causality, and a per-channel skip parameter D ∈ R^D.

2. `HyenaOperator(d_model, l_max, order=2, filter_order=4)` — the actual operator. In_proj: D → (order+1)·D, then a depthwise Conv1d (kernel=3, causal via padding=1 on the left), then split into `order+1` channels-of-chunks `x_0, x_1, ..., x_{order-1}, v` (each D-wide). The recurrence is:
   ```
   v = v * x_{order-1};             # multiplicative gate 1
   v = long_conv(v, k_0, D_0);      # FFT-based long convolution + skip
   v = v * x_{order-2};             # multiplicative gate 2
   v = long_conv(v, k_1, D_1);      # FFT-based long convolution + skip
   ...
   out = v * x_0;                   # final gate
   ```
   Out_proj: D → D. For order=2 this gives 2 multiplicative gates and 2 long convolutions.

3. `HyenaBlock(d_model, l_max, order=2, filter_order=4, ffn_mult=2)` — pre-LN → HyenaOperator → residual → pre-LN → GELU FFN (d_model → ffn_mult·d_model → d_model) → residual.

4. `HyenaModel(d_model, l_max, depth, num_classes, order=2, filter_order=4)` — stack of HyenaBlocks + per-token mean pool + classifier.

**Why this addition:** The repo has a wide array of subquadratic attention alternatives — FNet (Fourier mix), Performer (FAVOR+ random features), Linformer (low-rank projection), Nyströmformer, GQA, MLA — but **no long-convolution-based subquadratic primitive**. Hyena is the canonical example of the convolution-gating family and complements the existing attention-free sequence mixers. Adding it gives the repo a full taxonomy: (a) Fourier mix, (b) random-feature linear attention, (c) low-rank linear attention, (d) state-space models (Mamba, S4, xLSTM, RWKV, mLSTM, RetNet), and now (e) implicit long convolutions.

**Tech Stack:** Existing — `Tensor`, `Dense`, `LayerNorm`, GELU activation from `activations.h`. Will use a naive O(L²) convolution in the gradient-check tractable regime (matches the FNet convention). For filter generation: built-in `Sin` activation (sin(w·x) with learnable w per channel, the canonical Hyena filter non-linearity), built-in `PositionalEmbedding` (per-frequency complex exponential embed), built-in `ExponentialModulation` (per-channel exponential decay).

**Reference:**
- Paper: https://arxiv.org/abs/2302.10866 (Poli et al., 2023)
- Official reference (stripped standalone): https://github.com/HazyResearch/safari/blob/main/standalone_hyena.py

## Mathematical Specification

### Filter generation (HyenaFilter)

Inputs:
- `d_model` — channel dimension (D)
- `l_max` — maximum sequence length (L)
- `filter_order` — width of the implicit MLP (P)
- `emb_dim` — dim of positional input fed to filter MLP, default 3 (time + sin + cos)

Positional embedding `z ∈ R^{L × emb_dim}`:
- t[l] = l / (L - 1) for l = 0..L-1 (normalized time)
- For k = 0..(emb_dim-1)/2 - 1: z[l, 2k+1] = cos(2π·k·l/L), z[l, 2k+2] = sin(2π·k·l/L)

Implicit MLP (single channel):
- W_in: R^{emb_dim} → R^{P}, sin activation (with learnable frequency w_p per channel p)
- W_inner_1: R^{P} → R^{P}, sin
- W_inner_2: R^{P} → R^{P}, sin
- W_out: R^{P} → R^{D} (no bias)

Result is h ∈ R^{L × D}.

Exponential modulation (causality): h[l, d] *= exp(-delta_d * t[l]) where delta_d ∈ (0, ∞) is per-channel learned.

Skip: D ∈ R^D (per-channel scalar, learned).

### Long convolution (per channel, per HyenaOperator stage)

For each channel d and stage o:
- k_d^o ∈ R^L (the filter for this stage's channel)
- D_d^o ∈ R (skip for this stage's channel)
- v_d ∈ R^L (input to this stage's channel — the previous stage's output)

Output:
- y_d = conv(k_d, v_d) + D_d * v_d

where `conv(k, v)[t] = sum_{s=0..min(t, L-1)} k[s] * v[t - s]` (causal convolution).

### HyenaOperator (order = 2)

```
u_in = in_proj(x)              # (B, L, 3D)
u_in = u_in.transpose to (B, 3D, L)  # channels-first for Conv1d
short = depthwise_conv1d(u_in, kernel=3, pad=1, causal via trim last)
[gate_0, gate_1, v] = short.split(D, dim=channels)   # 3 chunks of size D

v = v * gate_1
v = long_conv(v, k_0, D_0)       # apply stage 0
v = v * gate_0
out_channels = v

out = out_channels.transpose to (B, L, D)
out = out_proj(out)
```

### HyenaBlock

```
h = layer_norm(x)
h = hyena(h)
x = x + h
h = layer_norm(x)
h = gelu_ffn(h)     # Dense(d_model, ffn_mult*d_model) → gelu → Dense(ffn_mult*d_model, d_model)
x = x + h
```

### HyenaModel

- Embedding layer (handled by caller — model expects pre-embedded input of shape (B, L, d_model))
- Stack of `depth` HyenaBlocks
- Per-token mean pool → (B, d_model)
- Classifier Dense(d_model, num_classes) → (B, num_classes)

- Every gradient check uses **random init** (not uniform — see TDD skill row on "uniform init masks row-vs-column confusion")
- Every gradient check uses **non-degenerate loss landscape** (random targets, scale ~0.3 init, eps=1e-5)

- Run full repo test suite (`make run_tests`) before final commit

## Risks / Pitfalls

1. **Naive O(L²) conv.** Fine for gradient check at L=8, slow at L=64+. Document this. (FFT upgrade left for future work.)
2. **Implicit filter MLP backward.** Each Linear in the MLP needs its own backward; caches of pre-activations needed for sin' chain rule.
3. **Depthwise conv1d gradient.** Standard backward — borrow from existing `Conv1D` impl.
4. **Causal vs non-causal conv.** Hyena is causal — conv kernel index `s` corresponds to lag from current time. Naive O(L²) implementation must use `s ≤ t` only.
5. **Gate ordering.** Per `standalone_hyena.py`, gates split after the short conv are `[x_0, x_1, v]` where x_0 is the *last* gate applied and x_1 the first. Must match reference.
