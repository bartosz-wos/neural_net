# Mamba-3 Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Implement Mamba-3 (Dao & Gu 2025, "Mamba-3: SSMs as general-purpose backbone") in `include/nn/layers/recurrent/mamba3.{h,cpp}` with full analytical BPTT and a `tests/test_mamba3.cpp` suite.

**Architecture:** A single `Mamba3Block` class with multi-head, complex-eigenvalue SSM parameterization. Key Mamba-3 innovations vs Mamba-1/2:

1. **Per-channel complex eigenvalues** `A[c] = a[c] · exp(i·θ[c])` stored as a real pair `(a_log[c], theta[c])`. Decay magnitude `a[c] ∈ (0,1)` and rotation phase `θ[c] ∈ (-π, π)`. Recurrence `h_t[c] = A[c] · h_{t-1}[c] + b_t[c] · x_t[c]` becomes a damped 2-D oscillator per channel (real-imag pair).
2. **Trapezoidal-rule discretization** (instead of Zero-Order Hold / Euler in Mamba-1/2). For per-step `Δ_t`, `Ā_t = (1 + 0.5·Δ_t·A) / (1 - 0.5·Δ_t·A)`, `B̄_t = Δ_t · B / (1 - 0.5·Δ_t·A)`. This is the second-order accurate variant that gives Mamba-3 better gradient flow.
3. **Scalar-times-identity A** (no per-head block structure; the state is per-channel, like Mamba-1). Multi-head is achieved by partitioning channels into H groups.
4. **RoPE-style input/output projections** — we replace convolutions with explicit per-position phase rotation on the input. The input projection `x_t[c]` is rotated by `e^{i·m·pos_t·θ_base[c]}` (a `pos` index times a per-channel base frequency). This gives the Mamba-3 paper's "Rotational SSM" property.

**Tech Stack:** C++17, the existing `Tensor`, `Dense` infrastructure. The complex SSM state per channel will be tracked as a `(T+1, d_inner, 2)` tensor where index `[t, c, 0]` is the real part and `[t, c, 1]` is the imaginary part of `h_t[c]`.

**Paper reference:** Dao & Gu 2025, "Mamba-3: State Space Models as General Purpose Backbone" (the formal Mamba-3 paper with complex-eigenvalue SSD).

**Step 3: Implement forward**

For each token t:
1. `p_t = in_proj(x_t)` — (2*d_inner,)
2. Split into `x_ssm_t` and `gate_t`
3. Apply RoPE-style rotation: `x_ssm_t_rot[c] = x_ssm_t[c] * cos(t * theta_base[c]) + i*x_ssm_t[c] * sin(...)` (we'll store as (d_inner, 2) tensor [real, imag])
4. `a_pre = dt_proj(x_t) + dt_bias`, `dt = softplus(a_pre)` — (n_heads,)
5. For each channel c: `A[c] = exp(A_log[c])` (decay magnitude) and `exp(i * theta[c])` (rotation)
6. Trapezoidal discretization: `Ā_t[c] = (1 + 0.5·dt_h·A[c]) / (1 - 0.5·dt_h·A[c])` (complex arithmetic)
7. `b_t = b_proj(x_t)` — (d_inner,)
8. Update state (complex): `h_t = Ā_t ⊙ h_{t-1} + (Δ_t · b_t) ⊙ x_ssm_t_rot` (complex arithmetic)
9. `o_t = Re(h_t · x_ssm_t)` (or sum over real part of conjugate-rotated projection — pick the paper convention)
10. Apply D skip: `y_t = o_t + D_skip � x_ssm_t`
11. Gate + out_proj: `out_t = out_proj(silu(gate_t) ⊙ y_t)`

For complex arithmetic, store as 2D real tensors and apply operations component-wise. State is `((T+1) * d_inner, 2)`.

## Task 4: Hand-derived single-channel forward test

**Files:**
- Test: `tests/test_mamba3.cpp`

**Step 1: Write test (T=1, d_model=1, n_heads=1, d_inner=2) hand-derived**

Set all weights to known values (e.g. all 1s), set biases to 0. Compute forward by hand and compare.

For the complex SSD:
- A_log[0] = A_log[1] = 0 → |A| = 1 for both channels
- theta[0] = theta[1] = π/4 → A = (1/√2)(1 + i) for both
- dt_bias[0] = 0, dt_proj weights = 0, dt_proj bias = 0 → dt = softplus(0) = ln(2) ≈ 0.693
- in_proj = all 1s: with x_t = 1, p_t = (1, 1, 1, 1) → x_ssm_t = (1, 1), gate_t = (1, 1)
- RoPE rotation at t=0: angle = 0 → identity
- b_t = b_proj(1) = (1, 1) for both channels
- Trapezoidal: Ā = (1 + 0.5·ln(2)·A) / (1 - 0.5·ln(2)·A) with A = (1/√2)(1+i)
  - 0.5·ln(2) ≈ 0.347
  - Numerator: (1 + 0.347·(1+i)/√2) = (1 + 0.245 + 0.245i)
  - Denominator: (1 - 0.245 - 0.245i)
  - Ā = (1.245 + 0.245i) / (0.755 - 0.245i)
  - Multiply by conj: ((1.245 + 0.245i) · (0.755 + 0.245i)) / (0.755² + 0.245²)
  - Numerator: 1.245·0.755 + 1.245·0.245i + 0.245·0.755i + 0.245·0.245i²
             = 0.940 + 0.305i + 0.185i - 0.060
             = 0.880 + 0.490i
  - Denominator: 0.570 + 0.060 = 0.630
  - Ā = 1.397 + 0.778i
- B̄ = 0.693 · (1,1) / (1 - 0.5·0.693·A) = 0.693 / (0.755 - 0.245i) = 0.693·(0.755 + 0.245i)/0.630 = (0.831 + 0.270i) for both
- h_1 = Ā · 0 + B̄ · x_ssm = (0.831 + 0.270i) · 1 = (0.831, 0.270) for both
- o_t = Re(h_1) = (0.831, 0.831) [taking Re(h) component]  (or sum_{j=0,1} h[j] for channel c — paper convention)
- y_t = o_t + D_skip ⊙ x_ssm = (0.831 + 1, 0.831 + 1) = (1.831, 1.831)
- silu(gate) = silu(1) = 1·sigmoid(1) = 0.731
- gated = 0.731 · 1.831 = 1.339
- out_proj of (1.339, 1.339) — out_proj weights all 1s, bias 0: out = 2 · 1.339 = 2.677

Compare with `rel_err < 1e-4`.

**Step 3: Implement backward**

For each timestep t (in reverse, T-1 down to 0):
1. `grad_y_t = grad_out_t = grad_output_t` (post out_proj)
2. `grad_gated_t = out_proj.backward(grad_y_t)` accumulates `grad_W_O`, returns `grad_gated_t`
3. `grad_gate_t = silu(gate_t) · grad_gated_t + silu_derivative(gate_t) · y_t · grad_gated_t`... actually `silu(g) · y` so `grad_gate = y · silu'(gate) · grad_gated = y · silu(gate) · (1 + gate · (1 - sigmoid(gate))) · grad_gated`
   Simpler: since `gated = silu(g) · y`, `dgated/dg = silu'(g) · y`. So `grad_g = grad_gated ⊙ y · silu'(g)`
4. Concatenate grad_x_ssm + grad_gate into grad_p for in_proj
5. `in_proj.backward(grad_p, lr)` accumulates `grad_W_inproj`, returns `grad_input`
6. Backward through the SSD recurrence for grad_x_ssm_rotated (real part), grad_dt, grad_b, grad_A_log, grad_theta
7. Undo RoPE rotation

## Notes

- The complex SSD state is the central novel element of Mamba-3. Track it carefully as `(T+1, d_inner, 2)` tensor.
- The trapezoidal discretization is `Ā_t = (1 + 0.5·Δ_t·A) / (1 - 0.5·Δ_t·A)` per channel. The denominator can be very small if `0.5·Δ_t·A ≈ 1` — clamp or guard to avoid division blowup.
- RoPE-style rotation: `angle[c, t] = t * theta[c]`. Apply as a per-channel complex rotation `e^{i·angle[c,t]}` to `x_ssm_t[c]`. For the backward, `d/dx_ssm_t[c]` accumulates `d/d(x_ssm_rotated[c]) · e^{-i·angle[c,t]}`.
