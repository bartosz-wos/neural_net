# RWKV-7 "Goose" Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add `RWKV7TimeMix` (single time-mixing block) and `RWKV7Model` (full stack + classifier) following Peng et al. 2025 "RWKV-7 'Goose' with Expressive Dynamic State Evolution" (https://arxiv.org/abs/2503.14456). RWKV-7 generalizes the delta rule with vector-valued state gating and in-context learning rates — the latest evolution of the RWKV linear-RNN family.

**Architecture:** Per-head, multi-head matrix state `wkv_t ∈ R^{(D/h) × (D/h)}` evolves via the **generalized delta rule** with vector-valued decay and per-channel learning rates. Channel-mixing (the FFN half of RWKV blocks) is left out of scope for v1 — it's a simple 2-layer ReLU² MLP with token-shift (matches RWKV-4 v1) and adds no math novelty.

**Tech Stack:** Existing `Layer`, `Tensor`, `Dense`. Files go in `include/nn/layers/recurrent/`. Tested with numerical gradient checks at machine precision (rel_err < 1e-5).

## Background

### Paper context

RWKV-7 (Peng et al. 2025, https://arxiv.org/abs/2503.14456) is the newest evolution of the RWKV family — after RWKV-4 (per-channel scalar decay), RWKV-5/6 (vector-valued decay), RWKV-7 introduces the **generalized delta rule**:

```
wkv_t = wkv_{t-1} · G_t  +  v_t^T · k̃_t
```

where `G_t = diag(w_t) − κ̂_t^T (a_t ⊙ κ̂_t)` is a *diagonal plus rank-one* transition matrix. The key innovations are:

1. **Vector-valued in-context learning rate** `a_t ∈ (0,1)^d` — each channel has its own learning rate (was scalar in DeltaNet).
2. **Decoupled removal/replacement keys** — `κ_t = k_t ⊙ ξ` is the *removal* key (ξ is a learned scalar parameter), `k̃_t = k_t ⊙ lerp(1, a_t, α)` is the *replacement* key (α is a learned scalar that interpolates between `1` and `a_t`).
3. **Per-head L2 normalization** `κ̂_t = κ_t / ||κ_t||_2` for numerical stability.
4. **Channel-mixing** uses ReLU² (not SiLU) for efficiency.
5. **No token-shift data dependency** and **no channel-mixing receptance** — removed for inference speed.

The state update can be rewritten (paper §2, Equation 22) as a "diagonal plus rank one" recurrence (DPLR form), which the paper proves can recognize **all regular languages with a constant number of layers** — exceeding the expressivity of softmax attention (TC⁰).

### Math we need to derive

**Weight preparation** (per token t, before splitting into heads):

```
x_t^□ = lerp(x_t, x_{t-1}, μ_□)            for □ ∈ {r, k, v, d, a, g}    (token shift; x_{-1}:=0)

r_t   = W_r · x_t^r                        (receptance, no bias in v1 to keep it tractable; per RWKV-7 we keep bias but use the convention from RWKV-6)
k_t   = W_k · x_t^k                        (key — will be split into heads)
v_t   = W_v · x_t^v                        (value)

ν_t   = sigmoid(loramlp_ν(x_t^v, bias=true))  (value-mix gate; layer-l index selects between two value variants; v1 uses layer l=0 only, so v_t = v'_t)

d_t   = loramlp_d(tanh, x_t^d, bias=true)
w_t   = exp(-exp(-0.5) · sigmoid(d_t))     in (exp(-e^{-0.5}), 1) ≈ (0.687, 1)

a_t   = sigmoid(loramlp_a(x_t^a, bias=true))   in (0, 1)

κ_t   = k_t ⊙ ξ                             (removal key; ξ is learnable scalar/vector parameter)
κ̂_t  = κ_t / ||κ_t||_2                     (per-head L2 normalization)
k̃_t   = k_t ⊙ lerp(1, a_t, α)              (replacement key; α is learnable scalar)
```

In v1 (no loramlp, no value-mix gate, no GroupNorm), we simplify the preparation to:

```
x_t^□ = lerp(x_t, x_{t-1}, μ_□)
r_t   = W_r · x_t^r + b_r
k_t   = W_k · x_t^k + b_k
v_t   = W_v · x_t^v + b_v
d_t   = tanh(W_d · x_t^d + b_d)
w_t   = exp(-exp(-0.5) · sigmoid(d_t))     (per-channel, in (0.687, 1))
a_t   = sigmoid(W_a · x_t^a + b_a)        (per-channel, in (0, 1))
κ_t   = k_t ⊙ ξ
κ̂_t  = κ_t / ||κ_t||_2
k̃_t   = k_t ⊙ lerp(1, a_t, α)
```

**WKV state update** (per head, in `R^{D/h × D/h}`):

```
wkv_t = wkv_{t-1} · (diag(w_t) − κ̂_t^T (a_t ⊙ κ̂_t))  +  v_t^T · k̃_t
```

The "left-multiplication by wkv_{t-1}" is **right-multiplication by the transition matrix on the right** (since the paper uses column-major storage: rows are keys, columns are values). We store `wkv_t[h, :, :]` so the row `wkv_t[h, i, :]` is the value associated with key channel `i`.

**Output** (per head):

```
o'_t[h, j] = wkv_t[h, j, :] · r_t[h, :]
p_t[h, j]  = LayerNorm(o'_t)[h, j] + u_t[h, j]      with u_t[h, j] = (r_t[h, :] · (ρ ⊙ k̃_t[h, :])) · v_t[h, j]
```

Then heads are recombined:

```
p_t ∈ R^D
o_t = (g_t ⊙ p_t) · W_o
```

In v1 (no GroupNorm, no channel-mix), we drop the LayerNorm from the output (it adds LayerNorm gradient noise that complicates FD testing) and combine heads directly.

**Backward (single-step BPTT).** Per head, with state `wkv_t ∈ R^{m×m}` where `m = D/h`:

- `g_o_t[h, :]` is the incoming gradient of `o_t[h, :]` (per head, after `W_o^T` if `W_o` exists).
- For simplicity in v1, no `W_o`: the head output `p_t` IS the model output. Then `g_o_t` is the gradient of loss w.r.t. `p_t` directly.

```
o'_t[h, :]  = wkv_t[h, :, :]^T · r_t[h, :]                       (per head, m-vector)
g_o'_t     = g_o_t                                              (since no LayerNorm in v1)

g_r_t[h, i]  = sum_j wkv_t[h, i, j] · g_o'_t[h, j]              (wkv row i dotted with g_o')
g_wkv[h, i, j] = r_t[h, i] · g_o'_t[h, j]                       (outer product)

Bonus: u_t[h, j] = (r_t ⊙ ρ ⊙ k̃_t)[h, :] · v_t[h, j]  →  sum_i r_t[h,i]·ρ[h,i]·k̃_t[h,i]·v_t[h,j]
              (a scalar: dot product of (r_t⊙ρ⊙k̃_t) with v_t[:,j])
```

Since v1 has no bonus, we drop `u_t` and the `ρ` parameter entirely — the wkv output IS the output.

**Backward through wkv update.** The trick: `wkv_t = wkv_{t-1} G_t + v_t^T k̃_t`. Unrolling:

```
dL/dwkv_t = g_wkv_t + dL/dwkv_{t+1} · G_{t+1}                   (recurrence carrier from t+1's update)
dL/dG_t   = wkv_{t-1}^T · dL/dwkv_{t+1}                         (note: wkv_{t-1} enters the linear combination at step t)
```

Actually since `wkv_t = wkv_{t-1} · G_t + v_t^T · k̃_t`, taking derivatives:

```
dwkv_t/dwkv_{t-1} = G_t^T                                       (left-multiplied by G_t^T propagates backward)
dwkv_t/dG_t       = wkv_{t-1}^T                                 (contribution to G_t is wkv_{t-1}^T)
dwkv_t/dk̃_t       = v_t^T                                      (per row; but k̃_t is per-channel so this is v_t broadcasted)
dwkv_t/dv_t       = k̃_t^T
```

The per-head G_t is `diag(w_t) − κ̂_t^T (a_t ⊙ κ̂_t)` (an `m×m` matrix). We need `dL/dG_t` and then expand:
- `dL/dw_t[i] = G_t[i, i] · dL/dG_t[i, i]`
- `dL/dκ̂_t[i, j] = -a_t[i] · dL/dG_t[i, j]` for `j ∈ [0, m-1]`, summed across j
- `dL/da_t[i] = -sum_j κ̂_t[i, j] · dL/dG_t[i, j]`

### Why this addition

- **Coverage gap.** The repo has RWKV-4 (per-channel scalar decay), DeltaNet (per-key scalar learning rate), GLA (per-head scalar decay), RetNet (fixed decay), Hawk/RG-LRU (input-tied gate). RWKV-7 brings **vector-valued learning rates, decoupled removal/replacement keys, and the generalized delta rule** — the most expressive of the linear-attention-with-state-evolution family.
- **Theoretical interest.** Paper proves RWKV-7 can recognize all regular languages with constant layers, exceeding TC⁰ (softmax attention). The DPLR state evolution is mathematically elegant.
- **Composes well.** A drop-in replacement for the time-mix block in any RWKV-style architecture; shares the `(T, D) → (T, D)` shape convention with RWKV-4, GLA, HGRN, Mamba variants.

**v1 simplifications** (vs paper):
- No `loramlp` for d/a/ν — use single Dense per gate.
- No value-mix gate (ν_t) — single v_t path (equivalent to layer l=0 in paper).
- No GroupNorm on output.
- No output projection W_o (so the wkv output IS the model output, post LayerNorm-like-stabilization that we just skip).
- No ReLU² channel-mix block.

These keep v1 to a tractable, fully-testable single-block model that exercises the **generalized delta rule** cleanly.

### D2: Why not use `Dense` for d/a? — Use Dense.

Single-layer Dense gives us `d_t = tanh(W_d · x_t + b_d)`. The paper uses a loramlp (low-rank MLP) but the math is equivalent — single-matrix projection followed by tanh. The important part is `w_t = exp(-exp(-0.5) · sigmoid(d_t))` which produces values in `(exp(-e^{-0.5}), 1) ≈ (0.687, 1)`.

### D3: Head layout

`num_heads * head_dim = d`. We split `(T, d)` into `(T, num_heads, head_dim)` per token and process each head independently. The `wkv` state for each head is `(head_dim, head_dim)` (the matrix state). For each token `t`, per head `h`:
- `r_t[h, :]` = `head_dim`-vector of receptance
- `k_t[h, :]`, `v_t[h, :]`, `w_t[h, :]`, `a_t[h, :]` same
- `ξ[h, :]` = head_dim-vector of removal-key multipliers
- `κ̂_t[h, :]` = `head_dim`-vector (per-head L2 normalization)
- `wkv_t[h, :, :]` = `(head_dim, head_dim)` state matrix
- Output `o_t[h, :]` = `head_dim`-vector

In v1, `ξ` is stored as a `(1, d)` tensor (one value per channel — same as RWKV-4 style).

### D4: Numerical gradient check strategy

For the **cell** with `d=4, num_heads=2, head_dim=2, T=3`:
- Forward shape, finite, wkv-state-shape check
- Per-head κ̂_t has unit L2 norm (sanity)
- wkv_t evolves (not zero, not identical to wkv_{t-1})
- Hand-derived forward for `num_heads=1, head_dim=2, T=2` (3-step recipe: shift, project, wkv-update, output)
- Input gradient check rel_err < 1e-4 (with loss = grad_loss · y_pred)
- All parameter gradient checks via centered FD:
  - W_r, W_k, W_v, W_d, W_a weights (5 dense weight tensors × d × d entries)
  - xi (d entries)
  - alpha (1 entry)
  - mu_r, mu_k, mu_v, mu_d, mu_a (5 token-shift vectors × d entries each)
  - All biases (5 biases × d entries each)
  Target: rel_err < 1e-3 (centered FD with eps=1e-5; the chain through wkv-update and L2-normalization will introduce ~1e-7 noise)
- Determinism (bit-exact with copied params)
- Parameters/gradients/zero_grad contract (5 + 5 + 5 + 5 + 5 + 1 + 1 = 27 tensors, or 24 if biases omitted)
- update_weights moves all 24 parameters
- Longer sequence (T=6) W_r gradient check (verifies wkv recurrence carrier in BPTT)
- wkv_0 = 0 invariant

For the **model**: forward shape + finiteness + training reduces loss (50 SGD steps, expect >30% loss reduction on synthetic sequence regression).

### D5: Layout convention

Tensor is 2D. Sequences are `(T, d)` (row = timestep, col = feature). Each head's per-token vector is a slice of the row. The wkv state is stored as `(num_heads, head_dim, head_dim)` — to slice per head, use index arithmetic since Tensor is 2D, we'll use `wkv_states_(num_heads, head_dim, head_dim)` stored as a single `(num_heads*head_dim, head_dim)` tensor via flat indexing, OR more cleanly, store it as a `(T+1, num_heads, head_dim, head_dim)` tensor using `Tensor::Tensor(rows, cols)` and slicing with manual offsets — actually easiest is to use a custom 4D-style accessor via per-head local tensors.

**Implementation choice**: store `wkv_cache` as a flat `(T+1, num_heads*head_dim*head_dim)` tensor; per-head `wkv_t[h]` is `wkv_cache.row(t).segment(h*head_dim*head_dim, head_dim*head_dim).reshape(head_dim, head_dim)`. Since `Tensor` doesn't have `segment` or `reshape`, we instead use direct indexing with manual offset arithmetic in the BPTT loop — same pattern as existing RWKV-4 file.

Forward (full math; tests pass after Task 1 only checks shape):
```cpp
Tensor RWKV7TimeMix::forward(const Tensor& input) {
    if (input.cols != d_) throw std::invalid_argument("...");
    size_t T = input.rows;
    last_input_ = input.clone();
    size_t m = head_dim_;

    // Allocate cache
    last_x_shift_ = Tensor(T, d_); last_x_shift_.fill(0.0);
    last_r_in_ = Tensor(T, d_); last_k_in_ = Tensor(T, d_); last_v_in_ = Tensor(T, d_);
    last_d_in_ = Tensor(T, d_); last_a_in_ = Tensor(T, d_);
    last_r_ = Tensor(T, d_); last_k_ = Tensor(T, d_); last_v_ = Tensor(T, d_);
    last_d_ = Tensor(T, d_); last_a_ = Tensor(T, d_);
    last_w_ = Tensor(T, d_); last_kappa_ = Tensor(T, d_); last_kappa_hat_ = Tensor(T, d_);
    last_k_tilde_ = Tensor(T, d_);
    last_wkv_ = Tensor(T+1, num_heads_ * m * m); last_wkv_.fill(0.0);

    // Token shift
    for (size_t t = 0; t < T; ++t) {
        for (size_t j = 0; j < d_; ++j) {
            double xt = last_input_(t, j);
            double xsh = (t == 0) ? 0.0 : last_input_(t-1, j);
            last_x_shift_(t, j) = xsh;
            last_r_in_(t, j) = mu_r(0, j) * xt + (1.0 - mu_r(0, j)) * xsh;
            last_k_in_(t, j) = mu_k(0, j) * xt + (1.0 - mu_k(0, j)) * xsh;
            last_v_in_(t, j) = mu_v(0, j) * xt + (1.0 - mu_v(0, j)) * xsh;
            last_d_in_(t, j) = mu_d(0, j) * xt + (1.0 - mu_d(0, j)) * xsh;
            last_a_in_(t, j) = mu_a(0, j) * xt + (1.0 - mu_a(0, j)) * xsh;
        }
    }
    // Projections
    last_r_ = W_r.forward(last_r_in_);
    last_k_ = W_k.forward(last_k_in_);
    last_v_ = W_v.forward(last_v_in_);
    Tensor d_pre = W_d.forward(last_d_in_);
    Tensor a_pre = W_a.forward(last_a_in_);
    // Compute w_t, a_t, kappa_t, kappa_hat_t, k_tilde_t
    for (size_t t = 0; t < T; ++t) {
        for (size_t h = 0; h < num_heads_; ++h) {
            size_t base = h * m;
            // Per-head a_t (sigmoid)
            for (size_t i = 0; i < m; ++i) {
                last_a_(t, base+i) = sigmoid(a_pre(t, base+i));
            }
            // Per-head w_t
            for (size_t i = 0; i < m; ++i) {
                double d_th = std::tanh(d_pre(t, base+i));
                double sig = sigmoid(d_th);
                last_w_(t, base+i) = std::exp(-std::exp(-0.5) * sig);  // in (exp(-e^{-0.5}), 1)
            }
            // kappa_t = k_t ⊙ xi
            for (size_t i = 0; i < m; ++i) {
                last_kappa_(t, base+i) = last_k_(t, base+i) * xi(0, base+i);
            }
            // Per-head L2 normalize
            double norm = 0.0;
            for (size_t i = 0; i < m; ++i) norm += last_kappa_(t, base+i) * last_kappa_(t, base+i);
            norm = std::sqrt(norm);
            if (norm < 1e-12) norm = 1e-12;  // safety against zero division
            for (size_t i = 0; i < m; ++i) last_kappa_hat_(t, base+i) = last_kappa_(t, base+i) / norm;
            // k_tilde_t = k_t ⊙ lerp(1, a_t, alpha)
            double a_alpha = alpha(0, 0);
            for (size_t i = 0; i < m; ++i) {
                double lerp = 1.0 + a_alpha * (last_a_(t, base+i) - 1.0);
                last_k_tilde_(t, base+i) = last_k_(t, base+i) * lerp;
            }
        }
    }

    // WKV update per head per token
    Tensor output(T, d_);
    for (size_t t = 0; t < T; ++t) {
        // wkv_t = wkv_{t-1} · G_t + v_t^T · k_tilde_t   (per head)
        for (size_t h = 0; h < num_heads_; ++h) {
            size_t base = h * m;
            // Pointer to wkv_{t-1} and wkv_t in the flat cache
            double* wkv_prev = &last_wkv_(t, h*m*m);  // row t in (T+1, num_heads*m*m)
            double* wkv_curr = &last_wkv_(t+1, h*m*m);
            // G_t = diag(w_t) - kappa_hat_t^T (a_t ⊙ kappa_hat_t)
            // First compute wkv_prev · G_t (m x m result)
            for (size_t i = 0; i < m; ++i) {  // row of wkv_curr
                for (size_t j = 0; j < m; ++j) {  // col of wkv_curr
                    double s = 0.0;
                    for (size_t k = 0; k < m; ++k) {
                        double G_kj = (k == j) ? last_w_(t, base+j) : 0.0;
                        G_kj -= last_kappa_hat_(t, base+k) * last_a_(t, base+k) * last_kappa_hat_(t, base+j);
                        s += wkv_prev[i*m + k] * G_kj;
                    }
                    // Add v_t[i] * k_tilde_t[j]
                    s += last_v_(t, base+i) * last_k_tilde_(t, base+j);
                    wkv_curr[i*m + j] = s;
                }
            }
        }
        // Output: per head o_t[h, j] = sum_i wkv_t[h, i, j] * r_t[h, i]
        for (size_t h = 0; h < num_heads_; ++h) {
            size_t base = h * m;
            double* wkv_curr = &last_wkv_(t+1, h*m*m);
            for (size_t j = 0; j < m; ++j) {
                double s = 0.0;
                for (size_t i = 0; i < m; ++i) s += wkv_curr[i*m + j] * last_r_(t, base+i);
                output(t, base+j) = s;
            }
        }
    }
    return output;
}
```

### Task 5: Backward pass — basic structure

The backward pass implements single-step BPTT through the wkv state. The math was derived in Phase 0 above. Implementation outline:

```cpp
Tensor RWKV7TimeMix::backward(const Tensor& grad_output, double /*lr*/) {
    if (grad_output.cols != d_) throw std::invalid_argument("...");
    size_t T = grad_output.rows;
    size_t m = head_dim_;

    // Allocate per-step buffers
    Tensor grad_x(T, d_); grad_x.fill(0.0);
    W_r.zero_grad(); W_k.zero_grad(); W_v.zero_grad();
    W_d.zero_grad(); W_a.zero_grad();

    Tensor grad_r_pre(T, d_); grad_r_pre.fill(0.0);
    Tensor grad_k_pre(T, d_); grad_k_pre.fill(0.0);
    Tensor grad_v_pre(T, d_); grad_v_pre.fill(0.0);
    Tensor grad_d_pre(T, d_); grad_d_pre.fill(0.0);
    Tensor grad_a_pre(T, d_); grad_a_pre.fill(0.0);

    // BPTT: dL/dwkv_t = g_wkv_t + G_{t+1}^T · dL/dwkv_{t+1}
    Tensor grad_wkv_next(m * m); grad_wkv_next.fill(0.0);
    Tensor grad_wkv_curr(m * m);

    for (size_t ti = 0; ti < T; ++ti) {
        size_t t = T - 1 - ti;
        // For each head, compute g_wkv_t = outer(r_t, g_o_t)
        for (size_t h = 0; h < num_heads_; ++h) {
            size_t base = h * m;
            double* gwv = &grad_wkv_curr(0, h*m*m);
            for (size_t i = 0; i < m; ++i)
                for (size_t j = 0; j < m; ++j)
                    gwv[i*m + j] = last_r_(t, base+i) * grad_output(t, base+j);
            // Add recurrence carrier from t+1's wkv
            double* gnext = &grad_wkv_next(0, h*m*m);
            for (size_t i = 0; i < m; ++i)
                for (size_t j = 0; j < m; ++j)
                    gwv[i*m + j] += gnext[i*m + j];
        }

        // Compute dL/dG_t = wkv_{t-1}^T · dL/dwkv_t  (per head, m×m)
        // Then expand:
        //   dL/dw_t[i] = G_t[i, i] contribution = sum_j dL/dG_t[j, i] · ... ?
        // Actually G_t = diag(w_t) - kappa_hat_t^T (a_t ⊙ kappa_hat_t)
        // dL/diag(w_t)[i] = dL/dG_t[i, i]
        // dL/(kappa_hat_t^T (a_t ⊙ kappa_hat_t))[i, j] = -dL/dG_t[i, j]
        // So:
        //   dL/dw_t[i] = dL/dG_t[i, i]
        //   dL/dkappa_hat_t[i, j] = -a_t[i] · sum_j dL/dG_t[i, j] (sum across j of the outer product row)
        // Wait: d/dkappa_hat_t[i, j] (sum_i' sum_j' G_t[i', j'] · dL/dG_t[i', j'])
        //      = -a_t[i] · dL/dG_t[i, j]  (from the -kappa_hat_t^T (a_t ⊙ kappa_hat_t) term)
        //   dL/da_t[i] = -sum_j kappa_hat_t[i, j] · dL/dG_t[i, j]
        // (kappa_hat_t depends on k_t and xi; the gradient through L2-norm normalization is a chain.)
        // For v1, treat kappa_hat as directly receiving gradient here; the backward of L2 norm is in a separate step.

        // For now: compute dL/dG_t and the resulting partial derivatives of (w_t, kappa_hat_t, a_t).
        // (Details in implementation.)

        // Then: dL/dk_t = dL/dkappa_t · (xi) + dL/dk_tilde_t (for direct k_t contribution)
        //            dL/dv_t = from wkv_{t+1}'s contribution
        //            dL/dr_t = outer(sum_j dL/dwkv_t[j] · wkv_t)  i.e. d_o'/dr_t[h, i] = sum_j wkv_t[h, i, j]
        // ...
    }
    // Backward through Dense projections: W_r.backward(grad_r_pre, 0.0) returns dL/d(r_in)
    //   Then token-shift mixing distributes gradient to x_t and mu_r.
    // ...
    return grad_x;
}
```

## Implementation Notes

### Backward through the wkv state — detailed derivation

The wkv update per head, per token:
```
wkv_t = wkv_{t-1} · G_t  +  v_t^T · k̃_t
```

where `G_t ∈ R^{m×m}`, `wkv_t ∈ R^{m×m}`. Both are stored head-major in a flat tensor.

**Forward shape sanity:** rows of `wkv_t` correspond to value-rows (the value stored for each key); columns correspond to the dimension that `r_t` queries.

**Output** (per head, per token):
```
o_t[j] = sum_i wkv_t[i, j] * r_t[i]
```
So `o_t = wkv_t^T · r_t` if we treat `r_t` as a column. In matrix terms:
```
[o_t]_j = sum_i wkv_t[i, j] * r_t[i]   ⟹   o_t[j] = (wkv_t^T · r_t)[j]
```

**Backward** — given `g_o = ∂L/∂o_t` (incoming gradient from the next layer), compute:

1. `∂L/∂wkv_t[i, j] = r_t[i] * g_o[j]`   (the direct path from output)
   Plus the carrier from `wkv_{t+1}`:
2. `wkv_{t+1} = wkv_t · G_{t+1} + v_{t+1}^T · k̃_{t+1}`
   `∂L/∂wkv_t[i, j] += sum_{i'} G_{t+1}[j, i'] * ∂L/∂wkv_{t+1}[i, i']`

   Actually: `wkv_{t+1}[i', j'] = sum_{i, j} wkv_t[i, j] · G_{t+1}[i, j, i', j']` — but `G_{t+1}` is `m×m` and acts on the right side of `wkv_t`, so:
   ```
   wkv_{t+1}[i, j'] = sum_j wkv_t[i, j] · G_{t+1}[j, j']
   ```
   Therefore:
   ```
   ∂L/∂wkv_t[i, j] += sum_{j'} G_{t+1}[j, j'] · ∂L/∂wkv_{t+1}[i, j']
   ```
   In matrix form: `∂L/∂wkv_t += ∂L/∂wkv_{t+1} · G_{t+1}^T`.

3. `∂L/∂G_t[i, j] = sum_{i'} wkv_{t-1}[i', i] · ∂L/∂wkv_t[i', j]`  (the inner product of wkv_{t-1}'s column i with the column j of ∂L/∂wkv_t)
   In matrix form: `∂L/∂G_t = wkv_{t-1}^T · ∂L/∂wkv_t`.

4. Expand `G_t = diag(w_t) - κ̂_t^T (a_t ⊙ κ̂_t)`:
   ```
   ∂L/∂w_t[i]     = ∂L/∂G_t[i, i]                                          (diagonal contribution)
   ∂L/∂κ̂_t[i, j] = -a_t[i] · ∂L/∂G_t[i, j]                                  (rank-1 contribution, summed across j → ∂L/∂κ̂_t is an outer product)
   ∂L/∂a_t[i]     = -sum_j κ̂_t[i, j] · ∂L/∂G_t[i, j]                       (rank-1 contribution to a_t)
   ```

5. `∂L/∂κ_t[i]`: κ̂_t depends on κ_t via `κ̂_t = κ_t / ||κ_t||_2`. The gradient of `||κ̂||_2 = 1` constraint is automatic (κ̂ has fixed norm). The chain is:
   ```
   ∂L/∂κ_t[i] = (1/||κ_t||_2) · [∂L/∂κ̂_t[i] - κ̂_t[i] · sum_k κ̂_t[k] · ∂L/∂κ̂_t[k]]
   ```
   This is the standard projection-back-to-tangent-space of the L2-normalize backward.

6. `∂L/∂k_t[i]` has three sources:
   - `∂L/∂κ_t[i] · ξ[i]`  (via κ_t = k_t ⊙ ξ)
   - `∂L/∂k̃_t[i]` from the rank-1 `v_t^T · k̃_t` term in the wkv update
   - For the next-token chain (i.e. ∂L/∂k_{t+1}), the κ̂_t depends on κ_{t+1} which depends on k_{t+1}

   `∂L/∂k̃_t[i] = sum_j v_t[j] · ∂L/∂wkv_t[i, j]`  (from `wkv_t = ... + v_t^T · k̃_t`)

   Actually wait — `v_t^T · k̃_t` is an outer product: `(v_t^T · k̃_t)[i, j] = v_t[i] · k̃_t[j]`. So:
   ```
   ∂L/∂k̃_t[j] = sum_i v_t[i] · ∂L/∂wkv_t[i, j]
   ```
   In matrix form: `∂L/∂k̃_t = ∂L/∂wkv_t^T · v_t`.

7. `∂L/∂v_t[i]` from `v_t^T · k̃_t`:
   ```
   ∂L/∂v_t[i] = sum_j k̃_t[j] · ∂L/∂wkv_t[i, j]
   ```
   In matrix form: `∂L/∂v_t = ∂L/∂wkv_t · k̃_t`.

8. `∂L/∂r_t[i]`:
   ```
   ∂L/∂r_t[i] = sum_j wkv_t[i, j] · g_o[j]
   ```
   In matrix form: `∂L/∂r_t = ∂L/∂wkv_t_direct · g_o` (where "direct" is the part before adding the recurrence carrier).

9. **Backward through `k̃_t = k_t ⊙ lerp(1, a_t, α)`**:
   ```
   k̃_t[j] = k_t[j] · (1 + α · (a_t[j] - 1))
   ```
   - `∂L/∂k_t[j] += ∂L/∂k̃_t[j] · (1 + α · (a_t[j] - 1))`
   - `∂L/∂a_t[j] += ∂L/∂k̃_t[j] · k_t[j] · α`
   - `∂L/∂α += sum_j ∂L/∂k̃_t[j] · k_t[j] · (a_t[j] - 1)`

10. **Backward through `w_t = exp(-exp(-0.5) · sigmoid(d_pre_t))`**:
    ```
    d_pre_t[j] = tanh(W_d · x_t^d + b_d)[j]
    ```
    Let `s = sigmoid(d_pre_t[j])`. Then `w_t[j] = exp(-exp(-0.5) · s)`.
    `∂w_t[j]/∂s = -exp(-0.5) · w_t[j]`.
    `∂s/∂d_pre_t = s · (1 - s)`.
    `∂L/∂d_pre_t[j] += ∂L/∂w_t[j] · (-exp(-0.5)) · w_t[j] · s · (1 - s)`.

    Then backprop through tanh: `∂L/∂(W_d · x_t^d + b_d)[j] = ∂L/∂d_pre_t[j] · (1 - tanh^2(...)) = ∂L/∂d_pre_t[j] · (1 - d_pre_t[j]^2)`.
    Then through Dense to get `∂L/∂W_d`, `∂L/∂b_d`, `∂L/∂x_t^d`.

11. **Backward through `a_t = sigmoid(a_pre_t)`**:
    `∂L/∂a_pre_t[j] = ∂L/∂a_t[j] · a_t[j] · (1 - a_t[j])`.
    Then through Dense for `W_a`, `b_a`, `x_t^a`.

12. **Backward through `ξ`**:
    `∂L/∂ξ[i] = k_t[i] · ∂L/∂κ_t[i]`  (from κ_t = k_t ⊙ ξ)

13. **Backward through token-shift** (r/k/v/d/a): same as RWKV-4:
    `∂L/∂x_t = ∂L/∂x_t^r · μ_r + ∂L/∂x_t^k · μ_k + ...` (with shifted carry-forward for `x_{t-1}`).

    `∂L/∂μ_r[i] = ∂L/∂x_t^r[i] · (x_t[i] - x_{t-1}[i])` (per token t).

### Head layout helpers

Since `Tensor` is 2D and wkv needs a per-head m×m slice, we'll use the convention:
- `last_wkv_(T+1, num_heads * m * m)` — row t holds wkv_{t-1} flattened as `[head_0_mat, head_1_mat, ...]` where each `head_h_mat` is m×m stored row-major
- Per-head, per-element: `last_wkv_(t, h * m * m + i * m + j)` is wkv_{t-1}[h, i, j]

For BPTT we maintain `grad_wkv_next(1, num_heads * m * m)` analogously.

### Tolerance choice

Target: rel_err < 1e-3 for parameter gradients via centered FD with eps=1e-5. The chain through:
- L2 normalization (k_t → κ_t → κ̂_t)
- Double-exp decay (d_t → sigmoid(d_t) → exp(-exp(-0.5) · s) → w_t)
- The full wkv update
will introduce some FD noise. 1e-3 is a safe threshold; we expect most entries at < 1e-5 (typical double-precision FD accuracy).

For input gradients, target rel_err < 1e-4 (the BPTT chain through token-shift is more direct).

### Known tricky parts

1. **L2 normalization backward**: the projected gradient formula above (step 5) is required; a naive `∂L/∂κ_t = ∂L/∂κ̂_t / ||κ_t||` is WRONG and will fail FD by ~50%.
2. **`G_t` rank-1 contribution**: the `-κ̂_t^T (a_t ⊙ κ̂_t)` term contributes an outer product to `G_t`. The `∂L/∂κ̂_t` and `∂L/∂a_t` from this term must be computed correctly; the diag term `∂L/∂w_t[i] = ∂L/∂G_t[i, i]` is the easy part.
3. **Recurrence carrier**: `∂L/∂wkv_t` accumulates BOTH the direct `r_t · g_o^T` AND `∂L/∂wkv_{t+1} · G_{t+1}^T`. Skipping the second term will underflow the gradient.
4. **Token-shift chain**: x_t receives gradient contributions from BOTH the current token AND the carry-forward from x_{t+1}. The carry-forward uses `(1 - μ)` not `μ`.

## Pitfalls to avoid

- **Don't add W_o or bonus in v1**: complicates the gradient check. The paper's bonus is `u_t[h, j] = (r_t ⊙ ρ ⊙ k̃_t)[h, :] · v_t[h, j]`, which is a separate scalar per head per token. Skipping it keeps v1 focused.
- **Don't use LayerNorm**: adds gamma/beta parameters and gradient noise that confuses FD tests. The output normalization in v1 is skipped.
- **Don't mix 1-D and 2-D tensor layouts**: stay with `(T, d)` for inputs/outputs, `(T+1, num_heads * m * m)` for wkv cache. Don't try to use 4-D tensors.
- **Verify the recurrence carrier is added**: without it, the gradient check on `W_r` will fail by exactly `1/(1 - max_w)` per timestep (the geometric series of the decay).
- **Verify L2 normalization backward**: a common bug is forgetting the projection-back-to-tangent-space term.
- **Verify the double-exp chain through w_t**: skip any of `exp(-0.5)`, `sigmoid`, or `exp` and the w_t grad will fail FD by O(1).
