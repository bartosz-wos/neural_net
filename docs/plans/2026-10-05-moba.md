# MoBA — Mixture of Block Attention Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Ship `MoBAAttention` — sparse long-context attention that routes each query to a top-k subset of *key blocks* chosen by mean-pooled key affinity, plus a block wrapper and a stacked model.

**Architecture:** Three classes in `include/nn/layers/attention/moba.{h,cpp}`. The layer partitions K/V into contiguous blocks of size `block_size`, computes per-query block affinity `s_i = <q, mean_pool(K[I_i])>` (Eq. 6, **unscaled**), hard-selects the top-`top_k` *historical* blocks plus the always-on current block (Eq. 5 + causal rules), then runs one softmax attention restricted to that union. Backward is hand-derived: the hard top-k is piecewise-constant in the parameters so no gradient flows through the gate; Q/K gradients come only from the attention-logit path, restricted to selected keys.

**Tech Stack:** C++17, repo `Tensor` (2-D, `double`), `Dense`/`LayerNorm`, Makefile, hand-rolled test harness.

**Paper:** Lu, Jiang, Liu, Du, Jiang, Hong, Liu, He, Yuan, Wang, Huang, Yuan, Xu, Lai, Chen, Hong, Liu, He, Yuan, Zhou, Zhang, Zhou, Yang, Zhou, Zhang, Zhang, Yang, Sun, Zhang, Qiu — *MoBA: Mixture of Block Attention for Long-Context LLMs*, arXiv:2502.13189, Moonshot AI / Tsinghua, 18 Feb 2025.

## Verification against the paper (done before writing any task)

Read from the HTML full text (`arxiv.org/html/2502.13189v1`), not from memory:

| Paper | Statement | Consequence for this impl |
|---|---|---|
| Eq. 2 | `MoBA(q,K,V) = Softmax(q K[I]ᵀ) V[I]`, `I ⊆ [N]` | selection is **per-query**; different queries have different `I` |
| Eq. 3 | block `i` covers `I_i = [(i-1)B+1, iB]`, `n = N/B` | require `N % block_size == 0`; **throw** rather than pad (padding would silently change the mean-pool) |
| Eq. 5 | `g_i = 1` iff `s_i ∈ Topk({s_j}, k)` | hard 0/1 mask, not a softmax weight |
| Eq. 6 | `s_i = <q, mean_pool(K[I_i])>` | **MEAN**, and **no `1/√d` scale** (Alg. 1 line 5 is `S = Q K̄ᵀ`) |
| causal | `s_i = -∞, g_i = 0` for block `i` with `pos(q) < i·B` | query `t` may only see blocks `b ≤ t/block_size` |
| current block | `g_i = 1` forced for the block containing `pos(q)`; that block gets a **causal mask** | mean-pooling the current block would leak future tokens, so the paper forces it on and masks it |

The three easiest things to get wrong, each pinned by a test:

1. **Scaling the gate score.** The `inv_temp` scale belongs to the *attention logits*, not to Eq. 6. Applying it to both is the #1 bug. Test: hand-derived gate score vs `last_scores_` to 1e-12, at `inv_temp = 0.5`, so a wrong scale gives exactly 2×.
2. **Mean vs sum pooling.** Sum and mean only rescale the top-k *order* (so top-k selection is unaffected), but they change the K **gradient** — observable via the param FD check, and in the hand-derived score check the factor is 1/`block_size`.
3. **`top_k` counts historical blocks only.** Two readings exist and they differ:
   - (a) top-k over all visible blocks `0..cur`, then OR in current ⇒ `|I_t| = min(top_k, cur+1) + (cur ∉ topk ? 1 : 0)`
   - (b) top-k over historical `0..cur-1`, then add current ⇒ `|I_t| = min(top_k, cur) + 1`

   **(b) is implemented**, matching the paper's "current block is a shared expert, always on" framing and its reported config (`top_k = 3`, `B = 2048`, `N = 32K` ⇒ 3 historical + 1 current). Documented in the header.

### Deliberate deviation: single union softmax instead of online-softmax tiling

Algorithm 1 lines 13-16 run two attention calls (current block causal, selected blocks non-causal) and combine with **online softmax**. That is *not* an average of the branch outputs — averaging gives each branch weight ½ regardless of how many keys it contributed. We instead compute **one softmax over the union `I_t`**:

```
m = max_{i ∈ I_t} z[i,t]                    z[i,t] = <q_t, k_i> · inv_temp
A[i,t] = exp(z[i,t] − m) / Σ_{i' ∈ I_t} exp(z[i',t] − m)
o_t = Σ_{i ∈ I_t} A[i,t] · v_i
```

Mathematically identical to the tiled combine (a tiled softmax is just a partitioned max-subtract softmax), but it removes an entire class of online-softmax merge bugs and is testable at N=8. Cost is `O(|I_t|)` per query instead of two small softmaxes — the right trade at this repo's scale. FlashAttention varlen / gather-scatter / tiling are **out of scope** for v1.

### Backward: no gradient through the gate

The hard top-k is `argmax`-based ⇒ piecewise constant in the parameters ⇒ **zero gradient** through `s_i` into Q/K. This matches every other hard-routing layer in this repo (`tokenformer.h`, `tome.h`). So:

- Q/K gradients come **only** from the attention-logit path — the same term set as standard MHA, but summed over *selected* keys only.
- Unselected keys must receive **exactly zero** K gradient. The accumulation buffer is freshly zeroed each call (never carried across calls). Test 9b pins this exactly (design below).

Chain, per head `h`, query `t`, key `i ∈ I_t`, given `dO[t,d]`:

```
dA[i,t]  = Σ_d dO[t,d] · v_i,d
dV[i,d] += A[i,t] · dO[t,d]
dS[i,t]  = A[i,t] · (dA[i,t] − Σ_{i'∈I_t} A[i',t]·dA[i',t])     softmax backward
dz[i,t]  = dS[i,t] · inv_temp                                    # <-- easy to drop
dq_t,c  += Σ_{i∈I_t} dz[i,t] · k_i,c
dk_i,c  += dz[i,t] · q_t,c                                        # ONLY i ∈ I_t
```

Then projections (`Dense` convention `y = x·Wᵀ + b`, `W` shaped `(d_model, d_model)`):

```
dO_pre[t,j] = Σ_c dO[t,c] · W_o[j,c]
grad_W_o[j,c] += Σ_t dO_pre[t,j] · O[t,c]      db_o[j] += Σ_t dO_pre[t,j]
grad_W_q[c,j] += Σ_t dq[t,c] · input[t,j]      db_q[c]   += Σ_t dq[t,c]     (same for k, v)
d_input[t,j]  = Σ_c dq[t,c]·W_q[c,j] + Σ_c dk[t,c]·W_k[c,j] + Σ_c dv[t,c]·W_v[c,j]
```

## Non-goals (v1)

FlashAttention varlen / gather-scatter / online-softmax tiling (Alg. 1 lines 10-16) · chunked prefill · KV-cache · GQA/MQA · MoBA/full layer-wise hybrid (§3.2 — a trainer concern, not a layer).

## API

```cpp
MoBAAttention(size_t d_model, size_t num_heads = 1,
              size_t block_size = 32, size_t top_k = 1, bool causal = true);
```

- `top_k` counts **historical** blocks; current block is always added ⇒ `|I_t| ≤ top_k + 1`.
- Ctor throws on `d_model == 0`, `num_heads == 0`, `d_model % num_heads != 0`, `block_size == 0`, `top_k == 0`.
- `forward` throws if `input.cols != d_model_`, if `N == 0`, or if `N % block_size_ != 0`.
- Parameters: 8 tensors — `{W_q.weights, W_q.bias, W_k.weights, W_k.bias, W_v.weights, W_v.bias, W_o.weights, W_o.bias}`.

## Conventions (match `stick_breaking.h`)

- Input/output `(N, d_model)`; N tokens, no batch dim.
- Heads are contiguous column slices: head `h`, channel `c` of token `t` is `X(t, h*head_dim + c)`.
- The repo's `Tensor` is **2-D only**. Head axis is flattened into **rows**: `last_scores_` and `last_gate_` are `(num_heads * N, n_blk)` with row `h*N + t`; `last_A_` is `(num_heads * N, N)`.
- Param grads accumulate into raw `grad_W_*` / `grad_b_*` tensors, **not** via `Dense::backward` (manual control needed), same as `stick_breaking`.

// Gate score hand-computed straight from Eq. 6, WITHOUT calling the layer.
// Dense convention: y = x*W^T + b  =>  K[t,c] = sum_j x[t,j]*W_k[c,j] + b_k[c]
static double hand_gate_score(const MoBAAttention& a, const Tensor& x,
                              size_t t, size_t b, size_t block_size) {
    double dot = 0.0;
    for (size_t c = 0; c < a.head_dim(); ++c) {
        double q = a.W_q.bias(c);
        for (size_t j = 0; j < x.cols; ++j) q += x(t, j) * a.W_q.weights(c, j);
        double ksum = 0.0;
        for (size_t s = b * block_size; s < (b + 1) * block_size; ++s) {
            double kv = a.W_k.bias(c);
            for (size_t j = 0; j < x.cols; ++j) kv += x(s, j) * a.W_k.weights(c, j);
            ksum += kv;
        }
        dot += q * (ksum / static_cast<double>(block_size));   // MEAN pool, not sum
    }
    return dot;                    // NO inv_temp -- the assertion's whole point
}

```cpp
Tensor MoBAAttention::forward(const Tensor& input) {
    const size_t N = input.rows;
    if (input.cols != d_model_)  throw std::invalid_argument("MoBA: input cols must equal d_model");
    if (N == 0)                 throw std::invalid_argument("MoBA: empty input");
    if (N % block_size_ != 0)   throw std::invalid_argument("MoBA: N must be divisible by block_size");

    const size_t d_h   = head_dim_;
    const size_t n_blk = N / block_size_;

    last_input_ = input.clone();
    const Tensor Q = W_q.forward(input);      // (N, d_model)
    const Tensor K = W_k.forward(input);
    const Tensor V = W_v.forward(input);
    last_Q_ = Q.clone(); last_K_ = K.clone(); last_V_ = V.clone();

    // --- Kbar: mean-pool each block of keys (Algorithm 1 line 4) ---
    Tensor Kbar(n_blk, d_model_);
    for (size_t b = 0; b < n_blk; ++b)
        for (size_t c = 0; c < d_model_; ++c) {
            double s = 0.0;
            for (size_t t = b * block_size_; t < (b + 1) * block_size_; ++t) s += K(t, c);
            Kbar(b, c) = s / static_cast<double>(block_size_);
        }

    // --- S: UNSCALED block affinity (Eq. 6 / Algorithm 1 line 5) ---
    Tensor S(num_heads_ * N, n_blk);
    for (size_t h = 0; h < num_heads_; ++h)
        for (size_t t = 0; t < N; ++t)
            for (size_t b = 0; b < n_blk; ++b) {
                double dot = 0.0;
                for (size_t c = 0; c < d_h; ++c) dot += Q(t, h*d_h+c) * Kbar(b, h*d_h+c);
                S(h * N + t, b) = dot;
            }
    last_scores_ = S.clone();

    // --- causal top-k gate (Eq. 5 + current-block rule) ---
    last_gate_ = Tensor::zeros(num_heads_ * N, n_blk);
    selected_.assign(num_heads_, std::vector<std::vector<size_t>>(N));
    std::vector<size_t> order(n_blk);
    for (size_t h = 0; h < num_heads_; ++h)
        for (size_t t = 0; t < N; ++t) {
            const size_t cur    = t / block_size_;
            const size_t n_hist = cur;                 // historical blocks 0..cur-1
            for (size_t b = 0; b < n_hist; ++b) order[b] = b;
            std::sort(order.begin(), order.begin() + n_hist,
                      [&](size_t x, size_t y) {
                          if (S(h*N+t, x) != S(h*N+t, y)) return S(h*N+t, x) > S(h*N+t, y);
                          return x < y;                // deterministic tie-break
                      });
            const size_t k_sel = std::min(top_k_, n_hist);
            auto& sel = selected_[h][t];
            sel.clear();
            for (size_t m = 0; m < k_sel; ++m) {
                last_gate_(h*N+t, order[m]) = 1.0;
                sel.push_back(order[m]);
            }
            last_gate_(h*N+t, cur) = 1.0;              // force current block
            sel.push_back(cur);
            std::sort(sel.begin(), sel.end());
        }

    // --- one softmax over the union I_t (== the paper's tiled combine) ---
    Tensor A(num_heads_ * N, N);
    Tensor O(N, d_model_);
    std::vector<size_t> keys;
    std::vector<double>  ex;
    for (size_t h = 0; h < num_heads_; ++h)
        for (size_t t = 0; t < N; ++t) {
            keys.clear();
            for (size_t b : selected_[h][t]) {
                const size_t lo  = b * block_size_;
                const size_t hi  = lo + block_size_;
                const size_t end = (causal_ && b == t / block_size_)
                                  ? std::min(hi, t + 1) : hi;   // causal in current block
                for (size_t i = lo; i < end; ++i) keys.push_back(i);
            }
            double qmax = -std::numeric_limits<double>::infinity();
            std::vector<double> z(keys.size());
            for (size_t m = 0; m < keys.size(); ++m) {
                double dot = 0.0;
                for (size_t c = 0; c < d_h; ++c)
                    dot += Q(t, h*d_h+c) * K(keys[m], h*d_h+c);
                z[m] = dot * inv_temp_;
                qmax = std::max(qmax, z[m]);
            }
            ex.assign(keys.size(), 0.0);
            double denom = 0.0;
            for (size_t m = 0; m < keys.size(); ++m) { ex[m] = std::exp(z[m] - qmax); denom += ex[m]; }
            for (size_t m = 0; m < keys.size(); ++m) A(h*N+t, keys[m]) = ex[m] / denom;
            for (size_t c = 0; c < d_h; ++c) {
                double acc = 0.0;
                for (size_t m = 0; m < keys.size(); ++m)
                    acc += (ex[m] / denom) * V(keys[m], h*d_h+c);
                O(t, h*d_h+c) = acc;
            }
        }
    last_A_ = A.clone();
    last_O_ = O.clone();
    return W_o.forward(O);
}
```

```cpp
// 9b. EXACT zero K-gradient on keys no query can see.
// N=8, d_model=4, block_size=4, top_k=1, num_heads=1 -> blocks {0:[0,4), 1:[4,8)}.
// Queries 0..3 live in block 0, so there are NO historical blocks visible to
// them: I_t = {0} for all of t in 0..3, i.e. they see ONLY keys 0..3.
// Queries 4..7 may also see block 1. Driving grad_output to zero on rows 4..7
// means only queries 0..3 contribute, and for those key columns 4..7 never
// enter I_t -> grad_W_k[c, 4..7] must be EXACTLY 0.0.
static void test_unselected_keys_get_zero_k_grad() {
    MoBAAttention a(4, 1, 4, 1);
    randomize(a, 640);
    Tensor x = rand_tensor(8, 4, 61, 1.0);
    Tensor out = a.forward(x);
    Tensor g(out.rows, out.cols);
    for (size_t t = 0; t < 8; ++t)
        for (size_t c = 0; c < 4; ++c)
            g(t, c) = (t < 4) ? (0.3 + 0.1 * c) : 0.0;    // rows 4..7 silent
    a.zero_grad();
    a.backward(g, 0.0);

    double max_invisible = 0.0;
    for (size_t c = 0; c < 4; ++c)
        for (size_t j = 4; j < 8; ++j)                    // key columns 4..7
            max_invisible = max(max_invisible, std::fabs(a.grad_W_k(c, j)));
    cout << "  max |grad_W_k| over invisible key columns = "
         << scientific << max_invisible << endl;
    check("unselected keys get EXACTLY zero K gradient", max_invisible == 0.0);

    // Non-vacuity: the visible columns must be NON-zero, else the test is
    // trivially satisfied by a backward that computes nothing at all.
    double max_visible = 0.0;
    for (size_t c = 0; c < 4; ++c)
        for (size_t j = 0; j < 4; ++j)
            max_visible = max(max_visible, std::fabs(a.grad_W_k(c, j)));
    check("visible key columns have NON-zero K gradient (test is non-vacuous)",
          max_visible > 1e-12);
}
```

> The `block_size = 4` choice is load-bearing. `block_size = 8` gives a single block where every key is visible — the zero-gradient assertion would then pass vacuously. `top_k` is irrelevant for queries 0..3 because they have no historical blocks.

**Step 2 — verify RED.** `backward` unimplemented.

**Step 3 — implementation** — exactly the chain in "Backward: no gradient through the gate" above. Notes:
- Read `A` from `last_A_`; `dA[i,t] = Σ_d dO[t,h*d_h+d] · V(i, h*d_h+d)`. **No `inv_temp` here** — `A` is post-softmax.
- Row-sum term `Σ_{i'∈I_t} A[i',t]·dA[i',t]`: iterate over the gathered key list from `selected_` (current block truncated to `t+1` when causal), **not** over all `i ∈ [0,N)` — otherwise the unselected `A = 0` entries contribute 0 anyway, so either form is numerically identical, but using the key list keeps intent explicit.
- `dk` is `Tensor::zeros(N, d_model)` allocated fresh per call. Never accumulate across calls.
- `grad_W_*` / `grad_b_*` **accumulate** (`+=`) across calls (repo convention) — only `dk`/`dq`/`dv` are per-call scratch.
- `zero_grad()` clears all 8. `update_weights(lr)` does manual SGD on weights **and** biases.
