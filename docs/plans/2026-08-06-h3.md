# H3 Layer (Hungry Hungry Hippos) Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add the H3 sequence layer from Fu et al. 2023 ("Hungry Hungry Hippos: Towards Language Modeling with State Space Models", https://arxiv.org/abs/2212.14052) to the recurrent sequence-modeling layers, with a thorough gradient-checked test suite.

**Architecture:** Two stacked SSMs — a Shift-SSM (memory of previous tokens) and a Diagonal-SSM (long-range memory) — sandwiched between input projections Q/K/V and an output projection O, with multiplicative interactions between them. The Shift-SSM gives local "recall" capability; the Diagonal-SSM gives long-range recall; the multiplicative interactions give the comparison capability of attention.

**Tech Stack:** C++17, raw Tensors (no external dependencies), Dense layer for Q/K/V/O projections, custom per-token head loops.

---

## Motivation

H3 is a Google/Stanford citation-paper (ICLR 2023, ~700 citations) that sits between S4/Mamba and attention in the **sequence-modeling design space**. It shows that:

1. Plain SSMs (S4D, GSS) fail simple synthetic language tasks that attention solves trivially (Induction Head, Associative Recall).
2. Multiplicative interactions between SSM outputs and input projections are the missing piece — they give SSMs the *comparison* capability.
3. The H3 layer (Shift SSM ⊙ V → Diag SSM → Q ⊙ output) matches attention on these synthetic tasks and is within 0.4 PPL of Transformers on OpenWebText.

The library already has Mamba (S6), Mamba-2 (SSD), RWKV, RetNet, mLSTM, sLSTM, Conformer, Hyena, MLP-Mixer — every other major sequence-modeling architecture. **H3 is the missing piece** in the SSM lineage.

---

## Why this matters for the library

- **Closes a gap in the recurrent family.** H3 is the canonical example of "multiplicative SSM" — between linear attention (no input projection) and Mamba (input-dependent everything). Showing all three in the same library helps understand the design space.
- **Theoretical/pedagogical value.** The paper's analysis ("Shift-SSM + multiplicative gates addresses what plain SSMs can't") is the cleanest motivation for the multi-SSM stacking pattern. A teaching library should have it.
- **Practical use.** H3 was scaled to 2.7B parameters and (per the paper) matched/beaten Transformers on OpenWebText. The RecurrentGemma / Griffin line of models is its direct descendant.

## Mathematical Specification

Following Fu et al. 2023, Algorithm 1 (with the simplifications noted under "Implementation choices"):

**Input:** u ∈ R^{N×d} — sequence of length N, hidden dim d.

**Step 1 — Input projections:** Q = u·W_Q, K = u·W_K, V = u·W_V (each in R^{N×d})

**Step 2 — Shift SSM on K:** K̄ = SSM_shift(K) ∈ R^{N×d}
- We use the canonical simple form: B = e_1 (fixed first basis vector), C = identity (fixed).
- State shape: x_t ∈ R^{d} (state dims = head dim d_h, and d_h = d/H for H heads; we use H=1 in the simplest case, so state shape = d).
- Recurrence: x_t = shift(x_{t-1}); x_t[0] = K_t; x_t[i] = x_{t-1}[i-1] for i > 0.
- Equivalently: x_t = [K_t, K_{t-1}, ..., K_{t-d+1}] — a sliding window of K values.
- Output: K̄_t = x_t (since C = identity).

**Step 3 — Split Q, K̄, V into H heads of dimension d_h = d/H.**
(For the simplest case H=1, d_h = d.)

**Step 4 — Per-head core:**
- Outer product: z_t = K̄_t ⊗ V_t ∈ R^{d_h × d_h}
- Diagonal SSM: Z_t[i,j] = λ[i,j] · Z_{t-1}[i,j] + z_t[i,j] (per-channel exponential gate)
- Recall: O_t[i] = sum_j Q_t[j] · Z_t[j,i] — i.e., O_t = Q_t · Z_t ∈ R^{d_h}

**Step 5 — Output projection:** y = O · W_O ∈ R^{N×d}

**Parameters (learnable):**
- W_Q, W_K, W_V, W_O (Dense layers, d → d)
- λ_log (shape d_h × d_h; λ = sigmoid(λ_log) to keep λ ∈ (0, 1))

**Backward:**
- Standard chain through output projection
- Through Q·Z: dQ_t = dO_t · Z_t^T; dZ_t = Q_t^T · dO_t
- Through diag SSM: the recurrence Z_t = λ·Z_{t-1} + z_t has a backward analogue — Z_t^≥t (the gradient at Z_t propagated forward from time t onward) needs to be computed. The recurrence is: grad_z_t = dZ_t + λ·grad_Z_{t+1}, propagated backward from t = N-1 to 0.
   - More precisely: with G_t = dZ_t (the loss gradient at Z_t), the gradient at z_t is G_t + λ·G_{t+1} + λ^2·G_{t+2} + ... = sum_{s≥t} λ^{s-t} · G_s
- Backward through outer product: z_t = K̄_t ⊗ V_t → dK̄_t = sum_j dZ_t·[i,j] · V_t[j] (contraction over j) = (dZ_t · V_t^T)[i]; dV_t = sum_i dZ_t[i,j] · K̄_t[i] = (K̄_t^T · dZ_t)[j]
- Backward through shift SSM: K̄_t = [K_t, K_{t-1}, ..., K_{t-d+1}] → dK_t = sum_{s: s ≤ t, s ≥ t-d+1} dK̄_s[s - (t - d + 1)] — i.e., dK_t is the sum of dK̄ entries that "remembered" K_t.
- Backward through Q/K/V projections: standard Dense backward.

## Implementation Choices

These are the simplifications chosen for clean gradient checks and pedagogical clarity:

1. **Single head (H = 1).** The paper's multi-head version is a reshape/permute. We start with H=1 to keep the math tractable. Future work: extend to multi-head.
2. **State dim = d** (head dim = d). Shift-SSM state has d slots, holding the last d K values.
3. **B = e_1, C = I.** Fixed per the paper's "for simplicity" option. This makes the shift SSM a pure sliding window.
4. **D = 0** (no skip connection in the SSM step). The paper says D exists but its contribution is minor; we omit it for clarity.
5. **λ via sigmoid λ_log.** Same as Mamba's "A = -exp(A_log)" pattern — sigmoid keeps λ ∈ (0, 1) without constraint.

## Test Plan

Following the convention from `test_mamba.cpp`, `test_hyena.cpp`, `test_mamba2.cpp`:

1. **Forward shape** — H3Block(T, d) → (T, d).
2. **Output is finite** — no NaN/Inf for typical inputs.
3. **Shift SSM sliding-window property** — verify last_input_ reconstructs K̄_t — K values from 0..d-1 steps ago.
4. **Diag SSM state propagation** — verify Z_t = λ·Z_{t-1} + z_t sequence in the cache.
5. **Input gradient check** — analytical vs FD on u.
6. **W_Q gradient check**.
7. **W_K gradient check** — tests the shift-SSM backward.
8. **W_V gradient check** — tests the diag-SSM backward through the outer product.
9. **W_O gradient check** — standard Dense backward.
10. **λ_log gradient check** — tests the diag-SSM λ gradient chain.
11. **zero_grad clears all gradients**.
12. **Training step reduces loss** — 30 SGD-style steps on a regression target.
13. **Parameters()/gradients() shape consistency**.

Test config: T=4, d=2 (small enough for tractable grad checks at machine precision).
