# TTT-MLP (Test-Time Training, MLP Variant) Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a `TTTMLP` layer that mirrors `TTTLinear` but with a 2-layer GELU MLP as the recurrent state, following Sun et al. NeurIPS 2024 ("Learning to (Learn at Test Time): RNNs with Expressive Hidden States", https://arxiv.org/abs/2407.04620) and the official PyTorch reference (https://github.com/test-time-training/ttt-lm-pytorch/blob/main/ttt.py `TTTMLP` class).

**Architecture:** Sequence mixer where the persistent recurrent STATE is the two weight matrices `(W1, W2)` of a 2-layer MLP with GELU nonlinearity. At each token t, both matrices are updated via a single closed-form gradient-descent step on a self-supervised reconstruction loss. Same single-step GD simplification as `TTTLinear` (no mini-batching, no dual form). The `TTTMLP` projection dims are `d_model → d_inner → 4·d_inner (GELU) → d_inner → d_model`, with the recurrent state being `(W1, b1)` ∈ R^{d_inner × 4·d_inner} × R^{4·d_inner} and `(W2, b2)` ∈ R^{4·d_inner × d_inner} × R^{d_inner}.

**Tech Stack:** C++17, existing `Tensor`, `Dense`, `Layer` infrastructure in `include/nn/core/`.

---

## Math (the single-step-GD simplification, mirroring TTTLinear)

For each token t with pre-projected input z_t ∈ R^{d_inner}:

```
  Z1_t  = W1_{t-1} · z_t + b1_{t-1}               ∈ R^{4·d_inner}   (pre-activation, hidden)
  X2_t  = gelu(Z1_t)                              ∈ R^{4·d_inner}   (post-activation)
  Z2_t  = W2_{t-1} · X2_t + b2_{t-1}               ∈ R^{d_inner}     (output of inner MLP, pre-LN)
  err_t = Z2_t - z_t                              ∈ R^{d_inner}     (the "innovation" / res. error)
  W2_t  = W2_{t-1} - η · err_t ⊗ X2_t / (||X2_t||² + λ)   ∈ R^{4·d_inner × d_inner}
  b2_t  = b2_{t-1} - η · err_t / (||X2_t||² + λ)            ∈ R^{d_inner}
  W1_t  = W1_{t-1} - η · (gelu'(Z1_t) ⊙ (W2_t^T · err_t)) ⊗ z_t / (||z_t||² + λ)
                                                       ∈ R^{d_inner × 4·d_inner}
  b1_t  = b1_{t-1} - η · (gelu'(Z1_t) ⊙ (W2_t^T · err_t)) / (||z_t||² + λ)
                                                       ∈ R^{4·d_inner}
  o_t   = W2_t · gelu(W1_t · z_t + b1_t) + b2_t    ∈ R^{d_inner}   (post-update output)
  y_t   = W_out · o_t + b_out                      ∈ R^{d_model}
```

Note: the order is W2 first (inner-output), then W1 (inner-hidden). This is because `err_t = Z2_t - z_t` is the gradient of `0.5 ||W2·gelu(W1·z) - z||²` w.r.t. `(W2·gelu(W1·z))`, which gives the "output layer" gradient `err_t ⊗ X2_t / (||X2_t||²+λ)` directly; the "hidden layer" gradient `gelu'(Z1_t) ⊙ (W2_t^T · err_t)` flows back through the gelu and W2.

Backward is the full BPTT chain through the per-token update, with two `A_t` Jacobians (one for W1, one for W2) propagating the future-token gradient backward.

public:

    // The W1 matrix has shape (4·d_inner, d_inner) and W2 has shape (d_inner, 4·d_inner).

           size_t mlp_ratio = 4);

    Tensor backward(const Tensor& grad_output, double learning_rate) override;
    void update_weights(double learning_rate) override;
    void zero_grad() override;

    std::vector<Tensor*> parameters() override;
    std::vector<Tensor*> gradients() override;
    Tensor get_weights() const override;
    Tensor get_gradients() const override;
    std::string name() const override { return "TTTMLP"; }

    // Accessors
    size_t d_model() const { return d_model_; }
    size_t d_inner() const { return d_inner_; }
    size_t d_hidden() const { return d_hidden_; }
    double eta() const { return eta_; }
    double lambda_reg() const { return lambda_reg_; }
    const Tensor& W1_state() const { return W1_state_; }
    const Tensor& W2_state() const { return W2_state_; }
    const Tensor& b1_state() const { return b1_state_; }
    const Tensor& b2_state() const { return b2_state_; }
    const Tensor& W_in() const { return W_in_.weights; }
    const Tensor& W_out() const { return W_out_.weights; }

    void reset_state();
private:
    // Sizes
    size_t d_model_, d_inner_, d_hidden_;
    double eta_, lambda_reg_;
    size_t mlp_ratio_;

    // Slow weights (learnable projections + biases of the inner MLP — held via Dense or directly)
    Dense W_in_;        // (d_inner, d_model)
    Dense W_out_;       // (d_model, d_inner)
    Tensor b_in_;       // (1, d_inner)      -- bias added after pre-projection
    Tensor b_out_;      // (1, d_model)      -- output bias (handled by W_out_'s own bias, optional)

    // Fast weights (persistent state)
    Tensor W1_state_;   // (d_hidden, d_inner) — hidden-layer weights
    Tensor W2_state_;   // (d_inner, d_hidden) — output-layer weights
    Tensor b1_state_;   // (1, d_hidden)
    Tensor b2_state_;   // (1, d_inner)

    // Gradient buffers
    Tensor grad_W1_w_, grad_W1_b_;
    Tensor grad_W2_w_, grad_W2_b_;
    Tensor grad_W_in_w_, grad_W_in_b_;
    Tensor grad_W_out_w_, grad_W_out_b_;
    Tensor grad_b_in_;

    // Forward cache for backward
    Tensor last_input_;        // (T, d_model)
    Tensor last_z_;            // (T, d_inner)        -- pre-projected inputs
    Tensor last_W1_t_;         // (T+1, d_hidden, d_inner) flat
    Tensor last_W2_t_;         // (T+1, d_inner, d_hidden) flat
    Tensor last_b1_t_;         // (T+1, d_hidden)
    Tensor last_b2_t_;         // (T+1, d_inner)
    Tensor last_Z1_;           // (T, d_hidden)       -- pre-activation, hidden
    Tensor last_X2_;           // (T, d_hidden)       -- post-gelu(Z1)
    Tensor last_Z2_;           // (T, d_inner)        -- W2 · X2 + b2  (post-update)
    Tensor last_o_pre_;        // (T, d_inner)        -- W2_t · gelu(W1_t · z_t + b1_t) + b2_t
    Tensor last_o_;            // (T, d_inner)        -- post-update inner output (o_pre + b_in_)

    size_t last_T_;

    void initialize_state();
    void check_shapes() const;
};

class TTTMLPModel : public Layer {

### Task 2: Implement `forward()` — `include/nn/layers/recurrent/ttt_mlp.cpp`

**Files:**
- Create: `include/nn/layers/recurrent/ttt_mlp.cpp`

**Step 1:** Write constructor with validation (mirrors TTTLinear):
- d_model > 0, d_inner > 0, mlp_ratio >= 1
- eta > 0, lambda_reg >= 0
- If d_inner == 0, default to d_model.
- d_hidden_ = d_inner * mlp_ratio_

**Step 2:** Write `initialize_state()`:
- W1_state_ ← Tensor::random(d_hidden_, d_inner_, 0.02) (paper uses 0.02 std)
- W2_state_ ← Tensor::random(d_inner_, d_hidden_, 0.02)
- b1_state_, b2_state_ ← zeros

**Step 3:** Write `forward()`:
- Clone `last_input_ = input.clone()`
- z = W_in_.forward(input); add b_in_ bias; cache `last_z_ = z.clone()`
- Allocate caches (size T+1 in time dimension)
- Copy W1_state_/W2_state_/b1_state_/b2_state_ into slot t=0
- For t = 0..T-1:
    - Z1 = W1_prev · z_t + b1_prev   (shape d_hidden)
    - X2 = gelu(Z1)                  (branched: 0.5·x·(1 + tanh(sqrt(2/π)·(x + 0.044715·x³))) for tanh-approx)
    - Z2 = W2_prev · X2 + b2_prev    (shape d_inner)
    - err = Z2 - z_t                 (the "innovation")
    - W2_new = W2_prev - (η / (||X2||²+λ)) · err ⊗ X2
    - b2_new = b2_prev - (η / (||X2||²+λ)) · err
    - Compute the inner-grad delta = gelu'(Z1) ⊙ (W2_new^T · err)   (shape d_hidden)
    - W1_new = W1_prev - (η / (||z_t||²+λ)) · delta ⊗ z_t
    - b1_new = b1_prev - (η / (||z_t||²+λ)) · delta
    - o_pre = W2_new · gelu(W1_new · z_t + b1_new) + b2_new
    - Cache all: Z1, X2, Z2, o_pre, W1/W2/b1/b2 at slot t+1
- Stack: last_o_ = o_pre + b_in_ (the same per-token add)
- y = W_out_.forward(last_o_); return y.

### Task 3: Implement `backward()` — full BPTT

**Files:**
- Modify: `include/nn/layers/recurrent/ttt_mlp.cpp`

**Backward math (reverse-time):**

For each step t, given:
- grad_o_pre[t] (gradient on last_o_pre_[t] — actually it's the gradient w.r.t. last_o_[t])
- cache: z_t, Z1_t, X2_t, Z2_t, o_pre_t, W1_t, W2_t, b1_t, b2_t

Local (direct) gradients at step t:
```
  d_err := grad_o_pre[t]    (passed in from grad_o / future-token chain)

  // Direct gradient w.r.t. W2 (output-layer fast weights), step t:
  //   W2_t = W2_{t-1} - (η/d_X) · err_t ⊗ X2_t      where d_X = ||X2_t||² + λ
  //   ⇒ direct dW2_step[t] = grad_o_pre[t] ⊗ X2_t / d_X      [shape: (d_inner, d_hidden)]
  //   direct db2_step[t] = grad_o_pre[t] / d_X                [shape: (d_inner,)]
  //
  // Direct gradient w.r.t. W1 (hidden-layer fast weights), step t:
  //   delta_t = gelu'(Z1_t) ⊙ (W2_t^T · err_t)
  //   W1_t = W1_{t-1} - (η/d_Z) · delta_t ⊗ z_t      where d_Z = ||z_t||² + λ
  //   ⇒ direct dW1_step[t] = delta_t ⊗ z_t / d_Z     [shape: (d_hidden, d_inner)]
  //   direct db1_step[t] = delta_t / d_Z             [shape: (d_hidden,)]

  // Recurrence Jacobian A2_t = ∂W2_t/∂W2_{t-1} = I - (η/d_X) · X2_t X2_t^T
  //                         A1_t = ∂W1_t/∂W1_{t-1} = I - (η/d_Z) · z_t z_t^T
  // (analogous to TTTLinear)

  // BPTT chain (reverse):
  //   dL/dW2_t = direct dW2_step[t] + A2_{t+1}^T · dL/dW2_{t+1}
  //   dL/dW1_t = direct dW1_step[t] + A1_{t+1}^T · dL/dW1_{t+1}
  //   dL/dW2_{t-1} = A2_t^T · dL/dW2_t
  //   dL/dW1_{t-1} = A1_t^T · dL/dW1_t

  // Gradient w.r.t. z_t (input of the inner MLP) — needed to backprop into W_in:
  //   o_pre[t] = W2_t · gelu(W1_t · z_t + b1_t) + b2_t
  //   dz_t has contributions from:
  //     (a) the direct path through (W2_t · X2_t) when "err_t" changes because z_t changes:
  //         ∂Z2_t/∂z_t = ∂err_t/∂z_t = W2_{t-1} · gelu'(Z1_t) ⊙ (W1_{t-1} · ...  -- complicated
  //         For simplicity (and to keep TTTLinear's simplification consistent), we treat z_t as
  //         "the input to a frozen-from-the-perspective-of-input-grad small MLP at step t".
  //         The cleanest formulation: z_t feeds both into W1_t (via the denominator derivative
  //         and the A1_t path) AND into the inner-output o_pre_t directly via W1_t (the gelu
  //         preactivation derivative and W1_t · z_t term).
  //
  //   For tractability we use the same simplification as TTTLinear: treat z_t as a parameter-like
  //   quantity only w.r.t. the per-step update rule's ∂W_t/∂z_t contribution, and backprop through
  //   o_pre_t via a direct chain rule.
  //
  //   dz_t  =  ∂o_pre_t/∂z_t  +  ∂W_t-chains/∂z_t
  //
  //   The "direct" part:
  //     o_pre_t[i] = sum_j W2_t[i,j] · gelu((W1_t · z_t)[j] + b1_t[j])
  //     ∂o_pre_t[i]/∂z_t[k] = sum_j W2_t[i,j] · gelu'(Z1_t[j]) · W1_t[j,k]
  //     ⇒ direct dz[k] += sum_i grad_o_pre[t,i] · W2_t[i,j] · gelu'(Z1_t[j]) · W1_t[j,k]
  //                     = sum_j gelu'(Z1_t[j]) · W1_t[j,k] · (sum_i grad_o_pre[t,i] · W2_t[i,j])
  //                     = sum_j gelu'(Z1_t[j]) · W1_t[j,k] · (W2_t^T · grad_o_pre[t])[j]
  //                     = sum_j gelu'(Z1_t[j]) · W1_t[j,k] · (err_from_grad)[j]
  //   where err_from_grad = W2_t^T · grad_o_pre[t]   (NOT the actual err_t = Z2_t - z_t)
  //
  //   The "recurrence" part (∂W_t/∂z_t contributions):
  //     dL/dW_t (from future chain) → ∂W_t[i,j]/∂z_t[k]
  //
  //     For W2: ∂W2_t[i,j]/∂z_t[k] = 0    (W2 update only depends on X2_t, not z_t directly)
  //             (but X2_t depends on z_t via W1 update and gelu, so there's an indirect path;
  //              following the TTTLinear simplification, we IGNORE the indirect contribution
  //              because it would couple the two state matrices — a tractability choice.)
  //
  //     For W1: ∂W1_t[i,j]/∂z_t[k] = -(η/d_Z)·[(W1_{t-1}[i,k]-δ_{ik})·z_t[j] + delta_t[i]·δ_{jk}]
  //                                   + η · delta_t[i] · z_t[j] · 2z_t[k] / d_Z²
  //         (the same formula as TTTLinear with err → delta and z → z_t)
```

Implementation outline:
1. Backward through W_out (gets grad_o = (T, d_inner))
2. Add grad_b_in_ accumulator from grad_o
3. For each step t (forward order), compute direct dW2_step[t] = grad_o[t] ⊗ X2_t / d_X and direct db2_step[t] = grad_o[t] / d_X
4. For each step t (forward order), compute direct dW1_step[t] and db1_step[t] from delta_t = gelu'(Z1_t) ⊙ (W2_t^T · grad_o[t]) -- note: the W2 used here should be W2_post_update (W2_t), since the post-update W2 is the one that produced o_pre_t
5. Accumulate forward direct contributions into grad_W1_w_/grad_W2_w_/grad_b1_/grad_b2_
6. Compute direct dz_t contribution from the o_pre_t path
7. Reverse-time BPTT loop:
   - At step t: dL/dW2_t = dW2_step[t] + dW2_total; dL/dW1_t = dW1_step[t] + dW1_total
   - Accumulate dW2_total = A2_t^T · dL/dW2_t  (for the next iteration, t-1)
   - Accumulate dW1_total = A1_t^T · dL/dW1_t
   - Also accumulate dz_t contribution from dL/dW1_t via ∂W1_t/∂z_t (the recurrence contribution)
8. Backward through W_in (gets grad_input)

**Pitfalls to watch for** (from systematic-debugging §5):
- Be careful: TTTLinear computes `dz_total(t, k) += dz_acc` from `dL/dW_t`. Here we must do it analogously for `dL/dW1_t`. The W2 chain does NOT contribute to dz directly (since W2 update doesn't depend on z_t in our simplification).
- The A2_t and A1_t Jacobians are independent (W2 chain decoupled from W1 chain given our z_t-decoupling assumption), so we can keep `dW2_total` and `dW1_total` as separate state.
- Direct dW2 step uses grad_o[t] (NOT err_t). The err_t in the W2 update is `Z2 - z_t`, but the GRADIENT flow `∂L/∂W2_t = ∂L/∂o_pre[t] · ∂o_pre[t]/∂W2_t` uses grad_o_pre[t] directly.
- For the recurrence term in dz_t: same formula as TTTLinear's "denominator derivative" + "minus a_scale · (W_prev - I) · z" + "minus a_scale · err · δ_jk" + "plus η · err · z · 2z / d²", but with `err` replaced by `delta_t` (the gelu'·(W2^T·...) quantity) and z replaced by z_t.

### Bugs caught and fixed during TDD

1. **b1/b2 update degeneracy**: The b2 update rule `b2 -= η/d_X · err` produces `b2_new += 1000 * z` when X2 is small (η/d_X explodes to ~1000). This made forward output `1000*z` even with W1=W2=0. Fixed by NOT updating b1/b2 in the standalone single-step-GD form.
2. **fd_param_check double-counted gradients**: The test was re-calling `backward()` per FD entry, accumulating gradients 2x, 3x, .... Fixed to call backward ONCE before the FD loop.
3. **mlp_ratio = 0 validation**: Constructor was treating 0 as "default to 4" — fixed by validating AFTER the initializer-list assignment.

### Known limitations

The TTTMLP analytical backward has larger FD error than TTTLinear because the W1 update rule's `delta_t[i]` is a non-linear function of z_t (it depends on z_t through Z1[i] = W1_prev · z and through W2_t · err), whereas TTTLinear's `err_t = W_prev · z - z` is exactly linear in z_t. The TTTLinear-style closed-form recurrence formula doesn't apply directly to TTTMLP's W1 update; we use a leading-order approximation that gives FD rel_err ~0.2-0.3 instead of TTTLinear's 1e-8.
