# DeltaNet Implementation Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Add a `DeltaNet` (linear attention with the delta rule) layer to the library, following the paper by Yang et al. (2024), "Linear Attention with the Delta Rule" (NeurIPS 2024).

**Architecture:** Per-head single-step recurrence with a (head_dim × head_dim) matrix state. The update rule replaces standard linear attention's `S_t = S_{t-1} + outer(k_t, v_t)` with a delta-rule update that subtracts the prior prediction `S_{t-1}·k_t` from `v_t` before adding, scaled by a `1/(1 + k_t·S_{t-1}·k_t)` adapter factor. Multi-head with standard projections (W_Q, W_K, W_V, W_O). Optional `k` projection reparameterization (learned L2 norm of k, multiplying k before the recurrence) — the canonical DeltaNet paper trick that stabilizes the recurrence.

**Tech Stack:** Existing `Layer`, `Tensor`, `Dense`, `LayerNorm` primitives. Files go in `include/nn/layers/recurrent/`. Tested with numerical gradient checks at machine precision.

## Background

**Paper context.** Linear attention (Katharopoulos et al. 2020) replaces softmax(QK^T)V with `S_t = S_{t-1} + outer(k_t, v_t)`, `o_t = S_t · q_t`. This is fast (O(d) per step) but incapable of "in-context copying" — it cannot use the retrieved values to update the state as it goes. The **delta rule** (Schlag et al. 2021, "Linear Transformers Are Secretly Fast Weight Programmers") fixes this by replacing the value with the *residual* `v_t - S_{t-1}·k_t`:

```
S_t = S_{t-1} + (α_t) · outer(k_t, v_t - S_{t-1}·k_t)
o_t = S_t · q_t
```

where `α_t = 1 / (1 + k_t · S_{t-1}·k_t)` is a normalization from the delta-rule derivation. Yang et al. 2024 add a **learned k-projection magnitude** `k_t ← (k_norm / |k_t|) · k_t` (the "beta" parameter, with `|k_t| = sqrt(k_t · k_t)` per-coordinate normalization) to stabilize the recurrence without losing the delta-rule benefits.

**Why now.** The library has Mamba, Mamba-2, RWKV, RetNet, H3, mLSTM, xLSTM, but not the linear-attention-with-delta-rule variant. DeltaNet is the most cited 2024 successor to linear attention (the "Mamba-3 era" reference) and pairs naturally with Mamba-2 in the linear-attention/SSM space.

```cpp
#define DELTANET_H

#include "../../core/layer.h"

#include <cmath>

// ============================================================================
// DeltaNet — Yang et al. 2024 (NeurIPS 2024)
//   "Linear Attention with the Delta Rule"
//   https://arxiv.org/abs/2406.06484
//
// Linear attention (Katharopoulos et al. 2020) replaces the quadratic softmax
// attention with a linear-time recurrence:
//
//   S_t = S_{t-1} + outer(k_t, v_t)
//   o_t = S_t · q_t
//
// Linear attention has the same expressive bottleneck as any linear function:
// it cannot perform "in-context copying" — once a value is stored, it cannot
// be updated later based on what the model has retrieved. The delta rule
// (Schlag et al. 2021) fixes this by replacing the value with the *residual*
// (the "new information" the state hasn't seen yet):
//
//   S_t = S_{t-1} + α_t · outer(k_t,  v_t - S_{t-1}·k_t)
//   o_t = S_t · q_t
//
// where α_t = 1 / (1 + k_t · S_{t-1} · k_t) is a normalization derived from
// solving the delta-rule optimality condition (delta-update « fast weight
// programming "SGD on the retrieved pattern with learning rate 1/L" ").
//
// Yang et al. 2024 add a learned k-projection magnitude (the "beta" parameter,
// with |k_t| = sqrt(k_t · k_t) per-coordinate normalization) to stabilize the
// recurrence without losing the delta-rule benefits:
//
//   k_t ← (β / |k_t|) · k_t
//
// This bounds |k_t| away from 0 and ∞, keeping α_t numerical-safe.
//
// ----------------------------------------------------------------------------
// Architecture (single DeltaNet layer, multi-head):
//
// Input:  X in R^{T x d_model}      (T sequence positions)
//
// Step 1 — Projections (Dense: y = x·W^T + b):
//   q_t = W_Q · x_t                                  in R^{H * d}
//   k_t = W_K · x_t                                  in R^{H * d}
//   v_t = W_V · x_t                                  in R^{H * d}
//   β_t = sigmoid(W_β · x_t)                         in R^{H}        (scalar per head)
//
// Step 2 — Per-head k-magnitude normalization (delta-rule paper §3.3):
//   for each head h:
//     k_t[h] *= (β_t[h] / |k_t[h]|)                 (|k| = per-head L2 norm)
//
// Step 3 — Per-head delta-rule recurrence (single-step, parallelisable):
//   S_0^(h) = 0 in R^{d x d}
//   for t = 0..T-1:
//     α_t[h] = 1 / (1 + k_t[h] · S_{t-1}^(h) · k_t[h])             (scalar per head)
//     S_t^(h) = S_{t-1}^(h) + α_t[h] · outer(k_t[h], v_t[h] - S_{t-1}^(h)·k_t[h])
//     o_t[h] = S_t^(h) · q_t[h]                                       (vector in R^d)
//
// Step 4 — Concat heads + output projection:
//   o_t = concat([o_t[0]; ...; o_t[H-1]])               in R^{H*d = d_inner}
//   out_t = W_O · o_t                                  in R^{d_model}
//
// ----------------------------------------------------------------------------
// Shape conventions:
//   X:               (T, d_model)
//   Q, K, V:         (T, d_inner = H * d)
//   β:               (T, H)
//   S (per head):    (d, d) — single matrix state per head per time step
//   o:               (T, d_inner)
//   W_O output:      (T, d_model)
//
// We use head_dim = d_inner / n_heads (must divide evenly). For numerical
// gradient checks we use d_inner=4, n_heads=2, head_dim=2, T=3-4.
//
// ----------------------------------------------------------------------------
// Learnable parameters: W_Q, W_K, W_V, W_O, W_β (W_Q, W_K, W_V, W_β share
// the same input x_t — "shared trunk" projections; W_O is the output mixing).
//
// We store the projections as Dense layers for forward/backward consistency
// with the rest of the library.
// ============================================================================

class DeltaNet : public Layer {
public:
    DeltaNet(size_t d_model, size_t n_heads, size_t head_dim = 0);

    // Input: (T, d_model) tensor. Output: (T, d_model) tensor.
    Tensor forward(const Tensor& input) override;

    // Standard backward: receives grad_output (T, d_model) and returns
    // grad_input (T, d_model). Internal Dense projections accumulate their
    // own gradients via the standard Layer convention.
    Tensor backward(const Tensor& grad_output, double learning_rate) override;

    void zero_grad() override;

    // Parameter accessors (for optimizer discovery)
    std::vector<Tensor*> parameters() override;
    std::vector<Tensor*> gradients() override;

    // Test introspection: per-head state at time T (last call)
    // Returns S_T for each head, stacked shape (n_heads, head_dim, head_dim).
    // Used to verify the recurrence is actually accumulating state.
    Tensor last_state() const;

    // Setters / accessors for inspectors
    size_t d_model() const { return d_model_; }
    size_t n_heads() const { return n_heads_; }
    size_t head_dim() const { return head_dim_; }
    size_t d_inner() const { return d_inner_; }

private:
    size_t d_model_;
    size_t n_heads_;
    size_t head_dim_;
    size_t d_inner_;

    // Dense projections: y = x · W^T + b
    // Stored as Dense so we get the standard forward/backward/zero_grad hook.
    Dense W_Q_, W_K_, W_V_, W_O_, W_beta_;

    // Cache for backward (all per-token, per-head)
    Tensor cache_x_;           // (T, d_model)
    Tensor cache_q_;           // (T, d_inner)
    Tensor cache_k_;           // (T, d_inner)
    Tensor cache_v_;           // (T, d_inner)
    Tensor cache_k_scaled_;    // (T, d_inner)  — k_t after β/|k_t| rescaling
    Tensor cache_beta_;        // (T, n_heads)
    Tensor cache_alpha_;       // (T, n_heads)  — α_t scalar per head
    std::vector<Tensor> cache_S_;  // S_t per head per t, cache_S_[t][h] is (d, d)
    std::vector<Tensor> cache_o_;  // (T, d_inner) per-head output (concat)
    Tensor cache_concat_o_;    // (T, d_inner) — what W_O sees

    // Per-head gradient buffers (needed for the backwards recurrence)
    Tensor grad_q_;            // (T, d_inner)
    Tensor grad_k_;            // (T, d_inner)
    Tensor grad_v_;            // (T, d_inner)
    Tensor grad_k_scaled_;     // (T, d_inner)
    Tensor grad_concat_o_;     // (T, d_inner)
    Tensor grad_x_;            // (T, d_model) — returned by backward()

    // Per-(head, time) gradient buffers for the recurrence
    std::vector<Tensor> grad_S_; // (T, n_heads, d, d)  — grad w.r.t. S_t

    void _check_init();
};

#endif // DELTANET_H
```

```cpp
#include "layers/recurrent/deltanet.h"
#include "../../core/tensor.h"
#include <stdexcept>
#include <cmath>

// Initialize projections to a small random scale (consistent with the rest
// of the library, ~0.02 — small enough that the recurrence stays numerically
// stable for forward checks, large enough that gradient checks are non-vacuous).
static Tensor rand_init(size_t rows, size_t cols) {
    Tensor t(rows, cols);
    // Random in [-0.5, 0.5] / sqrt(cols) for Xavier-ish scaling
    double s = 0.5 / std::sqrt(static_cast<double>(cols));
    for (size_t i = 0; i < rows; ++i) {
        for (size_t j = 0; j < cols; ++j) {
            t[i][j] = (static_cast<double>(std::rand()) / RAND_MAX - 0.5) * 2.0 * s;
        }
    }
    return t;
}

DeltaNet::DeltaNet(size_t d_model, size_t n_heads, size_t head_dim)
    : d_model_(d_model),
      n_heads_(n_heads),
      head_dim_(head_dim == 0 ? d_model / n_heads : head_dim),
      d_inner_(n_heads * (head_dim == 0 ? d_model / n_heads : head_dim))
{
    if (d_model_ == 0 || n_heads_ == 0) {
        throw std::invalid_argument("DeltaNet: d_model and n_heads must be > 0");
    }
    if (head_dim_ == 0 || d_model_ % head_dim_ != 0) {
        throw std::invalid_argument("DeltaNet: d_model must divide evenly by head_dim (or its default)");
    }
    if (n_heads_ * head_dim_ != d_model_ && n_heads_ * head_dim_ != d_inner_) {
        // Allow either d_inner = d_model (default) or d_inner = n_heads * head_dim
        throw std::invalid_argument("DeltaNet: n_heads * head_dim must equal d_model (default) or be set explicitly");
    }
    // Just check the regression-friendly case: d_inner = d_model.
    d_inner_ = d_model;

    // Dense(d_inner, d_model): y = x · W^T + b, but we use Dense(d_model, d_inner)
    // for the "x · W^T + b" projection form (matches the rest of the library).
    // W_Q projects d_model -> d_inner, so Dense(d_model, d_inner).

    // Initialize Dense projections with random small weights
    W_Q_ = Dense(d_model, d_inner_);
    W_K_ = Dense(d_model, d_inner_);
    W_V_ = Dense(d_model, d_inner_);
    W_O_ = Dense(d_inner_, d_model);
    W_beta_ = Dense(d_model, n_heads_);  // per-head beta (will be sigmoid'd)

    // Override the random init with our Xavier-ish scale
    W_Q_.weights = rand_init(d_inner_, d_model_);
    W_K_.weights = rand_init(d_inner_, d_model_);
    W_V_.weights = rand_init(d_inner_, d_model_);
    W_O_.weights = rand_init(d_model, d_inner_);
    W_beta_.weights = rand_init(n_heads_, d_model_);
    // Biases default to zero in Dense
}
```

**Step 1: Append the forward implementation.**

```cpp
Tensor DeltaNet::forward(const Tensor& input) {
    // input: (T, d_model)
    size_t T = input.rows;
    if (T == 0) return Tensor(0, d_model_);
    if (input.cols != d_model_) {
        throw std::invalid_argument("DeltaNet::forward: input.cols must equal d_model");
    }

    cache_x_ = input.clone();

    // Project
    cache_q_ = W_Q_.forward(input);   // (T, d_inner)
    cache_k_ = W_K_.forward(input);   // (T, d_inner)
    cache_v_ = W_V_.forward(input);   // (T, d_inner)
    Tensor beta_raw = W_beta_.forward(input);  // (T, n_heads)
    cache_beta_ = Tensor(T, n_heads_);
    for (size_t t = 0; t < T; ++t) {
        for (size_t h = 0; h < n_heads_; ++h) {
            cache_beta_[t][h] = 1.0 / (1.0 + std::exp(-beta_raw[t][h]));  // sigmoid
        }
    }

    // Per-head k-magnitude normalization: k_t[h] *= (beta_t[h] / |k_t[h]|)
    // |k_t[h]| = sqrt(sum_d k_t[h*head_dim + d]^2)
    cache_k_scaled_ = Tensor(T, d_inner_);
    cache_alpha_ = Tensor(T, n_heads_);
    for (size_t t = 0; t < T; ++t) {
        for (size_t h = 0; h < n_heads_; ++h) {
            // Compute |k_t[h]|
            double k_norm_sq = 0.0;
            for (size_t d = 0; d < head_dim_; ++d) {
                double k = cache_k_[t][h * head_dim_ + d];
                k_norm_sq += k * k;
            }
            double k_norm = std::sqrt(k_norm_sq + 1e-12);  // numerical floor
            double scale = cache_beta_[t][h] / k_norm;
            for (size_t d = 0; d < head_dim_; ++d) {
                cache_k_scaled_[t][h * head_dim_ + d] = cache_k_[t][h * head_dim_ + d] * scale;
            }
        }
    }

    // Per-head delta-rule recurrence
    // S_t^(h) is (head_dim, head_dim), one matrix per head
    cache_S_.clear();
    cache_S_.resize(T);
    cache_S_[0] = Tensor(n_heads_, head_dim_ * head_dim_);  // zero state
    // (We'll store S_t as a Tensor of (n_heads, head_dim * head_dim) — flat-ish.)

    cache_o_ = Tensor(T, d_inner_);
    Tensor current_state(n_heads_, head_dim_ * head_dim_);  // zero-initialized

    for (size_t t = 0; t < T; ++t) {
        cache_S_[t] = current_state.clone();

        for (size_t h = 0; h < n_heads_; ++h) {
            // Extract k_t[h], v_t[h] as column-like vectors
            // k_t[h]: (head_dim,), v_t[h]: (head_dim,)
            // current_state[h]: (head_dim * head_dim) flat = row-major matrix

            // Compute S_{t-1}^(h) · k_t[h]   (matrix-vector product)
            double Sk[64];  // head_dim_ <= 64 in our test config
            for (size_t i = 0; i < head_dim_; ++i) {
                double sum = 0.0;
                for (size_t j = 0; j < head_dim_; ++j) {
                    sum += current_state[h][i * head_dim_ + j] *
                           cache_k_scaled_[t][h * head_dim_ + j];
                }
                Sk[i] = sum;
            }

            // α_t[h] = 1 / (1 + k_t[h] · Sk)
            double k_dot_Sk = 0.0;
            for (size_t d = 0; d < head_dim_; ++d) {
                k_dot_Sk += cache_k_scaled_[t][h * head_dim_ + d] * Sk[d];
            }
            double alpha = 1.0 / (1.0 + k_dot_Sk);
            cache_alpha_[t][h] = alpha;

            // Compute v_t[h] - S_{t-1}^(h)·k_t[h] = v_t[h] - Sk
            double residual[64];
            for (size_t d = 0; d < head_dim_; ++d) {
                residual[d] = cache_v_[t][h * head_dim_ + d] - Sk[d];
            }

            // Update S_t[h] = S_{t-1}[h] + alpha * outer(k_t[h], residual)
            // outer[k, res] = a matrix where (i, j) = k[i] * res[j]
            for (size_t i = 0; i < head_dim_; ++i) {
                for (size_t j = 0; j < head_dim_; ++j) {
                    double k = cache_k_scaled_[t][h * head_dim_ + i];
                    current_state[h][i * head_dim_ + j] +=
                        alpha * k * residual[j];
                }
            }

            // Output o_t[h] = S_t[h] · q_t[h]
            for (size_t i = 0; i < head_dim_; ++i) {
                double sum = 0.0;
                for (size_t j = 0; j < head_dim_; ++j) {
                    sum += current_state[h][i * head_dim_ + j] *
                           cache_q_[t][h * head_dim_ + j];
                }
                cache_o_[t][h * head_dim_ + i] = sum;
            }
        }
    }

    cache_concat_o_ = cache_o_.clone();
    Tensor out = W_O_.forward(cache_concat_o_);  // (T, d_model)
    return out;
}
```

## Task 4: Backward pass — the math

**Objective:** Implement the backward pass. The recurrence is reversed via a backward-time sweep with the recurrences for `grad_S_t`, `grad_k_scaled_t`, `grad_v_t`, `grad_beta_t`.

**Math derivation.** Let `L` be the loss. For each head h, define:

- `S_t = S_{t-1} + α_t · outer(k_t, v_t - S_{t-1}·k_t)`
- `o_t = S_t · q_t`
- `α_t = 1 / (1 + k_t · S_{t-1} · k_t)` (scalar per head)

Rewriting with `r_t = v_t - S_{t-1}·k_t = v_t - Sk` and `S_t = S_{t-1} + α_t · outer(k_t, r_t)`:

```
dL/dS_t          = (dL/do_t) · q_t^T + (downstream carrier from t+1)
dL/d(α_t)        = dL/dS_t · outer(k_t, r_t)         (only affects S_t directly)
dL/d(r_t)        = (dL/dS_t)^T · (α_t · k_t)
dL/d(k_t)        = (dL/dS_t)^T · (α_t · r_t) + carry_from_(dL/dα_t) + carry_from_(dL/dSk)
dL/d(v_t)        = dL/d(r_t)
dL/dS_{t-1}      = dL/dS_t - dL/d(r_t) · k_t^T  (the part of S_{t-1} that was "subtracted via the residual")
                 + carry from α_t (alpha_t depends on S_{t-1} via k_t · S_{t-1} · k_t)
```

Carrier between `dL/dS_t` and `dL/dS_{t-1}`: the residual path is `S_{t-1} → r_t = v_t - S_{t-1}·k_t → S_t`, and also `S_{t-1} → α_t = 1/(1 + k_t·S_{t-1}·k_t) → S_t`. Both must be carried.

More compactly (drop the head index h):

```
Let gS_t = dL/dS_t         (grad w.r.t. S_t, matrix (d, d))
Let gS_t_next = grad_S_ from time t+1 (the "future" grad coming back)

Step 1 — Output gradient:
  g_o_t = grad_output[t]   (received from the layer above)
  g_q_t = gS_t · q_t       (just the output-side gradient)
  g_o_t → gS_t contributes:   gS_t += outer(g_o_t, q_t)

Step 2 — From gS_t, the residual path:
  We need dL/d(v_t) and the rest of the chain. The decomposition is:
    S_t = S_{t-1} + α_t · outer(k_t, r_t)
    r_t = v_t - S_{t-1}·k_t
    α_t = 1 / (1 + k_t · S_{t-1} · k_t)
  Apply the chain rule:
    dL/dv_t  = dL/dr_t · (∂r_t/∂v_t) = (gS_t · (α_t · k_t))^T  (treating gS_t as (d,d))
              [This is the simple closed-form; see derivation below.]

Step 3 — The full gS_t path: contributions propagate time-backward via:
  gS_{t-1} += (gS_t + future carrier) - gS_t · k_t · g_k_t^T  (residual carrier)
```

**Cleaner derivation.** Let me unpack the recurrence properly.

Each `S_t` is a function of `S_{t-1}`, `k_t`, `v_t`:

```
S_t = S_{t-1} + α_t · (k_t (v_t - S_{t-1}·k_t)^T)
    = (I - α_t · k_t · k_t^T) · S_{t-1} + α_t · k_t · v_t^T
```

So:
```
dS_t/dS_{t-1} = I - α_t · k_t · k_t^T - α_t² · (k_t · S_{t-1} · k_t) · ... (carries alpha dependence too)
```

The `α_t` depends on `S_{t-1}` via `k_t · S_{t-1} · k_t`, so:
```
dα_t/dS_{t-1} = -α_t² · k_t · k_t^T
```

This is the cleanest form. The implementation will:
1. Receive `grad_output` (T, d_model) = `g_o_t` flatted
2. Initialize `gS_T = 0` (no future from T+1)
3. For t = T-1 down to 0:
   - `gS_t += outer(g_o_t, q_t)` (output side contributes to gS_t)
   - Compute `g_v_t = (gS_t · (α_t · k_t))^T` — wait, careful with shapes.
   - Compute `g_k_t` from (i) the inner-product position in α_t and (ii) the outer-product position in the residual update.
   - Update `gS_{t-1}` from `gS_t` via the (I - α_t k_t k_t^T) carrier plus the α_t dependency.

**Step 1: Append the backward implementation to `deltanet.cpp`.**

```cpp
Tensor DeltaNet::backward(const Tensor& grad_output, double /*learning_rate*/) {
    size_t T = grad_output.rows;
    if (T == 0) return Tensor(0, d_model_);
    if (grad_output.cols != d_model_) {
        throw std::invalid_argument("DeltaNet::backward: grad_output.cols must equal d_model");
    }

    // dL/d(o_concat) starts at W_O_.backward's input gradient
    // We need to compute it manually since W_O_ is fed the concat output
    // The standard Dense.backward does: receive grad of W_O_'s output, compute
    // grad_input for W_O_, accumulate grad_weights/bias on W_O_, and return grad_input.
    // We delegate that to W_O_:
    Tensor grad_concat_o = W_O_.backward(grad_output, 0.0);  // (T, d_inner)
    // Split grad_concat_o into per-head contributions
    // (We don't need to split — it's already (T, d_inner) which is the same as
    // cache_o_'s shape; treat it as the per-head o gradient via the (H, d) layout.)

    // Now: compute the recurrence backward
    grad_S_.clear();
    grad_S_.resize(T);
    grad_q_ = Tensor(T, d_inner_);
    grad_k_ = Tensor(T, d_inner_);
    grad_v_ = Tensor(T, d_inner_);
    grad_k_scaled_ = Tensor(T, d_inner_);
    Tensor grad_alpha(T, n_heads_);  // local
    grad_x_ = Tensor(T, d_model_);

    // S_t = (I - α_t k_t k_t^T) S_{t-1} + α_t k_t v_t^T
    // (matrix identity: writing outer(k, r) = k r^T)
    //
    // We track the upstream gradient gS_t as a (d*d)-shaped tensor per head.
    Tensor gS_next(n_heads_, head_dim_ * head_dim_);  // zero-initialized

    for (int t_signed = static_cast<int>(T) - 1; t_signed >= 0; --t_signed) {
        size_t t = static_cast<size_t>(t_signed);

        // Step 1: gS_t gets the output-side contribution
        // g_o_t (concat) → gS_t += outer(g_o_t, q_t) per head
        // (head_dim * head_dim) update: gS_t[h][i,j] += g_o_t[h*d+i] * q_t[h*d+j]
        //
        // We need to ADD gS_next to the output-side contribution? Actually, gS_next
        // is the "downstream" grad of S_t — that IS gS_t. Then we compute gS_{t-1}
        // from gS_t.

        Tensor gS_t = gS_next.clone();  // gS_t is the downstream grad of S_t

        // Add output-side contribution to gS_t: o_t = S_t · q_t → dL/dS_t += outer(g_o_t, q_t)
        for (size_t h = 0; h < n_heads_; ++h) {
            for (size_t i = 0; i < head_dim_; ++i) {
                double go = grad_concat_o[t][h * head_dim_ + i];
                double gq = cache_q_[t][h * head_dim_ + i];
                // dL/dS_t[h][i, j] += g_o_t[h*d+i] * q_t[h*d+j]
                for (size_t j = 0; j < head_dim_; ++j) {
                    gS_t[h][i * head_dim_ + j] += go * cache_q_[t][h * head_dim_ + j];
                }
            }
        }

        grad_S_[t] = gS_t.clone();

        // Save the per-head q/k/v gradients
        // dL/dQ_t[h, i] = sum_j gS_t[h][i, j] * (dL/do_t contribution)
        // We use the fact that gS_t already includes the output-side term.
        // grad_q_t[h*d+i] = sum_j gS_t[h][i, j] * (the residual term doesn't contribute to q)
        // Since the output only depends on q via the inner product S_t · q_t,
        //   grad_q_t[g_o_t contribution] = (gS_t · q_t) but only the output-side part.
        //   The simpler route: grad_q_t = gS_t · q_t   (where gS_t is the full S_t gradient)
        //   Actually no — the output path is O_t = S_t · q_t, so dL/dq_t = g_o_t + dL/d(any later S_{t+1} that uses q_t) — but q_t doesn't appear in S_{t+1}, so just dL/dq_t = g_o_t.
        //   Wait: hmm. Output is o_t = S_t · q_t. dL/do_t = g_o_t. Then dL/dq_t = g_o_t · S_t^T (matrix), so grad_q_t[h*d+i] = sum_j S_t[h][i,j] * g_o_t[h*d+j].
        //   And dL/dS_t from output path = outer(g_o_t, q_t) which we already added.
        for (size_t h = 0; h < n_heads_; ++h) {
            for (size_t i = 0; i < head_dim_; ++i) {
                double sum_q = 0.0;
                double sum_k = 0.0;
                double sum_v = 0.0;
                for (size_t j = 0; j < head_dim_; ++j) {
                    sum_q += gS_t[h][i * head_dim_ + j] * cache_o_[t][h * head_dim_ + j];  // not directly used
                    // grad_q_t = S_t^T · g_o_t  → sum_j S_t[h][j, i] * g_o_t[h*d+j]
                    sum_q = 0.0;  // reset
                    sum_q += cache_concat_o_ ? 0.0 : 0.0;  // placeholder
                }
                // Recompute grad_q_t cleanly:
                double gq = 0.0;
                for (size_t j = 0; j < head_dim_; ++j) {
                    gq += gS_t[h][j * head_dim_ + i] * grad_concat_o[t][h * head_dim_ + j];
                }
                grad_q_[t][h * head_dim_ + i] = gq;
                // grad_k_scaled_t[h*d+i] from the recurrence update (see below)
                grad_k_scaled_[t][h * head_dim_ + i] = 0.0;  // placeholder, filled below
                // grad_v_t same.
                grad_v_[t][h * head_dim_ + i] = 0.0;
            }
        }

        // Step 2: Compute the residual / update contributions to grad_k, grad_v
        // For each head h:
        //   S_t = S_{t-1} + α_t · outer(k_t, r_t)
        //   r_t = v_t - S_{t-1} · k_t
        //   α_t = 1 / (1 + k_t · S_{t-1} · k_t)
        //
        // grad from gS_t (the outer-product update) w.r.t. (k_t, r_t):
        //   ∂S_t / ∂r_t = α_t · k_t  (as a column vector — outer(k_t, r_t) has ∂/∂r_t[j] = α_t · k_t[j])
        //   ∂S_t / ∂k_t[h*d+i] = ∂(α_t · outer(k_t, r_t)) / ∂k_t[h*d+i]
        //                       = (∂α_t/∂k_t[h*d+i]) · outer(k_t, r_t) + α_t · (e_i r_t^T) [direct k path]
        //   + indirect: k_t also appears in r_t = v_t - S_{t-1}·k_t → dr_t/dk_t[h*d+i] = -S_{t-1}[:, i]
        //   which contributes via dS_t/dr_t · dr_t/dk_t.
        //
        // For tractability, let's compute each piece:
        //   contrib_k_from_outer = α_t · r_t (vector of length head_dim)
        //   contrib_r_from_outer = α_t · k_t (vector of length head_dim)
        //   contrib_r_from_k = -S_{t-1}[:, :] · k_t  (this is Sk we computed in forward)
        //
        // So dS_t/d(r_t) = α_t · k_t (the r_t coefficient in the outer term)
        // And dS_t/d(k_t) = α_t · r_t + α_t · dr_t/dk_t · ... — this is more complex.
        //
        // The cleanest way: compute gV_t from the r_t path, then gK_t from BOTH the
        // outer-product path AND the r_t path AND the α_t path.

        // For each head, compute:
        //   g_r_t[h] = (α_t · gS_t^T · k_t)  (as a vector of length head_dim)
        //   g_v_t[h] = g_r_t[h]  (since v_t appears linearly in r_t)
        //   g_k_t[h] from three sources:
        //     (a) direct outer-product: (gS_t · r_t)^T · α_t   (vector of length head_dim)
        //     (b) r_t dependence: g_r_t[h] · (-S_{t-1}[:, h*d+k])  (for each k)
        //     (c) α_t dependence: grad_alpha_t[h] * (-α_t² · k_t · S_{t-1} · k_t)  (vector)
        //         Where grad_alpha_t[h] = gS_t[h] · outer(k_t, r_t) (matrix inner product)

        // Compute Sk[t] = S_{t-1}[h] · k_t[h] (matrix-vector)  — needed for backward
        // We can recover this from the forward computation:
        double Sk[64];  // re-compute below per head
        double r_t[64];  // residual

        // Compute gS_{t-1} (the carrier to previous time step)
        // gS_{t-1}[h] = gS_t[h] (the "t-1 appears in S_t directly" part)
        //              - g_r_t[h] · k_t[h]^T  (the indirect path via r_t)
        //              + (path from α_t dependence on S_{t-1})

        Tensor gS_prev(n_heads_, head_dim_ * head_dim_);

        for (size_t h = 0; h < n_heads_; ++h) {
            // Re-compute Sk and r_t for head h
            for (size_t i = 0; i < head_dim_; ++i) {
                double sum = 0.0;
                for (size_t j = 0; j < head_dim_; ++j) {
                    sum += cache_S_[t][h][i * head_dim_ + j] *  // S_{t-1}[h]
                           cache_k_scaled_[t][h * head_dim_ + j];
                }
                Sk[i] = sum;
                r_t[i] = cache_v_[t][h * head_dim_ + i] - Sk[i];
            }
            double alpha = cache_alpha_[t][h];

            // g_r_t[h, j] = sum_i gS_t[h, i, j] * alpha * k_t[h, i]
            // gS_t is (d, d), k_t is (d,). Result is (d,).
            double g_r[64];
            for (size_t j = 0; j < head_dim_; ++j) {
                double sum = 0.0;
                for (size_t i = 0; i < head_dim_; ++i) {
                    sum += gS_t[h][i * head_dim_ + j] * alpha *
                           cache_k_scaled_[t][h * head_dim_ + i];
                }
                g_r[j] = sum;
            }

            // g_v_t[h] = g_r_t[h]  (since r_t = v_t - S_{t-1}·k_t, ∂r_t/∂v_t = I)
            for (size_t i = 0; i < head_dim_; ++i) {
                grad_v_[t][h * head_dim_ + i] = g_r[i];
            }

            // Path (a): direct outer-product contribution to g_k_t
            // ∂S_t[h, i, j] / ∂k_t[h, i] = alpha * r_t[j]
            // → g_k_t[h, i] += alpha * sum_j gS_t[h, i, j] * r_t[j]
            double g_k_a[64];
            for (size_t i = 0; i < head_dim_; ++i) {
                double sum = 0.0;
                for (size_t j = 0; j < head_dim_; ++j) {
                    sum += gS_t[h][i * head_dim_ + j] * r_t[j];
                }
                g_k_a[i] = alpha * sum;
            }

            // Path (b): r_t dependence on k_t → g_r_t · (d r_t / d k_t)
            // d(r_t[j]) / d(k_t[i]) = -S_{t-1}[i, j]
            // → g_k_t[h, i] += -sum_j g_r_t[h, j] * S_{t-1}[i, j]
            double g_k_b[64];
            for (size_t i = 0; i < head_dim_; ++i) {
                double sum = 0.0;
                for (size_t j = 0; j < head_dim_; ++j) {
                    sum += g_r[j] * cache_S_[t][h][i * head_dim_ + j];
                }
                g_k_b[i] = -sum;
            }

            // Path (c): α_t dependence on S_{t-1} (via k_t · S_{t-1} · k_t)
            // dα_t / d(S_{t-1}[i, j]) = -α_t² · k_t[i] · k_t[j]
            // dα_t / d(k_t[i]) = -2 · α_t² · (S_{t-1} · k_t)[i] = -2 · α_t² · Sk[i]
            // dL/dα_t = sum_{i,j} gS_t[i, j] · (∂S_t[i, j] / ∂α_t) = sum_{i,j} gS_t[i, j] · k_t[i] · r_t[j]
            // → g_k_t[h, i] += g_α_t * dα_t / d(k_t[i]) = g_α_t · (-2α_t² · Sk[i])
            //   g_k_t[h, i, j via S_{t-1} path] += g_α_t · dα_t/d(S_{t-1}[i, j]) = g_α_t · (-α_t² · k_t[i] · k_t[j])
            double g_alpha = 0.0;
            for (size_t i = 0; i < head_dim_; ++i) {
                for (size_t j = 0; j < head_dim_; ++j) {
                    g_alpha += gS_t[h][i * head_dim_ + j] *
                               cache_k_scaled_[t][h * head_dim_ + i] * r_t[j];
                }
            }

            double g_k_c[64];
            for (size_t i = 0; i < head_dim_; ++i) {
                g_k_c[i] = g_alpha * (-2.0 * alpha * alpha * Sk[i]);
            }

            // Path (d): α_t dependence on S_{t-1} directly (going INTO gS_{t-1})
            // dL/dS_{t-1}[i, j] += g_α_t · dα_t/dS_{t-1}[i, j] = g_α_t · (-α_t² · k_t[i] · k_t[j])
            // This contributes to gS_prev along with the direct identity path.

            // g_k_t total:
            for (size_t i = 0; i < head_dim_; ++i) {
                double k = g_k_a[i] + g_k_b[i] + g_k_c[i];
                grad_k_scaled_[t][h * head_dim_ + i] = k;
            }
            // grad_alpha_ doesn't need to be stored separately; we used it locally.

            // gS_{t-1} carrier:
            // (I) direct path: S_t = S_{t-1} + α_t·outer(k_t, r_t)  → gS_{t-1} += gS_t (direct)
            // (II) residual path: r_t = v_t - S_{t-1}·k_t  → gS_{t-1} += -g_r_t · k_t^T
            // (III) α_t path: dα_t/dS_{t-1} = -α_t² k_t k_t^T  → gS_{t-1} += g_α_t · (-α_t² k_t k_t^T)
            for (size_t i = 0; i < head_dim_; ++i) {
                for (size_t j = 0; j < head_dim_; ++j) {
                    double direct = gS_t[h][i * head_dim_ + j];
                    double via_r = -g_r[j] * cache_k_scaled_[t][h * head_dim_ + i];
                    double via_alpha = -alpha * alpha *
                                       cache_k_scaled_[t][h * head_dim_ + i] *
                                       cache_k_scaled_[t][h * head_dim_ + j] *
                                       g_alpha;
                    gS_prev[h][i * head_dim_ + j] = direct + via_r + via_alpha;
                }
            }
        }

        gS_next = gS_prev;
    }

    // Now: grad_k_scaled_ → grad_k_ (undo the β/|k_t| scaling)
    // k_scaled = (β / |k|) * k → dk_scaled/dk = (β / |k|) * I + (correction from |k|)
    // For simplicity, we treat the gradient as:
    //   grad_k_t[h*d+i] = grad_k_scaled_t[h*d+i] * (β_t[h] / |k_t[h]|)
    // (The "correction from |k|" term is a Jacobian of the normalization, which
    //  is technically there but would complicate the test. Since the test
    //  succeeds at the level of "grad_q ≈ grad_q_FD, grad_v ≈ grad_v_FD, etc.",
    //  we can either include the full Jacobian or document the approximation.
    //  For exactness, include the full Jacobian.)
    //
    // Full Jacobian:
    //   k_scaled[i] = (β / |k|) · k[i]
    //   d(|k|)/d(k[j]) = k[j] / |k|
    //   ∂k_scaled[i] / ∂k[j] = (β / |k|) · δ_ij + (β / |k|²) · k[i] · k[j] / |k| · (-1)
    //                       = (β / |k|) · (δ_ij - k[i]·k[j] / |k|²)
    //   So grad_k[j] = sum_i grad_k_scaled[i] · (β / |k|) · (δ_ij - k[i]·k[j] / |k|²)
    //                = (β / |k|) · grad_k_scaled[j] - (β / |k|²) · (sum_i grad_k_scaled[i] · k[i]) · k[j] / |k|
    //                = (β / |k|) · (grad_k_scaled[j] - (<k_scaled, k_unscaled_ish>) · k[j] / |k|²)
    //
    // Where k_unscaled was the original cache_k_[t][h*d+i] (before scaling).
    //
    // Let me recompute — k_scaled = (β / |k|) · k where k = cache_k_[t]. So:
    //   The scaled k is (β / |k|) · k, which means k_unscaled = (|k| / β) · k_scaled.
    //   Let k_full = cache_k_[t][h*d+i] = k_unscaled.
    //   |k| = sqrt(sum k_full²)
    //   k_scaled[i] = (β / |k|) · k_full[i]
    //
    // For backward:
    //   grad_k_full[i] = sum_j grad_k_scaled[j] · ∂k_scaled[j] / ∂k_full[i]
    //   ∂k_scaled[j] / ∂k_full[i] = (β / |k|) · (δ_ij - k_full[i]·k_full[j] / |k|²)
    //   → grad_k_full[i] = (β / |k|) · grad_k_scaled[i] - (β / |k|³) · k_full[i] · sum_j grad_k_scaled[j] · k_full[j]
    //   → grad_k_full[i] = (β / |k|) · (grad_k_scaled[i] - k_full[i] · dot(gks, k_full) / |k|²)
    //   → grad_k_full[i] = (β / |k|) · grad_k_scaled[i] - k_scaled[i] · dot(gks, k_full) / |k|²
    //     (since k_scaled[i] = (β/|k|) · k_full[i])
    //   → grad_k_full[i] = (β / |k|) · grad_k_scaled[i] - k_scaled[i] · dot(gks, k_full) / |k|²
    //
    //   And dot(gks, k_full) = sum_i grad_k_scaled[i] · k_full[i]
    //                       = (|k| / β) · sum_i grad_k_scaled[i] · k_scaled[i]
    //                       = (|k| / β) · dot(gks, k_scaled)
    //
    //   → grad_k_full[i] = (β / |k|) · grad_k_scaled[i] - k_scaled[i] · (|k|/β) · dot(gks, k_scaled) / |k|²
    //                    = (β / |k|) · grad_k_scaled[i] - k_scaled[i] · dot(gks, k_scaled) / (β · |k|)
    //                    = (1 / |k|) · (β · grad_k_scaled[i] - k_scaled[i] · dot(gks, k_scaled) / β)

    for (size_t t = 0; t < T; ++t) {
        for (size_t h = 0; h < n_heads_; ++h) {
            double k_norm_sq = 0.0;
            for (size_t d = 0; d < head_dim_; ++d) {
                double k = cache_k_[t][h * head_dim_ + d];
                k_norm_sq += k * k;
            }
            double k_norm = std::sqrt(k_norm_sq + 1e-12);
            double beta = cache_beta_[t][h];
            double beta_safe = std::max(beta, 1e-12);

            // dot(gks, k_scaled)
            double dot_gks_ks = 0.0;
            for (size_t d = 0; d < head_dim_; ++d) {
                dot_gks_ks += grad_k_scaled_[t][h * head_dim_ + d] *
                              cache_k_scaled_[t][h * head_dim_ + d];
            }

            for (size_t d = 0; d < head_dim_; ++d) {
                double gks = grad_k_scaled_[t][h * head_dim_ + d];
                double ks = cache_k_scaled_[t][h * head_dim_ + d];
                // grad_k_full[d] = (beta / k_norm) · gks - ks · dot(gks, ks) / (beta · k_norm)
                double gk = (beta / k_norm) * gks - ks * dot_gks_ks / (beta_safe * k_norm);
                grad_k_[t][h * head_dim_ + d] = gk;
            }
        }
    }

    // grad_beta_t: k_scaled = (β / |k|) · k → dk_scaled[i] / dβ = k_full[i] / |k| = k_scaled[i] / β
    // grad_beta[h] = sum_i grad_k_scaled[i] · (k_scaled[i] / β)
    Tensor grad_beta_local(T, n_heads_);
    for (size_t t = 0; t < T; ++t) {
        for (size_t h = 0; h < n_heads_; ++h) {
            double beta = std::max(cache_beta_[t][h], 1e-12);
            double sum = 0.0;
            for (size_t d = 0; d < head_dim_; ++d) {
                sum += grad_k_scaled_[t][h * head_dim_ + d] *
                       cache_k_scaled_[t][h * head_dim_ + d] / beta;
            }
            grad_beta_local[t][h] = sum;
        }
    }

    // Propagate gradients through the Dense layers.
    // Order: W_O_.backward is already called (it sets grad on its own weights
    // and returns grad_concat_o which we used above).
    // Now: Q/K/V/beta projections need their own backward pass.
    // We pass grad_q_, grad_k_, grad_v_ as the upstream gradient to each.
    Tensor gx_q = W_Q_.backward(grad_q_, 0.0);
    Tensor gx_k = W_K_.backward(grad_k_, 0.0);
    Tensor gx_v = W_V_.backward(grad_v_, 0.0);
    // For beta: we need the gradient of the LINEAR part (before sigmoid)
    // grad_beta_pre = grad_beta_local · sigmoid'(beta_pre) = grad_beta_local · beta · (1 - beta)
    Tensor grad_beta_raw(T, n_heads_);
    for (size_t t = 0; t < T; ++t) {
        for (size_t h = 0; h < n_heads_; ++h) {
            double b = cache_beta_[t][h];
            grad_beta_raw[t][h] = grad_beta_local[t][h] * b * (1.0 - b);
        }
    }
    Tensor gx_beta = W_beta_.backward(grad_beta_raw, 0.0);

    // Sum the contributions to grad_x
    grad_x_ = Tensor(T, d_model_);
    for (size_t t = 0; t < T; ++t) {
        for (size_t d = 0; d < d_model_; ++d) {
            grad_x_[t][d] = gx_q[t][d] + gx_k[t][d] + gx_v[t][d] + gx_beta[t][d];
        }
    }

    return grad_x_;
}
```

```cpp
}

Tensor DeltaNet::last_state() const {
    if (cache_S_.empty()) return Tensor(0, 0);
    const Tensor& last = cache_S_.back();
    return last.clone();
}
```

```cpp
// Numerical gradient check helper
static double compute_loss(DeltaNet& dn, const Tensor& x, const Tensor& target) {
    Tensor y = dn.forward(x);
    double loss = 0.0;
    size_t N = y.rows;
    for (size_t i = 0; i < y.rows; ++i) {
        for (size_t j = 0; j < y.cols; ++j) {
            double diff = y[i][j] - target[i][j];
            loss += diff * diff;
        }
    }
    return loss / (2.0 * N);
}

static Tensor numerical_input_grad(DeltaNet& dn, const Tensor& x, const Tensor& target, double eps) {
    size_t T = x.rows, D = x.cols;
    Tensor grad(T, D);
    for (size_t t = 0; t < T; ++t) {
        for (size_t d = 0; d < D; ++d) {
            Tensor x_plus = x.clone();
            Tensor x_minus = x.clone();
            x_plus[t][d] += eps;
            x_minus[t][d] -= eps;
            double L_plus = compute_loss(dn, x_plus, target);
            double L_minus = compute_loss(dn, x_minus, target);
            grad[t][d] = (L_plus - L_minus) / (2.0 * eps);
        }
    }
    return grad;
}

void test_input_grad() {
    std::cout << "test_input_grad..." << std::endl;
    std::srand(42);
    DeltaNet dn(4, 2, 2);
    Tensor x(3, 4);
    Tensor target(3, 4);
    for (size_t i = 0; i < 3; ++i) {
        for (size_t j = 0; j < 4; ++j) {
            x[i][j] = (std::rand() / (double)RAND_MAX - 0.5) * 0.3;
            target[i][j] = (std::rand() / (double)RAND_MAX - 0.5) * 0.3;
        }
    }

    // Forward + analytical backward
    Tensor y = dn.forward(x);
    Tensor grad_out(3, 4);
    for (size_t i = 0; i < 3; ++i) {
        for (size_t j = 0; j < 4; ++j) {
            grad_out[i][j] = (y[i][j] - target[i][j]) / 3.0;  // d(0.5*||y-t||²)/dy
        }
    }
    Tensor analytical = dn.backward(grad_out, 0.0);

    // Numerical
    Tensor numerical = numerical_input_grad(dn, x, target, 1e-5);

    // Compare
    double max_rel = 0.0;
    for (size_t i = 0; i < 3; ++i) {
        for (size_t j = 0; j < 4; ++j) {
            double a = analytical[i][j];
            double n = numerical[i][j];
            double denom = std::max(std::abs(a), std::abs(n));
            if (denom < 1e-12) denom = 1e-12;
            double rel = std::abs(a - n) / denom;
            if (rel > max_rel) max_rel = rel;
        }
    }
    std::cout << "  max rel_err = " << max_rel << std::endl;
    EXPECT(max_rel < 1e-3);
}
```

## Pitfalls / Cross-cutting concerns

1. **`Dense` API surface.** The exact field names / constructor signature may differ from the assumption `Dense(d_model, d_inner)` with public `weights` field. **Verify with `read_file include/nn/layers/dense/dense.h` before writing the constructor (Task 2).** Adjust if `Dense` is `Dense(in_features, out_features, activation)` or similar.

2. **`Tensor` clone semantics.** `Tensor::clone()` returns a deep copy. Verify this exists; if not, use manual copy.

3. **`Tensor::rows` and `Tensor::cols` are 0-indexed** and `operator[]` returns a `Tensor::Row` proxy. Verify the indexing semantics: `t[i][j]` should be a `double&`.

4. **`head_dim_ <= 64` assumption.** The `Sk[64]`, `g_k_a[64]`, etc. stack buffers assume head_dim ≤ 64. Tests use head_dim=2. If higher needed, use heap allocation.

5. **Numerical stability of α_t.** The denominator `1 + k_t · S_{t-1} · k_t` could go through zero if `k_t ≈ 0`. The k-magnitude normalization helps, but add a small epsilon (`+ 1e-12`) to the denominator for safety.

6. **Numerical gradient check noise.** Parameter gradient checks are noisier than input gradient checks. Use a slightly larger eps (1e-4) for parameter gradients, and a tolerance of 1e-3 for rel_err.

7. **Determinism.** The recurrence should be deterministic given the same input. If using `std::rand()` in tests, use a fixed seed before each call.

8. **Bias handling.** `Dense` may have a bias vector. We're using `Dense` directly, so bias is opt-in. Verify whether `Dense`'s default includes bias.

9. **Umbrella header compile.** Adding `#include "layers/recurrent/deltanet.h"` to `nn.h` may trigger circular include if `deltanet.h` itself includes `nn.h`. Verify the header includes only `core/layer.h`, not `nn.h`.

10. **The `last_state()` accessor returns a clone.** This is for inspection only. The original `cache_S_` is mutated by the next forward pass, so the clone is returned by value.
